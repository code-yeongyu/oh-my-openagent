   tracked omo-memory-mcp.js (and memory-run-supervisor.mjs) could not start under
   Node's ESM loader (shebang must be byte 0): the entire MCP tool surface was dead on
   the real host. Fixed in plugin/scripts/build-extension.mjs (shebang stays first;
   parseBuildArtifact tolerates both layouts; digest body unchanged) with a regression
   test in build-extension.test.mjs. Bundles were rebuilt ONLY for QA and restored with
   git checkout per the task brief; bundle regeneration belongs to the build owner.

   mcp_omo-memory_memory(_apply_patch), so provenance/identity injection never fired on
   the search exposure. Fixed by matching the catalog names too (nudge-wiring.ts) and
   proven on the real surface in senpi-run.txt (non-auto identity, trailers landed).
