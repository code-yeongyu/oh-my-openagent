  omo-qa bash /tmp-host-qa/qa-pr2528.sh

Isolation:
- The container is disposable (`--rm`) and uses its own HOME and OpenCode database.
- No provider credentials, host OpenCode configuration, or unrelated host temporary files are mounted.
- The models.dev public catalog cache is mounted read-only to avoid an unrelated network timeout.
- `/tmp/qa-project` is created inside the container and removed with it.
- The host database is read only for session counts before and after the container run.

The runner waits for real `session.created` and `session.idle` SSE events, invokes the current worktree production notification sender, and validates the script's JSON payload before printing the captured result.
