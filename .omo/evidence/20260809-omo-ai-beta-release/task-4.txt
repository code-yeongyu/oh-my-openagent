## Deliverable

`script/verify-omo-ai-payload.mjs` - a sibling of `script/verify-npm-payload.mjs`
using the same `npm pack --dry-run --json` technique (maxBuffer 64 MB,
--ignore-scripts). Runs in `packages/omo-native` and enforces:

- INCLUDES (whitelist): bin/omo.js, bin/omo-agent-toolkit.js,
  plugin/package.json, plugin/extensions/omo.js, >=18 skill files
  (plugin/skills/*/SKILL.md), plugin/runtime/lsp-daemon/dist/cli.js,
  plugin/runtime/ast-grep-mcp/cli.js, plugin/runtime/agent-toolkit/cli.js,
  plugin/runtime/agent-toolkit/ulw-loop/cli.js,
  plugin/runtime/agent-toolkit/omo-agent-toolkit,
  plugin/runtime/agent-toolkit/omo-agent-toolkit.cmd
- EXCLUDES (blacklist): any path matching node_modules/, src/, test/, *.test.*
- SIZE: total unpacked size < 30 MB
- Exit 1 naming every offender/missing artifact
