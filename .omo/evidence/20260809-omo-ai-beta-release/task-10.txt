Commit subject: ci: PR-level omo-ai payload publishability check

## Deliverable

New job `omo-ai-payload-check` in `.github/workflows/ci.yml`, placed between
`build` and `auto-commit-schema`. Mirrors sibling job conventions (test,
typecheck, codex-compatibility, senpi-compatibility): checkout@v5,
setup-node@v6 (node 24), oven-sh/setup-bun@v2 (bun 1.3.12), cache@v5,
job summary step via write-job-summary.sh.

Steps:
  1. actions/checkout@v5
  2. actions/setup-node@v6 (node 24)
  3. oven-sh/setup-bun@v2 (bun 1.3.12)
  4. actions/cache@v5 (bun install cache)
  5. Install dependencies: bun install --frozen-lockfile
  6. Build omo-native: bun run build:omo-native
  7. Verify omo-ai payload: node script/verify-omo-ai-payload.mjs
  8. Dry-run publish: npm publish --dry-run --ignore-scripts --tag beta
     (working-directory: packages/omo-native)
  9. Write job summary (if: always())

No npm auth is configured. The --dry-run flag ensures the job never
publishes for real.

The new job is wired into the `needs` arrays of both `auto-commit-schema`
and `draft-release`:

  needs: [test, typecheck, codex-compatibility, senpi-compatibility, build, omo-ai-payload-check]
