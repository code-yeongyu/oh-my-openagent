`app-server-plugin-expect-stop-20260803.txt`.

CORRECTION - 2026-08-03

An earlier revision of this file listed a third case invoked as
`EXPECT=stop ... app-server-drive.sh --plugin` and claimed that run "required
`stop` as an expected hook". That claim was wrong and has been removed.

`app-server-drive.sh` sets `MODE="--self-test"; PROMPT=""; EXPECT=""; KEEP=0`
at line 57 and populates `EXPECT` only from the `--expect` flag at line 62,
falling back to `sessionStart,userPromptSubmit` at line 72. An exported
`EXPECT` environment variable is therefore discarded, so that run asserted only
the two default events and could not have enforced `stop`.

The case has been rerun correctly with `--plugin --expect stop`. The exact
captured output is committed as
`app-server-plugin-expect-stop-20260803.raw.txt`, summarized in
`app-server-plugin-expect-stop-20260803.txt`. Thanks to the review for catching
this; the conclusion now rests on an invocation that actually enforces the
assertion.
