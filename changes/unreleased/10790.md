### Security

- Computer use: outside full access, clicks, typing, key presses, scrolling, drags, pointer moves and holds aimed at the desktop or a display now need the human-confirmed foreground control grant, because they land on your real pointer and frontmost app. Without it they fail with `ControlRequired` and nothing is sent. Background input to one window still needs no approval, and full access keeps working with no prompt, headless runs included ([#10788](https://github.com/code-yeongyu/oh-my-openagent/issues/10788), [#10790](https://github.com/code-yeongyu/oh-my-openagent/pull/10790)).
- Computer use: the macOS background canary no longer moves your pointer back if you moved it while the canary ran, and a stopped session now stays stopped when the desktop engine restarts ([#10788](https://github.com/code-yeongyu/oh-my-openagent/issues/10788), [#10790](https://github.com/code-yeongyu/oh-my-openagent/pull/10790)).
