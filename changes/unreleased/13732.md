### Fixed

- On Linux, the computer tool's `desktop.elementAt(x, y)` now returns the element under the point, such as a GTK window's Press button, instead of the window's untitled root `filler` at every point. ([#13732](https://github.com/code-yeongyu/oh-my-openagent/pull/13732), fixes [#13296](https://github.com/code-yeongyu/oh-my-openagent/issues/13296))
- With real hit-test answers, the check that an element is not covered before an accessibility action now works on Linux too: another element of the same window across the target's centre refuses the action with `occluded`, as on macOS. The target's own descendants, such as a list row wider than the list's viewport, never count as covering it, on any platform where the backend can compare elements. ([#13732](https://github.com/code-yeongyu/oh-my-openagent/pull/13732))
