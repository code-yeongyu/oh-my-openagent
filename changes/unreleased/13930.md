### Security

- Computer use v3: the engine daemon draws an authority boundary around attach hosts. A peer the host registered is refused every host-only authority method, with one audit line written before the refusal leaves; its own calls run on a session of its own as issuer `remote`, never as the local host; and `--serve --start-stopped` starts with every session suspended. Nothing user-visible changes yet; the existing desktop engine is untouched. ([#13930](https://github.com/code-yeongyu/oh-my-openagent/pull/13930))
