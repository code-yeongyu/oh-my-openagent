**Two omo processes started with different `HOME` values no longer refresh the same OmO sign-in at once.** The credential lock was taken under `$HOME`, while the sign-in it guards (the Secret Service item on Linux) belongs to the OS account. A process launched with a scratch `HOME` therefore rotated the same refresh token as every other omo process, and the service revoked the sign-in and the device for refresh-token reuse. The lock now lives in the OS account's home on Linux, so those processes take turns. ([#12979](https://github.com/code-yeongyu/oh-my-openagent/pull/12979))
