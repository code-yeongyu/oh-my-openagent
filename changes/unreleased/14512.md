### Added

- The omo SDK's `config` namespace can now show where a setting comes from and catch risky routing changes before you make them. ([#14512](https://github.com/code-yeongyu/oh-my-openagent/pull/14512), part of [#14366](https://github.com/code-yeongyu/oh-my-openagent/issues/14366))
  - `config.status()` also reports the engine's own settings: whether model fallback is on, the fallback chains, and what compaction actually does. Background summaries stay on unless `compaction.speculativeEnabled` is false, even with `compaction.enabled: false` (senpi#7074), and `speculativeFraction` has no effect (senpi#7067). Each of these states the engine version it was read at.
  - `config.explain({ path })` names the file and layer that set a value, with project over user. For a path that does not exist it answers `unknown_path` with the nearest valid paths.
  - `config.check({ edits? })` lists policy findings for the current files, or for the files as the edits would leave them, without writing anything.
  - `config.modelSwaps({ session? })` lists the engine's fallback model swaps from a session record, with time, from and to, whether a fallback window is still open, and turns per model.
