### Fixed

- A workflow (DAG) run no longer loses its queued nodes when the session is quit and reopened, or when it is stopped and then resumed. Recovery used to fail every node whose child was still waiting for a concurrency slot as `resume_task_orphaned`. Only the first batch then finished and every dependent node was skipped. Now a child that never launched is retired and its node is re-admitted, and a child still queued in this session is picked up again. ([#12109](https://github.com/code-yeongyu/oh-my-openagent/pull/12109), fixes [#12107](https://github.com/code-yeongyu/oh-my-openagent/issues/12107))
