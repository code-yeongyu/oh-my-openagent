### Added

- `omo.json` accepts an opt-in `atomic` block (`enabled`, `binary_path`, `context`, `recording`) for the upcoming Atomic CLI integration. It is off by default and nothing uses it yet. Only the user config (`~/.omo/omo.json`, including its `[harness]` and profile blocks) can enable it, choose the executable, or set recording; a project config can only lower the context limits or turn context off, and every other `atomic` key it sets is ignored with a warning naming the file and key.
