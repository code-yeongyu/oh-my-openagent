### Changed

- The standalone `omo` binary starts about 4x faster on Linux and 6x faster on macOS: release binaries now carry Bun's bytecode cache, so a launch no longer parses the whole bundled program first (`omo --version` 880 ms -> 202 ms on Linux x64, 214 ms -> 33 ms on Apple silicon). Each binary is about 43 MB larger, and the per-binary size budget rises from 210 MiB to 260 MiB.
