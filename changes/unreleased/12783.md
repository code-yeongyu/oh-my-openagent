**Memory retention no longer evaluates its completion-record guard twice per record.** The completion sweep now reads the guard once and keeps or removes the record on that single answer, and the retention tests check their own preconditions instead of asserting them away. No change to what retention keeps or removes. ([#12783](https://github.com/code-yeongyu/oh-my-openagent/pull/12783), follow-up to [#12532](https://github.com/code-yeongyu/oh-my-openagent/pull/12532))

**The standalone `omo` binary's `omo doctor` reports memory runtime size again, like the npm install.** Each memory identity's runtime size against its cap and the total across identities are printed by both distributions, so binary/npm doctor parity holds ([#12785](https://github.com/code-yeongyu/oh-my-openagent/issues/12785)).
