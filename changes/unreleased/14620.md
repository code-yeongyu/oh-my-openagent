### Fixed

- The shipped thread SDK (`plugin/runtime/thread-sdk`) now reads the account's other devices by default. A script that opened it without passing `remote` (a connector, a lane monitor) saw only this device's sessions, so `list({ all_scope: true })` listed no other device and a live thread on another device read as `not_found`. A `remote` the caller passes still wins; the account surface loads the device-service client and the alias registry only on the first call that needs another device. ([#14620](https://github.com/code-yeongyu/oh-my-openagent/pull/14620), fixes [#14616](https://github.com/code-yeongyu/oh-my-openagent/issues/14616))
