### Fixed

- A reflection or dream run no longer fails completion validation when the memory maintenance pass writes its `omo.maintenanceAt` stamp to the memory repo's git config while the run is in flight: the worktree snapshot comparison filters that exact key from `.git/config` on both sides, so omo's own bookkeeping no longer reads as a tampered worktree. Section headers are parsed the way git does (a header may carry a key on the same line), and every other config byte - the other `[omo]` keys included - still has to match. Follow-up to [#12191](https://github.com/code-yeongyu/oh-my-openagent/pull/12191), which moved the maintenance stamp out of the config. ([#9962](https://github.com/code-yeongyu/oh-my-openagent/issues/9962))
