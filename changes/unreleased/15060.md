### Added

- The `github` skill ships as a built-in. It is the route for any GitHub work (pull requests, waiting for CI, issues, Actions runs and logs, releases, search, repository setup, raw REST/GraphQL) through a typed Bun SDK for eval cells plus a CLI and an MCP server, instead of the gh CLI, `gh api` or a browser. ([#15060](https://github.com/code-yeongyu/oh-my-openagent/pull/15060), refs [#15044](https://github.com/code-yeongyu/oh-my-openagent/issues/15044))

### Fixed

- PR screenshot uploads documented by the `github` skill run as one in-page script that returns only the user-attachments URL, so no token, cookie or form field reaches tool output. ([#15060](https://github.com/code-yeongyu/oh-my-openagent/pull/15060), fixes [#15053](https://github.com/code-yeongyu/oh-my-openagent/issues/15053))
- `auth.status` in the `github` skill reports `injected` for a token provider passed to `createClient({ token })` instead of claiming the gh login. ([#15060](https://github.com/code-yeongyu/oh-my-openagent/pull/15060))
