### Fixed

- `omo remote send` that waits on a turn now settles inside a bound: `--timeout <seconds>` (1..600, default 120) answers a typed `{kind:"timeout", waited_ms, ...}` JSON value instead of hanging when the turn never settles; a session that ends before settling answers `{kind:"session_ended", end}` as one JSON value under `--json` (both were a silent hang or stderr-only), and the queued notice rides that same JSON value instead of being dropped (#13425).
