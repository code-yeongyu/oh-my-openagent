### Fixed

- `omo remote`'s local-only verbs again reach the network only through this device's local API: the remote client no longer imports the code that opens this device's operator endpoint socket. `omo remote` hands it to the client and loads it only when needed, so `omo remote sessions` still lists this device's own sessions. A client built without it reports this device as unanswered in `sessions.list` and answers `unsupported` (`local_sessions`) for other session calls on this device. ([#13971](https://github.com/code-yeongyu/oh-my-openagent/pull/13971), fixes [#13968](https://github.com/code-yeongyu/oh-my-openagent/issues/13968))
