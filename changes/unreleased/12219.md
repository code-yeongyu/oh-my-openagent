### Known issues

- Engine TLS trust v1: distrusted intermediate certificates under an allowed root are not yet blocked; tracked upstream. The compiled engine now has tests for every TLS path (global `fetch`, `Bun.fetch`, a saved `fetch`, a Worker `fetch`, `node:https` and `WebSocket`): a root outside the selected set or denied by the OS fails on all of them, a store intermediate is used only when its usage allows server authentication and it is not denied, and a test named `limitation-pin:` records that a denied intermediate the server itself presents under an allowed root is still accepted. ([#12219](https://github.com/code-yeongyu/oh-my-openagent/pull/12219), part of [#10762](https://github.com/code-yeongyu/oh-my-openagent/issues/10762))
