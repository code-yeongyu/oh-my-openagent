### Changed

- **A subagent's processes are scoped to its own session, so one session can no longer kill another session's workers (#6123).** Every `bash` command now runs with `OMO_PROCESS_SCOPE=<session>` exported, so the whole process tree a session starts (Playwright workers, dev servers, test runners) carries its owning session. Before a `kill`, `pkill`, or `killall` target is signalled, the guard reads the target's tag: a process owned by a different session blocks the command instead of being killed as if it were this session's timed-out child, and pattern kills are resolved against the live process table so one foreign match blocks the whole command. Untagged processes (started outside OmO) stay killable; `OMO_PROCESS_ISOLATION=off` opts a single command out, and `--omo-senpi-process-isolation-disabled` disables the component. Tag reads use `/proc` on Linux and `ps -E` on macOS; Windows has no readable per-process environment, so the guard fails open there rather than blocking on missing evidence, and commands that reach `kill` through an indirection the scanner does not model (`bash -c`, `xargs kill`, command substitution) are allowed.
