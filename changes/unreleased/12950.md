**Code-review, QA and gate-review task agents can no longer write over the live OmO install.** They now always run as their own process inside a sandbox (bubblewrap on Linux, sandbox-exec on macOS) that blocks writes to `~/.omo` code and config while leaving engine state writable; a pre-launch check proves the block works, and where no sandbox is available they refuse to start instead of running unprotected (senpi#6287).
