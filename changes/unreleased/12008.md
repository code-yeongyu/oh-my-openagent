**Desktop memory sync now uses the desktop's account instead of the CLI's.** An engine the desktop launches claims its private `memory-sync` channel at startup, answers with the bootstrap handshake and resolves the sync account through the desktop. A launch without that channel still uses the account `omo login` keeps, and a declared channel that fails reports memory sync as unavailable rather than falling back to CLI credentials. Windows keeps refusing the channel until its pipe-pair path lands. ([#12008](https://github.com/code-yeongyu/oh-my-openagent/pull/12008))
