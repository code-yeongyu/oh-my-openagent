### Added

- Computer use v3: route tables as data, `desktop.diagnose` and recording. A table of exact toolkit keys (bundle id, WM_CLASS, window class) picks each target's input route, with user keys added the same way. A table that fails its load test refuses the session open and points at the bad entry. `desktop.diagnose` reads the permissions, the session state and the lock policy without ever prompting; each denied permission names its settings pane, and an OS backend can add its own doctor checks. Recording is off by default; when on, it writes cursor rows at 60 Hz, none while secure input is on, and reports the video half inactive when no encoder is present. Nothing user-visible changes yet; the existing desktop engine is untouched. ([#13362](https://github.com/code-yeongyu/oh-my-openagent/pull/13362))
