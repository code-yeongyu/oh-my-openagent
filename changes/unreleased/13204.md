### Changed
- Contributors: knip's configuration now lives with the code it describes. The root `knip.ts` composes `knip.base.jsonc` (global settings) with one `knip.workspace.jsonc` per directory (a workspace's config, the root entries under that directory and its pre-existing export rows), so two PRs for two packages no longer conflict on one shared `knip.jsonc`. The composed configuration is identical to the old file, and knip reports the same results. Add or change knip config in your own directory's `knip.workspace.jsonc`. ([#13204](https://github.com/code-yeongyu/oh-my-openagent/pull/13204), fixes #13200)
