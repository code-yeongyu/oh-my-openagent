### Changed

- **The frontend skill picks a layout pattern for every layout change, and visual-qa checks it.** Any change to a screen's structure (a new region, panel, split, list, sticky bar or scroll container) now fetches the matching StyleGallery pattern and writes one `Layout:` line in `DESIGN.md` naming the pattern, the element that owns the scroll and the pattern's anti-patterns, including in a project that already has a `DESIGN.md`. visual-qa's new A12 item checks the build against that line, with a probe for the element that really scrolls. Apple HIG hit targets, hierarchy, states, keyboard and motion are now rules for the first draft in the frontend skill, not only items in the QA checklist. ([#10684](https://github.com/code-yeongyu/oh-my-openagent/issues/10684), [#10685](https://github.com/code-yeongyu/oh-my-openagent/pull/10685))
