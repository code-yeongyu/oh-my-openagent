### Fixed

- A task child started through a launcher that runs the engine as its own child process (an npm shim or a wrapper script) no longer fails its start as a stall while the engine boots. The startup bound now follows the CPU of the launcher's whole process tree on Linux, macOS and Windows. ([#14827](https://github.com/code-yeongyu/oh-my-openagent/pull/14827), fixes [#14820](https://github.com/code-yeongyu/oh-my-openagent/issues/14820))
