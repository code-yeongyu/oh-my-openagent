### Added

- OmO Native asks a first-run consent question (an interactive `ui.confirm` dialog naming both destinations and every opt-out); the answer is persisted once in a 0600 marker next to the install id, and telemetry is allowed only when it reads `accepted`. A run with no dialog (headless, print, RPC, hosted engines) asks nothing, writes nothing, and counts as not consented, so nothing leaves such a run. The consent-gate writer audit registers the new marker site. This is wave B of #14920 and intentionally changes the fresh-install behavior from "on after an informational notice" to "on after an explicit allow"; it is held for the default-change decision. ([#14920](https://github.com/code-yeongyu/oh-my-openagent/issues/14920))
