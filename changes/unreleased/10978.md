### Fixed

**Keep credentials out of migration and doctor reports.** Configuration migration conflicts now identify key paths without printing legacy or retained values. Text and JSON migration previews preserve the configuration's object and array shape but redact every value; the target path shows where to inspect the full configuration. Doctor keeps model and provider identifiers while omitting arbitrary options, URL credentials, raw parser excerpts, and received schema values. Migration journals and backup files are owner-only, and new backup directories are private. ([#10978](https://github.com/code-yeongyu/oh-my-openagent/pull/10978))

Existing live config modes are preserved; new config files, journals and regular backup files are 0600. Only backup directories are created as 0700; live user/project `.omo` directories retain normal permissions. Migrating a legacy symlink does not chmod its target. Reports intentionally retain object key names and paths: a credential stored as a key rather than a value remains visible.
