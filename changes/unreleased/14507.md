### Added

- The OpenCode plugin's background-task and model-fallback toasts are now available in Korean. Set `"i18n": { "locale": "ko" }` or run with a `ko_*` `LANG`; English stays the default and keys without a Korean override fall back to English. ([#14507](https://github.com/code-yeongyu/oh-my-openagent/pull/14507))
