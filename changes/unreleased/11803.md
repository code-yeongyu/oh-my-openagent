### Added

- Physical Escape stops macOS computer use while it takes the foreground or holds a user-approved control grant. It cancels the active call, releases control, and blocks further computer runs, capabilities, and CUA actions until the user's next message actually starts. Synthetic or agent input, queued messages, and session-control deliveries do not resume it. Automatic full-access consent alone does not arm Escape between operations. The existing physical stop chord is unchanged. ([#11803](https://github.com/code-yeongyu/oh-my-openagent/pull/11803), part of [#11464](https://github.com/code-yeongyu/oh-my-openagent/issues/11464) and [#11459](https://github.com/code-yeongyu/oh-my-openagent/issues/11459))
