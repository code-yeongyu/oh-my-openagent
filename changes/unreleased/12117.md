### Fixed

- The OTLP sender's spool-loss report `omo.client_dropped` now names its cause `omo.dropped.cause` instead of `omo.dropped.reason`, and the published telemetry artifact declares the event (a bounded integer count and a closed cause enum). Previously the collector refused every such record, so client-side telemetry loss was never counted. Ships after the collector pin that accepts it.
