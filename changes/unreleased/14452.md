### Fixed

- `thread_read` of a thread with no live host scans at most 1 MiB from the end of its session file, with the window fixed before opening it. If a partial tail contains no displayable message, even when it ends in session bookkeeping, pass `error.details.next_cursor` as `cursor` to scan forward in bounded pages past oversized records. The tool, SDK, and `omo thread read` reject malformed cursors before looking up the thread. Status reads only file metadata. Tail cursors preserve the requested window and skipped-line counts, and reject file replacement or changes to the window content and parent links. ([#14452](https://github.com/code-yeongyu/oh-my-openagent/pull/14452))
