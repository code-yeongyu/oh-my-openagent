### Fixed

- `thread_read` of a thread with no live host scans at most 1 MiB from the end of its session file, with the window fixed before opening it. If no complete entry fits, pass `error.details.next_cursor` as `cursor` to scan forward in bounded pages past oversized records. Malformed cursors are rejected before file access. Status reads only file metadata. Tail cursors preserve the requested window and skipped-line counts, and reject file replacement or changes to the window content and parent links. ([#14452](https://github.com/code-yeongyu/oh-my-openagent/pull/14452))
