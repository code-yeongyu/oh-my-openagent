### Added

- Every interactive `omo` start now sets up this device's OmO device service in the background once you are signed in, so your other signed-in devices can see and command its sessions. It never delays the start and speaks up only when it stops on something you can fix. Turn it off with `"device_service": { "enabled": false }` in omo.json, or keep it and stop other devices from controlling this one with `omo remote control off` (`omo remote control` shows the setting). ([#12257](https://github.com/code-yeongyu/oh-my-openagent/pull/12257), part of [#12051](https://github.com/code-yeongyu/oh-my-openagent/issues/12051))
