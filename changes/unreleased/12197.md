### Fixed

- The builtin `dev-browser` skill's port-release step now behaves the same on macOS and Linux when it is rendered with no grace window: it sends SIGTERM and returns without waiting or sending SIGKILL. macOS's `seq 0` used to make it wait 0.2 s and then SIGKILL. The default 5 s step in the skill is unchanged. Its zero-grace test now waits for the port holder to exit before asserting, so it no longer fails on a loaded host. ([#12197](https://github.com/code-yeongyu/oh-my-openagent/pull/12197), fixes [#12196](https://github.com/code-yeongyu/oh-my-openagent/issues/12196))
