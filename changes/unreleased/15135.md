### Fixed

- Cancelling a workflow run stops every child the run owns, including a finished node's child that resumed on its own and a child of a node an amendment removed. If a child cannot be stopped yet, the run reports that its stop is still owed, refuses to be amended, retried or re-entered, and a repeated cancel finishes the job. A finished child can no longer reopen on its own once its node moved to a newer attempt, its node was removed, or its run is being cancelled or has ended. A re-run, retried, amended or recovered node never adopts, reuses or runs beside a child left over from an earlier attempt (#11381, #9993).

## 2026-11-27 - DAG cancel stops every owned child; a superseded attempt is never adopted (#11381)

A settled child runs again only through the self-resume reopen. For a DAG-owned record the manager now asks an owner fence (`ownerResumeFence`, registered by the DAG runtime) inside the same record mutation. The fence decides from the run's durable checkpoint: the claim must be current by one classifier (`owned-attempt.ts`), shared by admission, the re-entry sweep and recovery, and the run must not be settled or cancelling. A refused run is torn down and recorded as `task_self_resume_refused`.

Run cancel drains the run's live children to a fixed point, scanned by run (removed nodes included). An attached child keeps its deferred in-process teardown; any other is cancelled outright. A child still live fails the cancel with `DagRunChildrenLiveError` after the run is journaled cancelled.

The obligation is derived, not stored: a terminal run that still owns a live child carries `outstandingStop` in its snapshot and wait result. Amend, retry and re-entry refuse with `run_still_active` until a repeated cancel drains it.

No node is admitted while a superseded or removed-node child is live: the ready nodes fail with the retryable `stale_attempt_alive`, and node retry admits them once the stop lands. The owned start refuses start and reuse while any other live claim exists. Recovery stops stale siblings before it returns, attaches or folds a current claim. The record store keeps `owner.execAttempt`. Port of #11385.
