## 2026-11-27 - DAG cancel stops every owned child; a superseded attempt is never adopted (#11381)

Run cancel issues a cancel for each live child the run owns, not only the ones attached to the current scheduler. An owned start that finds a live child of an earlier attempt answers `owner_superseded` and the stale child is cancelled instead of adopted. Port of #11385.
