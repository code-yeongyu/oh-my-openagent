### Added

- thread: `thread_close` takes `mine` and refuses a thread the calling session did not open with `not_creator`, closing nothing; `thread_create` takes `metadata`, one JSON value of at most 4096 bytes stored with the thread and shown by `thread_read` (a larger one is refused `metadata_too_large` and nothing is created); the SDK adds `threads.handOver` and `threads.setMetadata`, recorded on every device that holds the thread and naming any it did not reach (#15221)
