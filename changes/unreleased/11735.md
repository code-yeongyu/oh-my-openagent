### Changed

- Computer use on macOS: `el.press()` on an element with no press action is refused before anything is sent and points at `el.click()` (the available actions are named); a UIKit (Catalyst/iPad) element is scrolled into view before it is pressed; an element that stands for its own window, such as Finder's inline rename field, resolves instead of failing; an empty chord (`el.press("")`) is refused before the element is focused, and a chord-less `el.press()` given options throws instead of running a background press. ([#11735](https://github.com/code-yeongyu/oh-my-openagent/pull/11735), part of [#11462](https://github.com/code-yeongyu/oh-my-openagent/issues/11462))
