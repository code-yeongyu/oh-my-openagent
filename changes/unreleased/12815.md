**A timed-out git's diagnostics record keeps the process table on hosts running thousands of processes.** With `OMO_GIT_TIMEOUT_DIAGNOSTICS_DIR` set, the memory git timeout snapshot (`ps` on macOS/Linux, PowerShell on Windows) now writes to a temporary file that is read back and deleted, instead of a pipe capped at 1 MiB, so a large process table no longer turns the record into `process snapshot failed: spawnSync ps ENOBUFS`. The snapshot keeps its 15 s timeout, and only a timed-out snapshot is still excused by the timeout test. ([#12801](https://github.com/code-yeongyu/oh-my-openagent/issues/12801))
