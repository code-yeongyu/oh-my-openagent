### Changed

- The thread SDK and `omo thread` resolve every address (`read`, `send`, `bind`, `rebind`, `bindings --session`, `report`, `locate`) through the shared thread address module, so they accept the same forms as the thread tools, `<device>/<thread>` and `here/<thread>` included.

### Fixed

- `bind`, `rebind`, `bindings --session`, `report` and a bound send answer `unsupported` with `details.reason: "session_on_other_device"` for a session another device holds, where they answered a bare `not_found`.

## 2026-11-19 - The thread SDK resolves through the address module (#14322)
