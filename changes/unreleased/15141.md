### Added

- OmO Native can give workers reusable nicknames through `task.nicknames` in
  `omo.json`. Nicknames appear in task results, completion notices, the live
  task widget, and team message notifications. Users can refer to workers by
  nickname in chat, and coordinators can use those nicknames in task tools
  for their own session. Nicknames are off by default and do not replace
  task names or IDs.

## 2026-11-26 - Opt-in worker nicknames (#15141)

Set `task.nicknames` in `omo.json` to label workers in the terminal. Use a
worker's nickname to read, steer, or cancel it in the current session.

## 2026-11-26 - Worker nickname pools and repeat numbering (#15141)

Pools rotate across sessions sharing an agent home. Repeat numbering is
tracked within each root session. An assigned label survives model retries
and session reopen. Task tools accept equivalent repeat spellings regardless
of the configured display style.
