**A subagent whose model takes more than 90 s to start answering is no longer aborted by runtime fallback.** With `runtime_fallback` enabled, the first-prompt watchdog cut every subagent that showed no progress within a fixed 90 s and re-prompted the fallback model, so reasoning-heavy models that legitimately think longer before their first token were killed and their prompt was sent twice. The watchdog now waits 300 s, the same stream-start bound the engines use, and `runtime_fallback.first_prompt_timeout_seconds` sets it (`0` disables it).
