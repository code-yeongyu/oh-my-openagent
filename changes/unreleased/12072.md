## 2026-11-01 - Guard timer unref in host heartbeat teardown (#12072)

`startHostHeartbeat` routes its schedule, unresponsive-deadline and close timers through a guarded unref (same typeof-check + try/catch-swallow semantics as the parent-wake notifier's helper, kept local because this package must not import `packages/omo-opencode`), so a throwing `unref` never escapes teardown. A fake-clock test drives a failing probe through running, unresponsive and terminal-pending into `close()` with every timer's `unref` throwing.
