### Fixed

- On Windows, a memory lock whose dead owner's record cannot be deleted for longer than the wait (for example, an ACL that denies delete) no longer reports a bare "Lock is held". The contention error now names the refusal in its message and carries the original `EPERM`/`EACCES` error as its `cause`, while a short-lived sharing hold is still retried. ([#13205](https://github.com/code-yeongyu/oh-my-openagent/issues/13205))
