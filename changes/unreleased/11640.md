### Fixed

- The SessionEnd cleanup launcher (`script/agent/cleanup-hook.sh`) accepted only `/tmp`, `/private/tmp` and `/var/folders` as log directories and silently rewrote anything else to `/tmp`, so on a host whose `TMPDIR` lives elsewhere the log was not where the caller expected it. It now accepts any absolute, existing temp directory outside the project tree, decides containment by directory identity (device and inode of every ancestor) rather than by comparing path strings, so a symlinked `TMPDIR`, a symlinked project path, an unnormalised `//` or `/./` segment and a case-variant name on a case-insensitive filesystem all resolve to the same answer, the stat flavour behind that comparison is probed rather than guessed from the platform, so a GNU `stat` early on `PATH` cannot silently disable the check, and the fallback location is checked the same way and creates no temporary directory of its own (when no temp directory outside the project exists, the hook reports that and stops logging), reports every rejected `TMPDIR` on stderr instead of substituting silently, and exposes the resolved path through `--print-log-file` so callers read one shared resolution (#10735).
- The first-party source scans use POSIX extended regular expressions instead of `git grep -P`, which exits 128 on a git built without USE_LIBPCRE (#10735).
