- On OpenCode 1.x, an auto compaction that follows an already finished answer no longer starts an unrequested model turn. The `experimental.compaction.autocontinue` handler now vetoes OpenCode's synthetic "Continue if you have next steps..." message when the turn before the compaction finished normally (no tool calls, no error) and no todos are open, so the session goes idle as it would have without the compaction. Interrupted work, open todos, and unreadable sessions still continue as before. Thanks to @mradwankhalil for the report and reproduction. ([#12121](https://github.com/code-yeongyu/oh-my-openagent/pull/12121), fixes [#12118](https://github.com/code-yeongyu/oh-my-openagent/issues/12118))
