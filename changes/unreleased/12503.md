### Added

- Configure the desktop engine environment directly with `computer.env` in
  `omo.jsonc`. String values override inherited engine-child variables and
  `null` removes them, so a terminal session can connect to an existing X11 or
  Wayland desktop without changing shell exports. Doctor uses the same
  environment as the live computer tool.
