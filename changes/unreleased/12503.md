### Added

- Configure the desktop engine environment with user-only `computer.env` in
  `~/.omo/omo.jsonc`, including its Native and profile blocks. Only `DISPLAY`,
  `XAUTHORITY`, `WAYLAND_DISPLAY` and `XDG_RUNTIME_DIR` are accepted; project
  settings and other keys are dropped with configuration warnings.
  String values override inherited engine-child variables and
  `null` removes them, so a terminal session can connect to an existing X11 or
  Wayland desktop without changing shell exports. Doctor uses the same
  environment as the live computer tool.
