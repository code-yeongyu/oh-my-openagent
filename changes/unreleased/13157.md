### Fixed
- Memory sync settings: when sync cannot read its status, OmO now records WHY. The engine's status path kept one sentence, "Memory sync authority is unavailable.", for every cause, with nothing in the log, so a report of that screen could not be acted on. Each cause now carries a code (`no_account`, `account_aborted`, `account_not_current`, `status_read_failed`, plus `legacy_source` where a source answers with no operation-capable account), together with the step that failed, and it is logged once when it starts rather than on every status poll. The device and pending-request reads and the enable and approve operations, which ended in the same sentence, now carry a code too (`operation_failed` for an unexpected error) and log it with the error; the reads, which the desktop also polls, log once per cause. The message a person sees is unchanged. ([#13157](https://github.com/code-yeongyu/oh-my-openagent/pull/13157))
