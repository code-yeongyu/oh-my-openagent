### Fixed
- Memory sync settings: when sync cannot read its status, OmO now records WHY. The engine's status path kept one sentence, "Memory sync authority is unavailable.", for every cause, with nothing in the log, so a report of that screen could not be acted on. Each cause now carries a code (`no_account`, `account_aborted`, `account_not_current`, `status_read_failed`, plus `legacy_source` where a source answers with no operation-capable account), and it is logged once when it starts rather than on every status poll. The message a person sees is unchanged. ([#13157](https://github.com/code-yeongyu/oh-my-openagent/pull/13157))
