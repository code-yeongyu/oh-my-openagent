**The telemetry collector now uses a private key for each installation.** Consented sessions register once with the collector and keep the install-bound key in a local 0600 cache; no shared ingest key is baked into the client. Registration failures disable only the collector branch for that process, rate-limit backoff persists across runs, and a rejected key is discarded for the next run. Explicit environment keys still take precedence, and PostHog delivery and opt-out rules are preserved. ([#11734](https://github.com/code-yeongyu/oh-my-openagent/pull/11734))

**The memory tool can now repair a note that has no frontmatter.** `update_description` on a frontmatter-less note writes a frontmatter block holding only the new description and keeps the body byte-for-byte, instead of refusing with the same error as every other edit; the other edits still refuse, and their refusal now names `update_description` as the way to add frontmatter. Thanks to @surlymochan. ([#11699](https://github.com/code-yeongyu/oh-my-openagent/pull/11699), fixes [#11035](https://github.com/code-yeongyu/oh-my-openagent/issues/11035))

**OmO's entry bundle no longer carries the memory name-listing renderer.** The `<external_projection>` name folding, directory grouping and budget fit load from the recall-store sidecar the first time a memory block with non-system files is compiled, shrinking `omo.js` by 6,719 bytes. Compiled memory blocks are byte-identical. ([#11559](https://github.com/code-yeongyu/oh-my-openagent/pull/11559))

**Opening a session no longer hangs on a Mac whose `/home` automounter is stuck.** With a home folder outside `/Users` (the desktop app's own home, QA or custom homes), the telemetry check resolved `/home`. When macOS's `auto_home` automounter stopped answering, that call never returned: the engine stopped responding and every request timed out. The check, and every place that resolves a path a tool or the model hands in, now treats `/home` and `/net` as plain text on macOS. ([#11546](https://github.com/code-yeongyu/oh-my-openagent/pull/11546), fixes [#11545](https://github.com/code-yeongyu/oh-my-openagent/issues/11545))

**OmO stops sending the schemas of rarely used tools on every request.** The six LSP tools, `workpool` and `task_cancel` now ride in the tool-search catalog and activate on their first by-name call, so a session that never uses them no longer pays for their schemas in each prompt; calling one by name still works exactly as before. ([#11457](https://github.com/code-yeongyu/oh-my-openagent/pull/11457))

**Feedback omits telemetry identifiers when telemetry is disabled.** Preparing a bug report or feedback draft now applies the native telemetry gate, including automated-run suppression and adapter opt-outs. Intentional reports remain available, existing feedback-specific opt-outs remain honored, and a deliberate automation opt-in still permits identifiers. Thanks to @MoerAI. ([#11421](https://github.com/code-yeongyu/oh-my-openagent/pull/11421))

**The model capabilities cache is rewritten only when the catalog changed.** Each startup refresh fetched the models.dev catalog and rewrote `model-capabilities.json`, about 1.5 MB, even when the catalog was the same as the one on disk. The refresh now compares the fetched catalog with the file, ignoring the fetch timestamp, and skips the write when they match. `refresh-model-capabilities` follows the same rule, so after an unchanged refresh the file keeps the timestamp of the fetch that last changed it. Thanks to @mradwankhalil. ([#10119](https://github.com/code-yeongyu/oh-my-openagent/pull/10119))

**A `google/antigravity-gemini-3.1-pro` model in a fallback chain keeps its id.** Model resolution rewrote `gemini-3.1-pro` to `gemini-3.1-pro-preview` for the `google`, `github-copilot` and `vercel` providers without skipping the `antigravity-` form, so a user chain naming `antigravity-gemini-3.1-pro` could resolve to `antigravity-gemini-3.1-pro-preview`, an id Antigravity does not serve. The rewrite now skips it, the same way it already skipped `antigravity-gemini-3-flash`. A plain `gemini-3.1-pro` still becomes `gemini-3.1-pro-preview`. Thanks to @cynkai. ([#8499](https://github.com/code-yeongyu/oh-my-openagent/issues/8499), [#8842](https://github.com/code-yeongyu/oh-my-openagent/pull/8842))

`@oh-my-opencode/utils/path-containment` gains `isDarwinAutomountTriggerPath(path, { platform, homeDir })`.
