**A Git-marketplace install no longer reinstalls LazyCodex at every session start.** When an earlier local install left a cache-root marketplace manifest naming a pruned version, auto-update read it as a missing payload and started the marketplace repair each session, even though Codex reads a Git marketplace from its own clone; the check now applies only when the marketplace is local.
