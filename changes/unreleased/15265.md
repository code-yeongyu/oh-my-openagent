### Added

- Computer use v3: the SP-M probe for macOS private symbols (`crates/omo-computer-backend-macos/probes/probe-sp-m.ts`) and its ledger `macos-spi.tsv`, one row per question per condition on macOS 15 and 26. Every row is `UNMEASURED` until a macOS 26 host with a QA account and a macOS 15 host exist; nothing user-visible changes. ([#13144](https://github.com/code-yeongyu/oh-my-openagent/pull/13144))
- Computer use: a probe ledger records what a GitHub-hosted macOS 15 and 26 runner allows for a binary we build ourselves. Accessibility reads, window capture, a listen-only event tap and a run-time permission grant work there; pid-routed clicks do not, so the live macOS checks for pull requests will run on owned macOS guests. ([#13227](https://github.com/code-yeongyu/oh-my-openagent/pull/13227), part of [#13221](https://github.com/code-yeongyu/oh-my-openagent/issues/13221))
- **Computer use v3 on macOS: window capture and displays.** The macOS backend lists windows from its own window-server enumerator, keyed by window number, process id and process start time, so a reused process id never inherits an old window. Stills come from a persistent ScreenCaptureKit helper, so a window on another Space or behind other windows is captured without switching Spaces. A minimized window is reported as unavailable instead of captured. A display still excludes the engine's own windows, and a frame that cannot prove that exclusion is refused. Displays report their bounds in points and their backing scale. A low-rate preview stream runs only while a window is leased and someone is watching, and it never feeds the model. ([#13897](https://github.com/code-yeongyu/oh-my-openagent/pull/13897))
- **Computer use v3 on macOS: the accessibility backend.** macOS windows are read and driven through accessibility with one batched attribute read per element, under a 3-second deadline that returns a partial tree with its cuts named instead of hanging. Chromium and Electron trees are woken with a single role read and an observer-bounded wait, with no sleeps, and the attribute that reflows a whole app is never written. Settling waits on accessibility notifications and treats busy indicators, unloaded web areas and indeterminate progress as loading. A reference taken before an app relaunched is refused as stale with nothing sent. Presses fall back through press, confirm and pick; set-value reads its value back; menus are listed and selected without moving focus. Notification banners are fingerprinted, and reported unavailable when the notification process is absent. ([#13898](https://github.com/code-yeongyu/oh-my-openagent/pull/13898))
- Computer use: the eight-signal disturbance sentinel for macOS (`script/qa/computer/sentinel/`, workflow `computer-sentinel-macos.yml`) records whether an agent's input disturbed the person's session, with its review LOWs fixed. QA tooling only; nothing user-visible changes. ([#13242](https://github.com/code-yeongyu/oh-my-openagent/pull/13242), [#13290](https://github.com/code-yeongyu/oh-my-openagent/pull/13290))
