### Fixed

- Installing a newer omo no longer cuts running sessions off the thread tools. The binary that migrates the gateway store now records the oldest schema whose code can keep using it, and an older omo opens a newer store that meets it instead of answering `gateway_schema_too_new` on every call. Schemas 15 and 16 keep working with schema 14 code. A newer store that an older omo cannot use is still refused with `gateway_schema_too_new`, also by a session that opened the store before the newer omo migrated it. omo 5.1.81 and older do not read the floor, so this protects installs from this release on. ([#14622](https://github.com/code-yeongyu/oh-my-openagent/pull/14622), fixes [#14382](https://github.com/code-yeongyu/oh-my-openagent/issues/14382))
- A source build (omob) no longer migrates the gateway store in the shared agent dir that released sessions read; it answers `gateway_migration_failed` and names `OMO_CODING_AGENT_DIR` for an isolated agent dir.
