### Fixed

- A thread tool given the bare id of a closed thread on another device (`thread_create({ thread })`, `thread_send`, `thread_read`, the control tools) reaches it as `<device>/<thread>` does. When every device is asked at once, a device that answers its own lookup in time could pass the 3.5 s cap and be counted silent, so the call answered `host_unavailable`. Now, when that first round finds no holder, each device that stayed silent is asked again alone. `host_unavailable` is answered only for a device that does not answer on its own. ([#14754](https://github.com/code-yeongyu/oh-my-openagent/pull/14754))
