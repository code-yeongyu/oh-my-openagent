### Fixed

- When the host refuses to close a thread, the `thread_close` refusal (`unsupported`) now names the engine's reason in its message, for example `refused to close it (work_pending: an admitted delivery not yet written)`. Before, the message named only the reason code, so a caller could not tell a running turn, a bash command and an undelivered message apart. The engine side of the same bug, where an interrupted run left a delivery that kept every close refused, is fixed in code-yeongyu/senpi#6971. ([#14178](https://github.com/code-yeongyu/oh-my-openagent/pull/14178), fixes [#14169](https://github.com/code-yeongyu/oh-my-openagent/issues/14169))
