**On Windows, a busy sign-in lock now names the process holding it.** `omo login`, `whoami` and `logout` used to report the holder as exited or unreadable whenever it was still running, so the message gave no pid and no fix. They now name its pid and image (read with `tasklist`), the lock path, and `taskkill /PID <pid> /F` as the way to end it. ([#14118](https://github.com/code-yeongyu/oh-my-openagent/pull/14118), refs #14001)
