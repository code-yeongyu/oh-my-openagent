### Fixed

- The engine now registers its agent dir with the device service even when the service's state directory appears right after the engine started (for example, when the device service is installed or started at the same moment). A freshly armed directory watch can miss an entry created in its first milliseconds, so the registrant never noticed the service and other devices listed no sessions. Each watch arm now re-checks the path once after it settles. ([#12482](https://github.com/code-yeongyu/oh-my-openagent/pull/12482))
