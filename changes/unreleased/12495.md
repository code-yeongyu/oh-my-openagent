### Changed

- The engine CA importer's design 9.7 mutation checks now run in CI for the trust code in `packages/omo-native`: `script/omo-native-trust-mutations.ts` applies each mutation as a source patch to a disposable copy of the package, requires its named test to turn red, and requires the same test to pass on the unpatched copy. It covers 31 source mutations (trust policy, launcher trust stage, user extras, generation retention, the OpenSSL hash-directory and default-file selectors) and 2 oracle self-checks, fails when a mutation's patch no longer matches exactly once, and runs in the new `Engine trust mutations` workflow on every change under `packages/omo-native`. Rows owned by senpi, the desktop or the macOS and Windows adapters run in their own pipelines.
