### Fixed

- A background task resumed with `task_id` no longer reports itself running while its child does nothing: a status poll between the continuation being accepted and the child going busy took the earlier run's answer as the new run's output, completed the task and aborted the child before the continuation ran. A resumed run now counts only output written after it started. ([#14158](https://github.com/code-yeongyu/oh-my-openagent/pull/14158))
