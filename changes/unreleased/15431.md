### Fixed

- A memory repository left dirty no longer blocks memory writes and parks reflection for hours. A memory write whose commit fails now puts back what it wrote instead of leaving it staged. `/memory adopt` commits edits another process left in the repository as one attributed external-edit commit, under the same lock and checks as a normal write; a refused adoption leaves the files untouched. A dirty repository no longer counts toward the reflection or facts park, and every "parent dirty" record now names the files in the way (#15411, #15412, #15413, #15415).
