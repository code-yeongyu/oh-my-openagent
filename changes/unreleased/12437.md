**omo verifies the device service it downloads against the real release key set.** The device service's release key set is now pinned to the minted Ed25519 keys, operational first and recovery second, in `packages/device-service-core/src/release/release-key.json` (a byte copy of the service's own `release-key.json`). A release signed by either key installs; one signed by neither, or with a malformed signature, is refused before anything is written. Until now the pin was a placeholder that refused every release.
