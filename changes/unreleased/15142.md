### Changed

- The macOS live QA pool may use a host with a logged-in console user (R-S4-1): the guest it starts there is a
  headless clone with clipboard bridging off (`run --no-graphics --no-clipboard`), the run keeps zero host-input
  legs, and the SET line records the host's 1-minute load, its core count and the set's p99 (`hostLoad=`, `cores=`,
  `p99Ms=`) beside a new `degraded=` count. A pass under a load above the core count reads `DEGRADED` on its line
  and never counts in `pass=`, and a set whose passes are all degraded exits 3, never green. This file is named
  `PENDING-pool-rule.md` because the PR number is assigned when its PR opens; rename it to `<pr-number>.md` then.
