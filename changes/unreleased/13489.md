**`omo remote --help` and `omo remote <command> --help` now answer.** They print the usage (or that command's entry with its flags) on stdout and exit 0, before any sign-in or device-service check, instead of failing as an unknown argument. `omo --help` lists `remote` among the commands. `-h` now also answers as a help flag after any verb, including in a value position (for example `omo remote open dev --project --help` prints help instead of taking `--help` as the project name).
