### Changed

- Generated build outputs are no longer tracked in git: the Senpi plugin bundles under `packages/omo-senpi/plugin/extensions/`, the `agent-toolkit-sdk`, `bunshin-ts` and `thread-sdk` runtime bundles, `runtime/rollback-migrate.js`, the Codex installer bundle, the plugin installer `plugin/scripts/install.mjs` and the three `omo-native` `bin/lib/*.generated.js` modules. A build writes them: the root build (and so `bun install`) generates the `bin/lib` modules first, and the release builds every one of them from the release commit before it packs `omo-ai` and compiles the binaries. The release payload gate now fails when a generated `omo-ai` module is missing. A local install from a checkout that was never built stops with `run bun run build:senpi-plugin` instead of failing on a missing file. ([#13216](https://github.com/code-yeongyu/oh-my-openagent/pull/13216))
