### Changed

- Memory sync: if you go back from 5.1.64 or later to an older release, the older release cannot push while any edit that was waiting to be sent when 5.1.64 or later last ran is still unsent. It still records new edits, but every push attempt fails until you upgrade again; the waiting edits are kept and go out then. Once those edits have been sent, the older release pushes normally (#12506). ([#13661](https://github.com/code-yeongyu/oh-my-openagent/pull/13661))
