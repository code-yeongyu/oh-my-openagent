### Changed

- Memory sync: if you go back from 5.1.64 or later to an older release while edits captured by the newer release are still waiting to be sent, the older release cannot push. It still records new edits, but every push attempt fails until you upgrade again; the waiting edits are kept and go out then. When nothing captured by 5.1.64 or later is waiting, the older release pushes normally (#12506). ([#13661](https://github.com/code-yeongyu/oh-my-openagent/pull/13661))
