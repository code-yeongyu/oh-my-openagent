**The LSP MCP starts when a project config folder links outside the working directory.** A `.omo` folder that is a symlink or Windows junction to another location, common when dotfolders live on another drive and OpenCode Desktop runs from the home folder, made the LSP server exit at startup with `Project LSP config path must be inside cwd`, so no `lsp_*` tools appeared. That path is now skipped and the server starts, while a request that names such a path is still refused. ([#10093](https://github.com/code-yeongyu/oh-my-openagent/issues/10093), [#10222](https://github.com/code-yeongyu/oh-my-openagent/pull/10222))
