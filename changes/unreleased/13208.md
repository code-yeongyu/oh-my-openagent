### Added
- Thread gateway: the store can take in a delivery that another device's service attested for a session on this device that is not running (the intake row of #13037). The row is committed in the same transaction as a same-device delivery, keeps the sender's delivery id, text and display text, is rate-limited per sending device, and is admitted later under the engine's own ledger key, so the engine counts it once even if the same delivery also arrives live. A reply to such a delivery continues its chain. The gateway store's schema moves to version 12 (three new nullable columns); a process still on the previous build reports the store's "schema too new" error until it restarts. Nothing calls the intake yet, so no behavior changes. ([#13208](https://github.com/code-yeongyu/oh-my-openagent/pull/13208))
