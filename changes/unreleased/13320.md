**A resume after a refused engine load reports the restart instruction.** A child resume that failed because the senpi engine refused to load next to an incompatible redaction registry slot previously showed only the generic "The task host could not open the child session." message. The resume path now classifies the refusal and keeps the same restart-omo instruction a fresh start already shows.
