### Added

- The omo SDK revokes another device of the account: `devices.revoke({ id, confirmName })` acts only when `confirmName` equals the device's current name, never revokes this device, and counts the revoke only once the account no longer lists it. `omo account devices revoke` now shares the same implementation. ([#14522](https://github.com/code-yeongyu/oh-my-openagent/pull/14522))
