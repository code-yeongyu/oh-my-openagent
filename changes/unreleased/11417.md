**Error messages name a step that works today.** While terminal sign-in is closed, every "run omo login" hint (sign-in, `omo sync`, expired or unreadable sign-ins, memory sync) points at the OmO desktop app instead, and keeps naming `omo login` once accounts open. A refused service request says whether to sign in again, wait, try later or update omo, instead of always blaming sign-in. A missing plugin file, `omo thread` and `omo update` on a broken current install print the exact reinstall command, and `/computer` says why computer use is unavailable. ([#11390](https://github.com/code-yeongyu/oh-my-openagent/pull/11390), part of [#11379](https://github.com/code-yeongyu/oh-my-openagent/issues/11379))

**Maintainers can inspect or recreate a stuck get.omo.dev channel pointer from the installer mirror workflow.** A manual run with `op=head` prints the signed HEAD and GET of `channels/latest` or `channels/beta` (status, every response header, body; credentials redacted), and `op=recreate` deletes the pointer and writes the given version as a new object, then reads it back; it refuses a version that is not fully mirrored or does not fit the channel (a prerelease on beta, a stable release on latest). Both share one concurrency group per channel with a mirror that moves that channel. ([#11349](https://github.com/code-yeongyu/oh-my-openagent/pull/11349), part of [#11313](https://github.com/code-yeongyu/oh-my-openagent/issues/11313))

## 2026-10-26 - Cover restored Stop admission through the real manager (#11401)

The restart regression reconstructs pause custody over a shared state directory, releases the restored Stop, injects a child restore failure, and verifies that real manager admission changes from held to started. A native-session regression also quits, disposes and reopens the same persisted JSONL, sends a real person prompt through AgentSession, and verifies the actual manager admits a new task. The native engine's input release is the person-reachable action; `/resume` remains the session picker.

Missing-runtime notices describe an incomplete installation without spelling a retired CLI command. A host missing the computer-use API now names the registered `omo update` command. ## 2026-10-25 - Optional shared bundled skills directory (#11332)

Every bundled skill consumer (resources discovery, the task skill loader, and

## 2026-10-26 - A failed paused-child restore cannot wedge parent admission (#11401)

An acknowledged child could fail to restore after the parent quit and reopened. ## 2026-10-26 - Reinstall and sign-in guidance (#11390)

The launcher sets `OMO_REINSTALL_COMMAND` (`updateTarget().command`) for the engine so the plugin can name the reinstall command after `SENPI_BRAND` is scrubbed. `runThreadCommand` takes a `reinstall` step from its caller (npm: the reinstall command; compiled: the releases page). `omo update` on an install already at the channel version whose engine tree cannot be resolved exits 1 with the reinstall command. `omo sync` reads the account refusal body's code through `ApiRefusal`, using the shared guidance and falling back to HTTP status for unknown or malformed bodies.
