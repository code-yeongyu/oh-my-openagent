### Fixed

- The bundle marker digest no longer folds the running node's `builtinModules` into the digested build settings: the builtin family is recorded as one stable token and only source-derived externals are digested, so a byte-identical bundle built under node 26 (which adds `node:ffi`) no longer reads as stale. A RED test pins the stability and that a source-derived external still changes the digest (#13155).
