### Fixed

- The browser skill ships omowright `305c823`, so sessions attached to the user's own browser work with BrowserSkill 0.4 again. Every page action carries the context of a fresh `session.cooperate("sync")`, and a `cooperation_sync_required` refusal waits for the person with `session.cooperate("wait")`, then re-syncs.
