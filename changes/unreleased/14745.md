### Fixed

- The agent no longer tells OmO app users to run `/reload` after a config change such as a new per-task model. Each session's system prompt now says how a saved omo config edit takes effect on the surface it runs in. In the terminal UI, saved edits hot-reload once the session is idle with no subagent running, and `/reload` applies them sooner. In the OmO app and other RPC clients, the agent is told those surfaces have no slash commands or terminal keys, and the app is told to start a new task for a changed per-task model. One-shot runs apply the change on the next run. ([#14745](https://github.com/code-yeongyu/oh-my-openagent/pull/14745))
