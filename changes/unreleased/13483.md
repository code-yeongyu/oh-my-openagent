### Fixed

- A reply to a sender named by its device no longer goes through the relay when this device's own id cannot be read; the send is refused `host_unavailable` with the reason, and nothing is sent. ([#13483](https://github.com/code-yeongyu/oh-my-openagent/pull/13483), part of [#13037](https://github.com/code-yeongyu/oh-my-openagent/issues/13037))
- A session that another device holds but does not run is reached through a probe only while this device's service can carry the wake; with the wake off, the answer stays `not_found` instead of an attach refusal. ([#13483](https://github.com/code-yeongyu/oh-my-openagent/pull/13483))
- A wake whose connection drops after the request was written is reported uncertain, not refused, so it is never retried as if nothing ran. ([#13483](https://github.com/code-yeongyu/oh-my-openagent/pull/13483))
