### Added

- A local install from a checkout now warns, in one line naming `bun run build:senpi-plugin`, when the plugin build predates a later commit that changed a plugin build input. The in-tree plugin build records the commit it was made from in the ignored `plugin/.build-stamp`; the launcher reads the checkout's commit from `.git` without spawning a process and compares only when it moved. It never blocks the start, and a packed or published install is unaffected. Uncommitted edits are not compared.

## 2026-11-12 - The local launcher warns on a plugin build older than the checkout (#13234)

`plugin/scripts/build-stamp.mjs` owns the stamp. `build-extension.mjs` calls `writeBuildStamp` after an in-tree build; with `OMO_SENPI_PLUGIN_OUTPUT` set it writes none, and an unreadable HEAD removes an older stamp. The rendered launcher imports `staleBuildWarning` from the checkout inside a guard, because the launcher outlives the checkout's version. A hit is any changed path on `bundle-inputs.json` (files, or below its directories) or a change to the map itself. Must not break: the stamp stays out of every package (`verify-omo-ai-payload.mjs` forbids `plugin/.build-stamp`), an unresolvable HEAD stays silent rather than guessed, and the launcher starts whatever the check does.
