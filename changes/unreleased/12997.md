**Thread tool rows in the TUI now read like a status line instead of a JSON dump.** Each `thread_*` tool shows one call line (the verb, the target thread's name or short id, and the message's first line) and one outcome line with a few short details: `-> planner  follow-up delivered (turn 306)`, `planner: 12 messages (latest: ...)`, `3 threads in this workspace` with the first few threads, `created scratch`. Delivery ids, message sequence numbers and full uuids stay out of the collapsed row; a failure shows its code, message and next step; the expanded view (ctrl+o) adds the full result. What the model receives is unchanged. ([#12997](https://github.com/code-yeongyu/oh-my-openagent/pull/12997))
