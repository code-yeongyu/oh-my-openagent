### Fixed

- thread client: refuse a dial whose key record is missing, or whose host does not authenticate while a key record names its endpoint. A host that challenges under a launch with no key record under the key root is refused `host_identity_unproven`. A host that does not authenticate is refused when a key record under the key root names the dialed endpoint, or when a record there cannot be read; the refusal names the record. An endpoint that no key record names is served without authentication. When the launch a record names has ended, a later senpi host start removes the record, and so does removing it by hand; after that, that endpoint is served without authentication. An agent session is told only the refusal's code and one fixed sentence. The next step stays the generic one; the key-record remedy follows in [#15192](https://github.com/code-yeongyu/oh-my-openagent/issues/15192).
