### Added

- Computer use: the agent cursor now has one look and one motion planner (IS row 52). The overlay renderers on each desktop will draw from this shared table; none consumes it yet. A glide lasts between 150 and 450 ms and grows with the distance on screen. A newer action carries the cursor on from where it is. A short hop is placed without a glide, and with reduced motion the cursor fades in at the target. The look (an arrow with a soft round halo, a colour per session and a badge for the action) and the timing ship as `cursor-look.json` and `cursor-motion.json` in the computer tool package. Nothing here moves the system pointer or delays an action.
