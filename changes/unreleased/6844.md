### Added

- `call_dsh_agent` delegates a self-contained task to a DeepSeek Harness (dsh) agent, spawned as the published headless CLI or over the Agent Client Protocol, once `dsh.enabled` is set in the config. ([#6844](https://github.com/code-yeongyu/oh-my-openagent/pull/6844))
- A `verify` argument on `call_dsh_agent` runs a deterministic command in the run's working directory afterwards, so a result is checked locally with no model call; a failing gate returns the agent output together with the captured evidence. ([#6844](https://github.com/code-yeongyu/oh-my-openagent/pull/6844))
