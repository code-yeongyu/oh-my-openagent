### Fixed

- Account commands in a compiled `omo` find the signed keychain helper installed beside the binary even when the entry point did not register it, so a desktop runtime inside a renamed app bundle (for example `OmO (Nightly).app`) no longer fails with "OmO's keychain helper is missing or damaged" (exit 9). The extra location is used only by a compiled binary, and the helper there must still pass the same signature check (#13102).
