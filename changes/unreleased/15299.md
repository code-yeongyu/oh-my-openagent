### Changed

- omo now runs on senpi 2026.11.27 (from 2026.11.23); the bundled plugin and the service-auth table are regenerated for it. What changes through the engine:
  - A terminal that speaks OSC 7577 learns each session's resume command, so a restored terminal can reopen the session it was showing. omo's compiled entry loads that hand-off first, ahead of every other module.
  - A message another session sends while the previous message's turn is still starting joins that turn, so messages sent together arrive in one turn, in order.
  - A peer message stopped by the per-session turn cap is answered as held, and Resume continues a capped session.
  - The todo widget no longer shows an item as in progress while the session is idle.
  - A question reattached after a reload shows its prompt again.
  - On a shared session host, telemetry is decided per caller, and a decline by any caller removes the attribution headers.
  - JavaScript eval cells run `using` blocks, TypeScript cells and scoped cleanup.
