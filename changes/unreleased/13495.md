**Scripts can create, interrupt, close, rename and re-model threads through the thread SDK.** `createThreadSdk(...)` from `runtime/thread-sdk/sdk.js` now has `create`, `interrupt`, `close`, `rename` and `set_model`. They take the same arguments as `thread_create`, `thread_interrupt`, `thread_close`, `thread_rename` and `thread_set_model`, run the same code, and answer the same data on this device or another device of the account. A script acts as itself, not as a session, so `self` answers `caller_context_missing` and a thread it creates records no creator session. ([#13413](https://github.com/code-yeongyu/oh-my-openagent/issues/13413))
