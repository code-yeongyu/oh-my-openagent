### Fixed
- Thread names on other devices now resolve when their sessions are resumable, and fuzzy handoff searches the account's remote candidates as well as local candidates.
- Failed lookups through a configured relay return their typed error (`host_unavailable` with the device-service state: offline, connecting, keychain locked, authorization stale, degraded or update required); a relay that is not set up (not configured, disabled, signed out, sign-in required) preserves local address resolution. Renaming a remote thread checks names on its own device before changing its name or alias.
