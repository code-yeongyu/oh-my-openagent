**The computer-use conformance report gains a schema check, a summary and an honest "not observed" signal.** `script/qa/computer/conformance/report.ts --check-schema` accepts a complete run even when its cells fail and rejects a missing, duplicate, undeclared or contradictory cell; `--summary` prints the cell counts including how many cells disturbed the session and how many no observer read. A signal that no recorder could read is recorded as `not_observed` instead of a false clean reading, and such a cell never passes. QA tooling only; no runtime behaviour changes.
