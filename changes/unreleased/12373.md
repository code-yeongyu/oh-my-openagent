### Fixed

- A parent's Stop, Resume, a message sent while its run is stopped, and `task_cancel` now reach a background child that another live omo process of the same user is running (after `/reload`, or with the session open in two windows). They are carried to that process, which applies them on its own handle, instead of leaving the child running or filing it as lost. Its completion is reported to the session of the process that runs it. When that process runs an older build, has lost the child, or `task.control_channel` is off, the answer is a typed "owner cannot apply" with the reason, never silence. ([#12373](https://github.com/code-yeongyu/oh-my-openagent/pull/12373), fixes [#12349](https://github.com/code-yeongyu/oh-my-openagent/issues/12349))
