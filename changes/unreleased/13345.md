### Added
- `bun run test:shards` runs the whole root test suite across the machine's cores: the serial quarantine first, then `min(cores - 1, 16)` serial `bun test --shard` processes (override with `OMO_TEST_SHARDS`), each writing a JUnit report; `bun script/test-shards.ts --verify <serial.xml> <reportDir>` proves the shards ran exactly the serial run's tests, once each. The one-process `bun test` is unchanged. ([#13345](https://github.com/code-yeongyu/oh-my-openagent/issues/13345))
