- On Windows, a failed memory reflection no longer reports Bun's `child reaper unavailable under Bun on win32` notice as its cause. Failure notices, `/facts` status and the failure fingerprint now name the real cause line (a provider error, a timeout, an expired key), so different failures are no longer counted as one streak.
