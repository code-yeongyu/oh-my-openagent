### Added

- Add persistent OpenCode PR watches with `watch_pull_request`,
  `list_pull_request_watches`, and `unwatch_pull_request`. A shared host poller
  wakes the registering session when checks pass or fail, merge conflicts
  appear, or external review and comment activity changes.
- Restore watches and pending wake deliveries after host restarts, using
  durable message receipts to deduplicate delivery retries and respecting
  GitHub rate limits during polling.
