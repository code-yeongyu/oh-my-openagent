### Fixed

- On macOS and Linux, a memory reflection that hits its deadline now ends its whole process group, so a helper process that ignores SIGTERM no longer keeps running in the run's worktree (#11384).
- If the reflection's bootstrap exits unexpectedly, the remaining group members are stopped immediately without signaling a process group that may have reused its ID. If the status pipe is lost, the supervisor uses the model's saved exit status.
