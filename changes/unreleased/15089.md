### Changed

- The browser skill's bundled runtime is omowright 0.3.10 (was 0.3.4, #15088). No API change.
  - A failed `fill()` scrubs the entered value out of the error it rejects with, as a best effort over ordinary error shapes: a cause that is not an `Error`, an `AggregateError`'s members, a field a transport adds, a getter, a boxed string or number, an error that cannot be rewritten in place, an `Error` from another realm, and a `DOMException`, whose message lives on its prototype. A value of four or more code points is removed even where it touches a letter or digit; a shorter one is removed only as a whole token, so `fill("a")` on `locator a a7` leaves `a7` readable. Among what is not read (the full list is in omowright's 0.3.9 and 0.3.10 release notes): property names, private fields, and text that only a method of an object computes (a `URL`, `Headers`).
  - An `Error` nested in a payload keeps its class and identity. The exception is an `Error` in which the value is found and that cannot be rewritten in place (frozen, or with a field that is neither writable nor configurable): that one is replaced by a scrubbed copy of the same class. An error in which the value is not found is left as it is, frozen or not. The command's own parameters are not rewritten.
  - When an orphaned browser left on a profile ignores SIGTERM, the launch re-checks that the pid is still the recorded process before it escalates to SIGKILL (a check right before that signal, not an atomic one), and it fails with an error naming the pid when a process the reap could not end is still running; before, the launch went ahead.

### Fixed

- Every example in the `browser` skill parses and accounts for the names it uses: each name is declared in its document's examples, is a platform global, or is listed in a `// given:` line that says what the reader supplies. The `Humans` example in `references/commands.md` passes concrete options where it used undeclared ones, and the reference's first example no longer stops the session the later examples use. The network recipe subscribes to the response before it navigates (it could miss a response that arrived during `goto`), keeps its collector subscribed for the scrolling example, and no longer says scrolled items are de-duplicated.
