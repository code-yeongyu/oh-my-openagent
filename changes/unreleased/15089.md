### Changed

- The browser skill's bundled runtime is omowright 0.3.7 (was 0.3.4, #15088). A failed `fill()` no longer leaks the entered value through a cause that is not an `Error`, when the value touches a letter or digit, inside an `AggregateError`'s members, in a field a transport adds to its error, through a getter, or in an error that cannot be rewritten in place; an `Error` nested in a payload keeps its class and identity, and the command's own parameters are never rewritten. A reaped orphan browser is gone before its profile is reused. No API change.

### Fixed

- Every example in the `browser` skill parses and accounts for the names it uses: each name is declared in its document's examples, is a platform global, or is listed in a `// given:` line that says what the reader supplies. The `Humans` example in `references/commands.md` passes concrete options where it used undeclared ones.
