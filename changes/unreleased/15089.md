### Changed

- The browser skill's bundled runtime is omowright 0.3.6 (was 0.3.4, #15088): a failed `fill()` no longer leaks the entered value through a cause that is not an `Error`, when the value touches a letter or digit, or inside an `AggregateError`'s members and fields a transport adds to its error. No API change.

### Fixed

- Seven examples in the `browser` skill now declare the names they call (`mkdtempSync`, `rmSync`, `join`, `tmpdir`, `loadOmowright`, and the `flag` path the `tool.monitor` examples watch), so each runs as written in an eval cell.
