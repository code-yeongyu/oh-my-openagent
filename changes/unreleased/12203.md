### Fixed

- The browser skill ships omowright `1996390` (was `73c4898`). Attached sessions work with BrowserSkill 0.4 again: the skill's loop and recipes now sync with `session.cooperate("sync")` and pass that `{ context }` to every gated page action instead of being refused with `cooperation_sync_required`. The new omowright also restarts a daemon whose `daemon.json` names one that no longer runs, finds a live Windows daemon whose `daemon.json` vanished, and has `bskDoctor` name the browser the daemon is actually connected to (pin bump by @LilMGenius, [#12203](https://github.com/code-yeongyu/oh-my-openagent/pull/12203), [#12451](https://github.com/code-yeongyu/oh-my-openagent/issues/12451))
- omowright fixes from @ashmoonori-afk now reach OmO users: `connectRunningBrowser()` finds a browser that already has remote debugging on through `DevToolsActivePort` (code-yeongyu/omowright#115), `goto` settles on sparse and frameset pages (code-yeongyu/omowright#116), the BrowserSkill IPC client decodes UTF-8 split across stream chunks (code-yeongyu/omowright#117), and stale-ref recovery re-binds a ref only when exactly one element matches (code-yeongyu/omowright#118)
- The bundled omowright also carries agent tabs that stay in their own window from @devxoul (code-yeongyu/omowright#120), the pipe-readiness leak fix for #9525 and the Windows installer fix for #9855
