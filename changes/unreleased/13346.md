### Added

- Computer use v3: consent, the foreground lease and the window reservation. A human grant opens a single-holder foreground lease; background input is the default route and needs no grant. Each per-app consent entry is bound to the target's code identity at grant time, and a different identity under the same app key refuses `ControlRequired{identity_changed}`. A held lease shows a presence surface, and `preview.subscribe` delivers small JPEG preview frames that never enter model context. `display.release` and `display.resume` end and re-arm the lease. Every lease end goes through one path, which calls a session-owned hook once with its cause. Nothing user-visible changes yet; the existing desktop engine is untouched. ([#13346](https://github.com/code-yeongyu/oh-my-openagent/pull/13346))
