### Fixed

- A thread that is not running no longer stays `queue_full` for good. Messages waiting for it now expire after 24 hours even while it is down, and they stop counting against its 128-message backlog, so later sends are accepted again. A refused send now says the target is not running (`target_running`) and when its oldest message frees a slot (`frees_at`). ([#14469](https://github.com/code-yeongyu/oh-my-openagent/pull/14469), fixes [#14466](https://github.com/code-yeongyu/oh-my-openagent/issues/14466))
- A session that stops taking its thread messages no longer cuts itself off from every sender: steers have their own reserve (16 messages / 256 KiB), so they are admitted even when 128 undelivered follow-ups fill the target's backlog, and `queue_full` now says how many messages are held, how many the session took without writing them, how old the oldest is, and why they are not draining. ([#14431](https://github.com/code-yeongyu/oh-my-openagent/pull/14431), fixes [#14428](https://github.com/code-yeongyu/oh-my-openagent/issues/14428))

### Added

- `thread_send` `collapse_key` (`omo thread send --collapse-key`, SDK `send`): a repeated message replaces the sender's earlier undelivered one under the same key, so a notifier that re-sends an alert every few minutes leaves at most one undelivered message. Sessions on this device only. `thread_list` rows show each thread's undelivered `backlog`. ([#14431](https://github.com/code-yeongyu/oh-my-openagent/pull/14431))
