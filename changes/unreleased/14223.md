### Fixed

- On Windows, a memory sync and a memory write starting together on a new device no longer fail with a held `memory-write` lock. Creating the memory repository there takes longer than the 5 s lock wait, so the second caller timed out. Callers in one process now wait for the one creation already running. ([#14223](https://github.com/code-yeongyu/oh-my-openagent/pull/14223), fixes [#14188](https://github.com/code-yeongyu/oh-my-openagent/issues/14188))
