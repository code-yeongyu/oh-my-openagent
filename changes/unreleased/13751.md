### Changed

- `omo remote open`, `send`, `model`, `interrupt`, `close` and `attach` now run on the one remote client (part 4c-2 of the one remote module design). `send` waits by default by following the session before it sends; `--jsonl` streams one follow event per line and `--timeout <ms>` bounds a waited send. A send that waits on an approval names the request and the device to answer it on. `--json` prints the client's value as is: the open result, the send receipt, `{model}`, the interrupt result or `{closed}`, and a failure as `{kind: "error", code, message, next_action}`.
