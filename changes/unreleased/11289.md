**The research delivery barrier checks one meaning record per delivered edition.** `fact meaning-check --edition <format>` writes `fidelity-meaning-defects.<format>.json` bound to that edition's bytes, so an html report delivered with a byte-different inline, Markdown, or post edition passes once each edition with different bytes is checked (an edition whose bytes match a checked edition, such as a copy at another path or a PDF of the html edition, shares its record), and a stale or unchecked edition refuses alone. A single-edition session keeps using `fidelity-meaning-defects.json` unchanged. Existing session fidelity records remain blocking even when a delivered row attaches a different clean record, and two paths to one record (including through a symlink) no longer duplicate its defects.
