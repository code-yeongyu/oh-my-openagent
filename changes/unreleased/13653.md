### Fixed

- Desktop memory sync: the 10 s bootstrap bound now covers the whole selection, including the lazy device-account sidecar import. A slow or stuck import answers the selection as unavailable within the bound instead of after it, and a claim that starts after the bound passed takes the inherited descriptor and closes it without starting the exchange (#12048). ([#13653](https://github.com/code-yeongyu/oh-my-openagent/pull/13653))
- Desktop memory sync: on a launch whose private-descriptor table no host CLI captured, the memory component's registration now removes `SENPI_PRIVATE_FDS` / `SENPI_PRIVATE_FDS_FINAL` from the environment at once, so a child process another extension starts before the channel is claimed no longer inherits the declaration. The sidecar's claim puts them back for senpi's capture in the same module evaluation, and the launch still counts as a desktop launch (#12057). ([#13653](https://github.com/code-yeongyu/oh-my-openagent/pull/13653))
