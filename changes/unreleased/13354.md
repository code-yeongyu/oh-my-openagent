### Added

- Computer use v3 (Linux): the X11 backend captures windows from their own pixmap, so an occluding window no longer hides them, composites the cursor in device pixels, reports RandR monitors with the Xft DPI scale, and gives displays stable ids. With no display server, every verb that needs a backend answers `COMPUTER_UNAVAILABLE` (`no_display_server`) and points to `computer.diagnose`. A Linux live driver for QA starts its own session and prints one `SET linux/<session> pass= fail= blocked=` line, counting a scenario the session cannot admit as blocked, never as passed. ([#13354](https://github.com/code-yeongyu/oh-my-openagent/pull/13354))
