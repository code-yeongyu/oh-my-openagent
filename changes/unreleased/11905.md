### Added

- Categories and agents can set `models_distribution: "round_robin"` alongside `models` to spread new task children across their configured model chains. The default `sequential` policy keeps the existing order. Each child's fallback chain wraps from its selected starting model without repeating models, and continuations keep their current model.
