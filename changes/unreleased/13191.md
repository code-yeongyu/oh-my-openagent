### Fixed

- `/memory-merge` now folds a source entry's first name the way Windows reads it before the `system/` check, so an entry such as `system./new.md` or `system:s/new.md` is kept aside like `system/` instead of being written into the target's `system/` (#13191).
- A refused `/memory-merge` removes the directories it created on the way, so the target is left exactly as it was (#13191).
- A memory repository whose `.git` file holds a relative `gitdir:` pointer is resolved against that file's own directory (#13191).
