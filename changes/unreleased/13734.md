### Fixed

- On Windows, a background key chord that holds Ctrl, Alt, Shift or Win (for example `ctrl+k`) is now refused with `BackgroundUnavailable` and nothing sent, instead of being reported delivered while the application received only the bare key. Send such a chord with `delivery: "foreground"` or use accessibility actions. ([#13734](https://github.com/code-yeongyu/oh-my-openagent/pull/13734), fixes [#13297](https://github.com/code-yeongyu/oh-my-openagent/issues/13297))
