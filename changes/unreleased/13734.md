### Fixed

- On Windows, background keyboard input that holds Ctrl, Alt, Shift or Win while another key goes down is now refused with `BackgroundUnavailable` and nothing sent, instead of being reported delivered while the application received only the bare key. This covers key chords such as `ctrl+k`, bounded key and mouse holds with such keys, and a single character the keyboard layout types with Shift or AltGr (for example `K`, or `@` on a German layout). Send it with `delivery: "foreground"` or use accessibility actions. ([#13734](https://github.com/code-yeongyu/oh-my-openagent/pull/13734), fixes [#13297](https://github.com/code-yeongyu/oh-my-openagent/issues/13297))
