### Added

- Computer use v3: apps, menus, system surfaces and the URL policy. `win.menu.items()` reads a window's menus (label, enabled, checked, accelerator, submenu, path) and `menu.select` picks one. `apps.list`, `apps.open` and `apps.quit` resolve an app with its source and identity, and quitting a protected process is refused. `capabilities().surfaces` and `computer.surface(kind)` open system surfaces, or refuse `Unavailable{surface, reason}`. The `computer.url_policy` table refuses a denied host before any input is sent, and delivers with `urlPolicy:"unknown"` when the URL cannot be read. Nothing user-visible changes yet; the existing desktop engine is untouched. ([#13347](https://github.com/code-yeongyu/oh-my-openagent/pull/13347))
