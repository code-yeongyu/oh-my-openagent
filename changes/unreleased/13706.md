### Fixed

- Memory sync no longer stops for good when its first start fails. A start that fails (for example another omo process holding the account's credential lock past the 15 s wait) or gets stuck is retried on the same backoff as a waiting start, 15 s doubling to five minutes. A stuck start is named in the log, and the first successful start logs "memory sync started", so a log shows whether sync is running (#13701). ([#13706](https://github.com/code-yeongyu/oh-my-openagent/pull/13706))
