### Fixed

- `thread_list` (and `omo thread list --json`) now says `aliases_unavailable` (`sign_in` or `host_unavailable`) when the account's alias registry cannot be read, instead of listing every thread as if it held no alias. A caller that uses aliases as lane names no longer mistakes a held alias for a free one.
