### Fixed

- `thread_list` (and `omo thread list --json`) now says `aliases_unavailable` when it lists threads without the account's aliases, instead of listing every thread as if it held no alias: `sign_in` or `host_unavailable` when the alias registry cannot be read, `not_asked` when this device's device service is not connected (aliases are only read while it is). A caller that uses aliases as lane names no longer mistakes a held alias for a free one. ([#13934](https://github.com/code-yeongyu/oh-my-openagent/pull/13934), part of [#13923](https://github.com/code-yeongyu/oh-my-openagent/issues/13923))
