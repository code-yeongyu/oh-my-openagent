### Fixed

- Starting a Web Worker under Bun (`new Worker(url)` without `node:worker_threads`) no longer throws `TypeError: worker.on is not a function` from the team lock observer, which in the OpenCode plugin surfaced as an uncaught exception in opencode's TUI worker whenever another plugin started one. The observer now tracks a Web Worker's registration and exit through its own events, so a team lock held inside a Web Worker can be reclaimed after the worker is gone. ([#14165](https://github.com/code-yeongyu/oh-my-openagent/pull/14165))
