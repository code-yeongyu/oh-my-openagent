### Fixed

- Reflection notices show summaries correctly for numbered headings and preserve numeric prefixes in the content. ([#12838](https://github.com/code-yeongyu/oh-my-openagent/pull/12838))
- Memory sync: if the outbox's `pending/` folder cannot be read (for example a permission error), the push now reports the error instead of silently skipping cleanup, which let old segment files pile up again. ([#12828](https://github.com/code-yeongyu/oh-my-openagent/pull/12828), part of [#12506](https://github.com/code-yeongyu/oh-my-openagent/issues/12506))
- Memory sync: tests now pin the 2,000-line bound where a body edit switches from whole-line merging to the character merge, and the in-code note states the line diff's real memory ceiling (about 32 MB). No behavior change. ([#12820](https://github.com/code-yeongyu/oh-my-openagent/pull/12820), fixes [#12526](https://github.com/code-yeongyu/oh-my-openagent/issues/12526))
- Codex on Windows: the generated `.cmd` runtime wrapper now runs its target even when the path contains `%`, `!`, `^` or parentheses (for example a user folder named `Kim (Work)`), and `omo doctor` checks that same path. ([#12819](https://github.com/code-yeongyu/oh-my-openagent/pull/12819), fixes [#12811](https://github.com/code-yeongyu/oh-my-openagent/issues/12811))
- Memory sync on the desktop app: account lookups that overlap at session start no longer drop a just-opened account or open it a second time. ([#12818](https://github.com/code-yeongyu/oh-my-openagent/pull/12818), fixes [#12804](https://github.com/code-yeongyu/oh-my-openagent/issues/12804))
- `omo doctor` on Windows now recognizes a leftover Codex Light `omo.cmd` wrapper and reports it as broken when its cached runtime is gone; before, it was listed as an unknown `omo`. On macOS and Linux, a Codex Light wrapper whose cache path contains `$`, a backtick, a backslash or a double quote is no longer misreported by `omo doctor` or the OpenCode doctor's runtime-wrapper check. ([#12810](https://github.com/code-yeongyu/oh-my-openagent/pull/12810), fixes [#12560](https://github.com/code-yeongyu/oh-my-openagent/issues/12560))
- Memory sync on the desktop app: two account lookups that overlap at session start now share one account request instead of each sending its own over the claimed sync channel. ([#12803](https://github.com/code-yeongyu/oh-my-openagent/pull/12803), fixes [#12799](https://github.com/code-yeongyu/oh-my-openagent/issues/12799))

### Changed

- Inline charts: the `visualize` and `data-scientist` skills now ask for values that stay readable without hover (labels or a collapsed table, plus an accessible chart summary), one precision per number, totals that add up, one meaning per colour, a true zero kept apart from missing data, and a period label that matches the query window. Small components are no longer drawn as thin stacked-bar bands. ([#12816](https://github.com/code-yeongyu/oh-my-openagent/pull/12816), fixes [#12620](https://github.com/code-yeongyu/oh-my-openagent/issues/12620))
