**A full disk no longer leaves a truncated `boulder.json` or loses the write error.** `writeBoulderState` writes through a temp file and a rename, so a failed write keeps the previous state byte for byte, and it returns a typed result whose `BoulderStateWriteError` (code, path, what to do) reaches the caller; the ulw-execute hooks log it.
