## 2026-11-12 - model_profile passwd lookup: file symlinks into the checked folder (#13292 follow-up)

`findLookupBinary` already dropped PATH entries whose real path is at or below the current directory or an untrusted folder, but it returned the `getent`/`id` file it found in a remaining entry without resolving it, so a file symlink in a trusted directory could still point at a binary the checked or session folder ships. The candidate file's real path now gets the same containment check (`findOnPath` takes an optional `accept` predicate; a rejected candidate moves the search on to the next entry), so such a symlink is skipped while a symlink to a binary outside those folders still runs. Other `findOnPath` callers pass no predicate and behave as before.
