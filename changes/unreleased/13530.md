### Fixed

- An engine registers its agent dir with the device service again within about a second of the service coming back after a stop, whether or not the operating system reports the new socket in time. Until now the registrant waited for that file notification alone once its connection had closed, and on a macOS machine with heavy file activity the notification arrived seconds to tens of seconds late, so the restarted service did not list that engine's sessions until then. The registrant now arms its endpoint watch again once the endpoint it knew is gone, which gives the returning service the same one-second settle re-check a service gets at engine start ([#13530](https://github.com/code-yeongyu/oh-my-openagent/pull/13530), fixes #12733).
