### Fixed

- An engine registers its agent dir with the device service again when the service stops and comes right back, whether or not the operating system reports the new socket in time. Once its connection had closed, the registrant used to wait for that file notification alone, and on a macOS machine with heavy file activity the notification arrived seconds to tens of seconds late, so the restarted service did not list that engine's sessions until then. The registrant now arms its endpoint watch again once the endpoint it knew is gone, so a service that is listening again within about a second of that is found by the watch's one-second re-check. A service that returns later than that still waits for the notification ([#13531](https://github.com/code-yeongyu/oh-my-openagent/issues/13531)) ([#13530](https://github.com/code-yeongyu/oh-my-openagent/pull/13530), fixes #12733).
