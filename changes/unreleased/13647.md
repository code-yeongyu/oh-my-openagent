### Fixed

- Memory sync: an `omo logout` that could not get the service to confirm the device revoke (offline, a server error, an uncertain refresh) no longer leaves that device's sync key in the account keyring for good. The revoke is now owed: the next `omo login` on the same computer revokes the old device with the new sign-in, and a remaining member then rotates the old key out, as it does after any sign-out. An owe for another account waits for a sign-in to that account, and an owe that fails to send waits for the next sign-in (#12281).
