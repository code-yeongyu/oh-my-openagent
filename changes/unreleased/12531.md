## 2026-11-05 - ps-lstart start identity is timezone-independent (#12531)

On darwin/freebsd without `bun:ffi` (a Node runtime), the process-start identity falls back to `ps -o lstart=`, which prints local time. Two processes with different `TZ` settings read the same pid as the same scheme with different bytes, `startIdentitiesConflict` counts that as a conflict, and a live owner reads as dead, breaking memory-core stale-lock recovery and the senpi-task `host_claim` owner check. The spawned `ps` now runs with `TZ=UTC`, so the identity no longer depends on the reader's timezone. Covered by `process-identity.ps-lstart.test.ts`, which reads the same live pid under two timezones and expects equal identities.
