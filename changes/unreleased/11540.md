**`omo doctor --verbose` shows the models and reasoning your config actually runs.** Configured Models now asks the same resolvers the runtime uses, so an agent configured with a `models` chain and `reasoning` shows that reasoning instead of the built-in default, and a category configured only through `models` shows your model (marked as a user override) instead of the built-in fallback.
