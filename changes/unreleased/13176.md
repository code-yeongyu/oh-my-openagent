**A long foreground task can move to the background instead of blocking.** With `background_task.foregroundHandoffMs` set (default `0`, off), a `task` with `run_in_background: false` whose child is still running after that long returns its task id and lets the parent carry on; the child is not stopped, and its answer arrives in its completion notice with the duration counted from its start. ([#13176](https://github.com/code-yeongyu/oh-my-openagent/pull/13176))
