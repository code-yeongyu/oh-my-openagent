**Signing out of the desktop app while memory sync waits for the memory repository now makes sync go idle.** Sync used to keep reporting that it was waiting for the repository until the first memory write. Now a desktop sign-out makes sync go idle as soon as it happens, and a desktop channel that closes makes sync report why. Sync still does not read the account again on each retry while it waits. A CLI sign-out done in another process is seen on the first sync pass after the repository's first commit, as before.
