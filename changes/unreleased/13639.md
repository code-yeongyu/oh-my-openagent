**Signing out while memory sync waits for the memory repository now makes sync go idle.** Sync used to keep reporting that it was waiting for the repository until the first memory write. Now a signed-out device goes idle, and an account whose desktop channel closed reports why, as soon as the account changes. Sync still does not read the account again on each retry while it waits.
