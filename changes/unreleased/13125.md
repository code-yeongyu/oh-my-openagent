### Fixed
- `thread_create` with no `cwd` now opens the new thread in the calling session's folder instead of the folder the engine process runs in. A thread created from a desktop thread with no project used to land in the home folder, where its link could not be opened and a follow-up `thread_send` needed `all_scope`. An explicit `cwd` still wins, and a thread created on another device keeps that device's own default. ([#13125](https://github.com/code-yeongyu/oh-my-openagent/pull/13125))
