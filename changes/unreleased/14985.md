## 2026-11-25 - The install namespace as typed calls (#14985)

`bin/lib/install-calls.js` holds one body per install operation; each takes its input, then its ports as one argument with real defaults, and answers a typed value or failure without printing, exiting or reading a terminal. `self-update.js` (`runSelfUpdate`), `setup-import.js` (`runSetup`), the launcher's `--version` and the compiled entry render those answers byte for byte; `compiled-update.ts` keeps `compiledUpdate` as the renderer of the compiled edition's update. `install.setup.apply` with `consent: "each"` asks `decide` once per pending stage before that stage writes. The setup plan carries a typed summary whose phrases `summaryPhrase` builds from the same fields, and typed `{ key, value }` entries for the dry-run and count lines (`setupEntryText`); it never holds the stage plans, file bytes or keys. The launcher's unreachable `setup` branch and `updateVersionedInstall` are removed.
