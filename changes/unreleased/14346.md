### Fixed

- The one-line installer (`curl -fsSL https://get.omo.dev/install.sh | bash`) now installs in a shell whose only user is root, such as proot-distro Ubuntu on Android or a container, instead of stopping with "refusing to run as root". It still refuses `sudo`/`doas` from a normal user, and its message now gives the pipeline-form override `curl -fsSL https://get.omo.dev/install.sh | OMO_INSTALL_ALLOW_SUDO=1 bash`.
