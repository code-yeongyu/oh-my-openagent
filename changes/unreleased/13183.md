**A notice can reach a busy parent's running turn.** `background_task.busyParentWakeDelayMs` (default `60000`, as before; `0` for at once) sets how long a background task or monitor notice waits for a parent whose turn is still running before OMO stores it in the session, where the running turn reads it at its next tool step instead of an extra turn after it.
