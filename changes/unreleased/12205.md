### Fixed

- The fused-path equivalence check no longer reds on a session id that happens to carry no decimal digit. The pinned EQ harness now normalizes a generated entry id wherever it is embedded in another string, so the `EQ.omo E21-E24` comparison holds across runs instead of failing on the one run in a few hundred whose leaf entry id contains no digit. ([#12204](https://github.com/code-yeongyu/oh-my-openagent/issues/12204))
