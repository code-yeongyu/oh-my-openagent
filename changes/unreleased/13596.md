### Fixed
- Thread gateway: the session wake keeps working after the session that started it ends (#13037). The carrier and the delivery consumer are one per agent directory for the whole process, but they used the first session's gateway store, which that session's shutdown closed, so every later wake in the process failed. The running wake now opens its own store for the life of the process.

### Changed
- Thread gateway: the operator daemon declares the delivery consumer as soon as it loads omo, with no session open (#13037 cold wake). `omo daemon run` sends the daemon it ensured senpi's `warm`, so a daemon the device service starts on demand can be handed deliveries before any session runs. A warm that is refused or unsupported prints one line and the run still exits 0.
