### Fixed

- The senpi-task cold-revive residency test is now bounded by the product's own liveness rules instead of a flat 20 s total (Part of #10993). A Windows child that blocks for a while during startup no longer fails it unless the product would also give up, and a real stall fails with the last stage it reached and the stall length. The test's child also reports senpi's startup phase timings, so the next block names its phase.
