### Fixed

- `omo sync` ties the account it records, every pin write and every request it sends (the device listing of `omo sync status` included) to the exact sign-in it started with. A sign-in that replaced the saved one while keeping the device id (other keys, another account, or a new credential generation) no longer gets the earlier sign-in's account recorded on it, a waiting `omo sync enable` no longer publishes its pin under it, and its token is no longer sent beside the earlier sign-in's keys. A sign-in saved by an older version keeps working when its token is refreshed during the run (#12945). ([#13138](https://github.com/code-yeongyu/oh-my-openagent/pull/13138))
