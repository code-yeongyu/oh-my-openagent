### Added

- `/stop all` (or the agent's `stop_session` tool, when the user says "do this, then stop") now also cancels every child task of the session and releases finished children that still hold a resident session, so none continues or is revived after a restart; the stop's report lists each child it ended and any it could not reach. Needs a senpi build with the `session_stop` event (code-yeongyu/senpi#7084); an older engine never fires it. ([#14398](https://github.com/code-yeongyu/oh-my-openagent/pull/14398))

## 2026-11-19 - the task component answers session_stop (#14398)

`components/task/session-stop.ts` `registerTaskSessionStop` subscribes to senpi's `session_stop` (oh-my-openagent#14390): it lists the session's tasks (`parent-session` scope), cancels every one in `CANCELLABLE_STATUSES` (now exported from `commands.ts`) plus finished ones with `residency_state: "resident"` (a later send would revive them) with the reason `session stopped (/stop all)`, and answers `{ stopped, failed }` items of kind `child`; `cancel_pending` (unreachable task host) and a throw are `failed` with the reason, `noop`/`stale`/`not_found` are left out, and with nothing to stop it answers undefined. `index.ts` registers it next to `/tasks`.
