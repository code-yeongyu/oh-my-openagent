### Fixed
- Computer use v3 (`omo-computer-core`): `click` and `mouse.down` now refuse a lone `x` or `y` instead of dropping it. Every public exec verb (the v1 `typeText`, `keyChord`, `holdKeys`, `holdMouse`, `raiseWindow`, `ax.perform`, `ax.focus` and `ax.typeText`, plus `openSystemSurface`) accepts `callId`, `runGeneration` and `observeAfter` and reaches the one exec request shape, and `ax.focus` is no longer decoded as a read. The protocol tests now type-check imported replies that lack a ledgered member and refuse a reader that destructures with only `..`. Nothing user-visible changes yet; the existing desktop engine is untouched. ([#13140](https://github.com/code-yeongyu/oh-my-openagent/pull/13140))
