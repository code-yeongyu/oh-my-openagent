### Fixed

- `thread_send` and other commands to a session on another device no longer answer "unsupported, update omo and senpi" when that device refuses with `engine_capability_missing` and a cause that passes on its own. When the device answers `attach_required` (it lists the session on a route that takes no delegated connections, such as a terminal, and no longer counts this device's attach), omo drops its attach, attaches again and sends the command once more, so the send lands. If the device still refuses, or answers `daemon_unavailable`, the result is `host_unavailable` with the cause in `details.cause` and a retry hint. Only an engine that will never take the command stays `unsupported`. ([#14359](https://github.com/code-yeongyu/oh-my-openagent/pull/14359))
