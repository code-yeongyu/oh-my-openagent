### Fixed

- `thread_send` and other commands to a session on another device no longer answer "unsupported, update omo and senpi" when that device refuses with `engine_capability_missing` and names a transient cause (`engine_unproven`, `daemon_unavailable`). They now answer `host_unavailable` with the cause in `details.cause` and a retry hint; only an engine that will never take the command stays `unsupported`. ([#14359](https://github.com/code-yeongyu/oh-my-openagent/pull/14359))
