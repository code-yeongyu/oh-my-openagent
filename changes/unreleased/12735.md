**omo hands its device keys to the device service from memory, with no credential store read for relay.** A fresh sign-in (`omo login`, `omo account adopt`) deletes the signed-out marker and then hands its in-memory keys and account to a running device service. The memory sync session re-adopts from the credential it already holds when the service reports no adopted device. Every sign-out path (logout, forget, a session the service ended) tells the service to forget the device. The start-up bootstrap no longer reads the stored credential. `device.adopt` carries `account` only to a device service at 0.1.3 or newer, and the pinned device service is raised to 0.1.3 (design D PR 4).
