### Added

- Computer use on macOS: `el.type(text, { delivery? })` types into one accessibility element without taking your focus. A native text field takes the text through its own selection and the value is read back exactly (no key sent, no focus moved, so it also works in an app with several windows); any other element is given app-local focus and receives keys only once the app confirms it holds the focus, and an element that never takes focus is refused with nothing typed and a message naming where the focus is. The result says how the text was delivered (`inserted` or `keys`); a secure field's text never appears in an error. ([#11710](https://github.com/code-yeongyu/oh-my-openagent/pull/11710), part of [#11462](https://github.com/code-yeongyu/oh-my-openagent/issues/11462))
