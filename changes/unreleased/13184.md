### Changed

- **One `monitor` tool replaces `monitor_start`, `monitor_stop`, `monitor_list` and `monitor_output`.** `monitor(description, command, timeout_ms)` wakes the agent with a `[MONITOR EVENT]` notice for every batch of lines and a final `[MONITOR ENDED]`/`[MONITOR EXPIRED]`/`[MONITOR FAILED]` notice, writes all output to a file named in each notice, and is stopped with `background_cancel`. The four old tool names are removed; `docs/reference/monitor.md` maps each old call to its replacement. ([#13184](https://github.com/code-yeongyu/oh-my-openagent/pull/13184))
