### Fixed

- Thread tools: an agent can now reach a session on another device of the same account by its name. A name that matches the title of one live session on another device sends there, and a name shared across devices (or with a thread on this device) is refused as ambiguous with every candidate and its device listed, never picked silently. Claiming or renaming a thread alias on a signed-in CLI device now reaches the account's alias registry instead of always answering that the registry cannot be reached; an alias claimed on one device now reaches that thread from every other device instead of reporting its device offline, and a registry outage never changes how a plain name resolves. `omo thread read` resolves aliases and other devices' threads the way the agent's `thread_read` does. ([#12837](https://github.com/code-yeongyu/oh-my-openagent/pull/12837), fixes [#12833](https://github.com/code-yeongyu/oh-my-openagent/issues/12833))
