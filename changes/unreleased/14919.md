### Security

- omo CLI installs and self-updates verify a detached release signature (Ed25519 over BLAKE2b-512) over each release's SHA256SUMS under compiled-in public keys, and refuse a missing or invalid signature once the signed-release cut-over version is compiled in; the macOS update path additionally requires the expected Developer ID signer. Release checksum lists carry a signed version+channel header, so a mirror cannot replay an older signed release as a newer one.
