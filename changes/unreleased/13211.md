**Two more desktop session actionability tests no longer fail on a stalled host, and fake time in the test harness is now opt-in.** The tests that check the battery refuses a disabled element, or an action the element does not offer, "at once" now check that no fake time passed, instead of a 1 s wall-clock bound.
