### Added

- Computer use (macOS): `computer.apps.list()` lists the installed and running applications, and `computer.apps.open(id, { activate?, reveal?, app? })` opens an application, file, folder or URL without bringing it forward and returns it with the window it shows as a window handle. A relative path names an item in the session's folder. `activate` and `reveal` take your foreground and need the human-confirmed grant (`computer.control.acquire`). When `computer.window(filter)` matches nothing, the error now lists the open windows by app and suggests `computer.apps.open("<app>")`. ([#11719](https://github.com/code-yeongyu/oh-my-openagent/pull/11719), part of [#11463](https://github.com/code-yeongyu/oh-my-openagent/issues/11463))
