**A task whose first model is refused by the task host now starts on the next model in its chain.** When the host refuses to open the child because the model's context window misses the start minimum, or because it cannot resolve the model, the start falls back to the category's next model and the fallback names the window and shortfall. Other refusals still end the start. ([#11343](https://github.com/code-yeongyu/oh-my-openagent/pull/11343), fixes [#10879](https://github.com/code-yeongyu/oh-my-openagent/issues/10879))
