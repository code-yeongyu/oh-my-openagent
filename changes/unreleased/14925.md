### Added

- An agent can live in its own markdown file: `agents/<name>.md` under the engine's agent directory (`~/.omo/agent`) or the project's `.omo`, as well as the pi and Senpi folders, with the `agents.<name>` fields as frontmatter and the prompt as the body. The task tool can spawn it by name, `omo doctor --models` lists it, and an omo.json `agents.<name>` entry still wins over a file of the same name. ([#14925](https://github.com/code-yeongyu/oh-my-openagent/pull/14925))

## 2026-11-25 - Markdown agent files reach the task tool (#14925)

`loadMarkdownAgents` (extracted from `loadAgents`, whose behavior is unchanged) scans `agent/` and `agents/` under the pi and Senpi locations plus the resolved agent home (`resolveAgentHome`) and `<project>/.omo`. `resolveTaskAgents(config, markdownAgents)` and `describeModelChains(config, registry, markdownAgents)` layer them between the builtins and omo.json agents; the omo-senpi task engine and the omo-native doctor runtime (through the new `./agent-loader` subpath) pass them in.
