**Opening a session no longer re-sweeps the memory root.** The memory component's cleanup of abandoned one-shot runs now runs at most once a day per engine process, shortly after an open, instead of inside every session open; a long-running desktop or daemon engine still repeats it daily. A session that ends before that cleanup starts hands it to the next open, so crashed runs are still reclaimed. ([#12896](https://github.com/code-yeongyu/oh-my-openagent/pull/12896))

## 2026-11-09 - The transient memory sweep runs once per process, off the open path (#12896)

`memory/transient-sweep-once.ts` `scheduleTransientSweepOnce` claims each memory root once per `TRANSIENT_RUN_MAX_AGE_MS` (24 h) in a process (a `globalThis` claim map under `Symbol.for("omo.memory.transient-sweep.claims")`; an older claim re-arms on the next open) and starts `sweepTransientMemoryRuns` on an unref'd 1 s timer, so it no longer runs inside `register()` on every session open. Once started, the sweep is still tracked by the session's in-flight work, so the shutdown drain waits on it. `session_shutdown` releases a claim whose sweep has not started yet. `transient-run-lifecycle.test.ts` counts sweeps across five opens (exactly one, none during an open) and checks that a released claim is swept by the next open; `transient-sweep-once.test.ts` checks that a claim re-arms at the 24 h bound and not before it.
