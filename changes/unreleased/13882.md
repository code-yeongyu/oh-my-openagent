### Added

- Computer use v3: the hand host's daemon side. A host now starts the per-user engine daemon with a fresh capability it never writes to disk, serves `hand.ensure` so another process on the machine is admitted only after asking it, answers the engine's `hand.status` with its stop latch, keeps the engine's stop path alive with a heartbeat, restarts a silent engine with backoff, and lifts a stop only from the console. Nothing user-visible changes yet; the existing desktop engine is untouched. ([#13882](https://github.com/code-yeongyu/oh-my-openagent/pull/13882))
