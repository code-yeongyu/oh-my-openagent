### Changed

- `omo login --new-device` is gone. The OmO service keeps one device per computer, so registering another device over an unreadable stored sign-in either failed after approval or left two live devices. When the stored sign-in cannot be read and no device service holds this computer's device, `omo login` now says to remove the device on the Devices page if it is still listed, then run `omo account forget` (which also has the device service forget the device), then `omo login`. When the device service does hold the device, it points to the OmO desktop app instead and does not suggest `omo account forget`.
- When the credential store is locked, `omo login` says to unlock it and try again.
- When the device service is installed but does not answer, `omo login` names the service's leftover endpoint file and says that opening the OmO desktop app starts the service.
