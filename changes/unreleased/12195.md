- A memory-reflection run that the supervisor stops at its time limit is no longer reported as a crash. The reflection child now runs under the supervisor's crash record (`--supervised`), and the supervisor records only deaths it did not ask for, with their real signal. Requires a senpi release with `--supervised`.

## 2026-11-02 - The memory run supervisor owns its reflection child's death record (#12195)

The reflection child is launched as `senpi -p --supervised` (`components/memory/worker/spawn-payload.ts`), so a deadline kill no longer leaves a lifetime marker that the next start turns into an `unclean_exit` crash. `memory-run-supervisor.ts` records an unrequested fatal-signal death itself through `memory-child-death-record.ts`, as `{kind: "print", detection: "parent", signal}` in `process-crashes/crashes.jsonl`, using senpi-task's shared `appendParentCrashRecord`. A deadline kill, a code exit or a SIGTERM shutdown records nothing.
