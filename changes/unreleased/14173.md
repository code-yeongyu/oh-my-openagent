### Fixed

- `thread_read` with a small `max_bytes` now returns the newest messages that fit, ending at the latest reply, on this device and on another one. Before, it filled the budget from the oldest message of the 60-message window, so a 1.5 KB read of a short thread returned only its preamble. `next_cursor` from such a read pages the older messages of the window.

## 2026-11-18 - thread_read budget ends at the newest message (#14173)

- `src/components/thread/read-budget.ts`: `takeWithinBudget` takes `from: "end"`, which fills the budget from the newest entry backward and returns the entries oldest first.
- `src/components/thread/reader.ts`: tail mode fills from the end of its window and issues `t1o` cursors that page the window's older entries; page mode with a `t1` cursor still pages forward.
- `src/components/thread/paged-reader.ts`: `selectEntryPage` applies the same rule to the remote paged read; its `t3` cursors name the oldest returned message and the window's first.
