## 2026-10-27 - claude-code acquires Claude Code on provider_login_start (#11518)

The `claude-code` component handles senpi's awaited `provider_login_start` for `anthropic-subscription`. Through the existing single-flight `ensure()` it acquires the pinned executable before `claude auth login` runs, and maps the download notice and percent lines onto `event.progress`. It resolves early when `event.signal` aborts, while the shared download keeps running for the next caller. Pin, integrity, PATH preference and the turn hooks are unchanged. The payload is a narrow local structural type; the pinned senpi already emits the event (senpi#4436), so the handler is live on the current engine.
