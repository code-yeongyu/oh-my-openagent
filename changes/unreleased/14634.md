### Fixed

- Cancelling a thread tool call now stops it. Every peer thread tool (`thread_read`, `thread_send`, `thread_interrupt`, `thread_create` and the rest) takes the host's abort signal: a call cancelled before it starts runs nothing, and a call cancelled while it waits on another device settles at once as `cancelled` instead of waiting out its 30-50 s command bound. A cancelled call that may already have reached the thread says so, and a retry under the same key answers `idempotency_uncertain`. ([#14634](https://github.com/code-yeongyu/oh-my-openagent/pull/14634), fixes [#13426](https://github.com/code-yeongyu/oh-my-openagent/issues/13426))
