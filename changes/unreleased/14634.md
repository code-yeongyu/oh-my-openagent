### Fixed

- Cancelling a thread tool call now stops it. Every peer thread tool (`thread_read`, `thread_send`, `thread_interrupt`, `thread_create` and the rest) takes the host's abort signal. A call cancelled before anything left this device ran nothing: it answers `cancelled`, and a retry under the same key runs fresh. A call cancelled after its command reached another device answers `cancelled` at once instead of waiting out its 30-50 s command bound; the command's wait ends with it, and the call's receipt records what the command actually did, so a retry under the same key waits for that and then replays it rather than sending again. ([#14634](https://github.com/code-yeongyu/oh-my-openagent/pull/14634), fixes [#13426](https://github.com/code-yeongyu/oh-my-openagent/issues/13426))
