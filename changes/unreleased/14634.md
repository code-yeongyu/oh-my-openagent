### Fixed

- Peer thread tools now answer `cancelled` when the host cancels a call. Cancelling during preparation, before the first write, leaves the thread unchanged and its idempotency key reusable. If a remote open was already sent, the caller stops waiting but the run keeps its connection and records the result. A retry with the same key reports the open in progress or replays that result; it never opens a second thread. ([#14634](https://github.com/code-yeongyu/oh-my-openagent/pull/14634), fixes [#13426](https://github.com/code-yeongyu/oh-my-openagent/issues/13426))
