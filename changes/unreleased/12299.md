### Fixed

- Memory sync: pushing a large memory set no longer needs memory in proportion to the whole set. Every push step used to re-read and re-write one journal file holding every pending item's data, several times per batch, so a device pushing a few thousand memory files peaked at 2 GiB or more (#12286). The journal now keeps a small index of pending items with their data in separate files, and a push reads only the batch it is sending. A journal written by an older build is converted the first time it is read.
