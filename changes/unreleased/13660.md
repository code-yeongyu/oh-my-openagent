### Fixed

- Memory sync: a batch of many small items whose data came to just under 8 MiB could be refused by every other device as too large, because the size check counted only the item data and not the per-item header and file name each record carries. The check now counts what the receiving device counts, so a batch this device sends is never refused for size (#12306). ([#13660](https://github.com/code-yeongyu/oh-my-openagent/pull/13660))
