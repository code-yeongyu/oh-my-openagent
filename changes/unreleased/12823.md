### Added
- macOS live QA: a Chrome two-window typing scenario checks that background typing lands in the second window and leaves the first one untouched and key.
- macOS live QA: a dense-window observe scenario checks that a page with 5,000+ accessibility nodes returns a partial snapshot at the deadline, drills into a cut, and keeps the default skeleton within its token budget.
- The live macOS QA driver's `--list` flag prints every scenario name on any host.
- The live macOS QA driver's `--dense-rows <n>` flag sets how many rows the dense-window page renders (default 2,000).
