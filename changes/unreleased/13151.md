### Security
- Desktop memory sync no longer risks running out of memory on an oversized reply from the sync service. zod moves to 4.6.7 (GHSA-mrhx-c7xc-m3w5: validating a huge array collected one issue per bad element), and every array the sync channel reads is now capped at 100,000 items, so an oversized reply is rejected up front. The senpi engine dependency still carries zod 4.6.5 until omo adopts a senpi release built after senpi#6409. ([#13151](https://github.com/code-yeongyu/oh-my-openagent/pull/13151))
