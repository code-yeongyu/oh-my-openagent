**LazyCodex says when comment-checker is not installed.** A Codex marketplace install (`codex plugin add`) does not install the plugin's npm dependencies, so the comment-checker binary was absent and the PostToolUse hook passed every edit without output. The first edit in each session now adds a notice that edits are not being checked and that `npx lazycodex-ai install` installs the checker; it never blocks.
