### Fixed

- Onboarding failure reasons no longer carry an absolute path or an error's raw text into the onboarding context, the onboarding tools' results or the onboarding RPC replies. A source that cannot be read names only its failure kind (for example `EISDIR` or `not valid JSON`), and a missing onboarding runtime names the missing file (`extensions/omo-onboarding-scan.js`) and the reinstall step instead of the runtime's import error. `omo setup` errors name the failure kind without the file's path. ([#15359](https://github.com/code-yeongyu/oh-my-openagent/pull/15359), fixes [#15352](https://github.com/code-yeongyu/oh-my-openagent/issues/15352))
