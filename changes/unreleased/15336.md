### Fixed

- A long-lived memory repository's `.git` no longer grows without bound. Each sync round leaves a transfer pack behind, and nothing ever merged them, so two hosts reached about 29 GiB in 780 packs for a 112 MiB tree. The memory maintenance pass now folds the packs into one once a repository holds 64 or more, under the same lock and timeout as before, and existing bloated repositories shrink on their first pass. `/memory doctor` now shows the repository's pack count (#15139).
