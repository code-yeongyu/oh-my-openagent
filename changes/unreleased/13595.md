### Added

- `omo remote bootstrap` and `omo remote enable` install one fixed per-user cold-wake unit that runs the omo session host (`omo daemon run` for the registered agent dir): the systemd user unit `omo-session-host.service` on Linux, the LaunchAgent `ai.omo.session-host` on macOS. They record it as the device service's only cold-wake unit, the entry `"omo"` of its `OMO_RELAYD_SERVICES` table, keeping the other entries and restarting the device service only when the table changed. `omo remote disable` removes both, and while remote sessions are off a bootstrap removes them instead of installing them (#13594).
