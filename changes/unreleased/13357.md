**Computer use v3 on Linux: the X11 stop chord, Esc, the self set and the doctor chain.** On X11 the physical stop chord is heard through XI2 raw key events, so an app's keyboard grab cannot swallow it, while synthetic XTEST keys never trigger it. If the listener cannot be armed, every action is refused (`StopPathUnavailable`, reason `deaf`). Esc ends the current lease. A window that belongs to the agent's own terminal, the desktop app, or an engine process is refused as `SelfTarget`. A monitor layout change starts a new epoch, and `omo doctor computer` reports the X11 checks (display, accessibility bus, uinput access, compositor) as ok, missing or unknown. ([#13357](https://github.com/code-yeongyu/oh-my-openagent/pull/13357))
