### Fixed

- Memory sync: signing out of one OmO account and into another on the same computer no longer leaves memory sync stuck. Every push on the new account used to fail with `unverified_base`, because the memory repository resumed the previous account's sync state. Each account now keeps its own: switching accounts sets the previous account's synced memories and sync state aside (switching back restores them), and the new account starts from its own. Memory synced by an older OmO version is kept only when the signed-in account's sync service confirms it synced that memory; if that service shows it belongs to another account, it is set aside rather than uploaded and comes back when that account signs in again. When the service no longer keeps the history that would tell, memory sync says so and uploads nothing until you choose; while the check cannot reach the service, nothing is uploaded or set aside. A switch interrupted by a crash is finished at the next start (#14481). ([#14491](https://github.com/code-yeongyu/oh-my-openagent/pull/14491))
