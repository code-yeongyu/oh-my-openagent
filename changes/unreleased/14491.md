### Fixed

- Memory sync: signing out of one OmO account and into another on the same computer no longer leaves memory sync stuck. Every push on the new account used to fail with `unverified_base`, because the memory repository resumed the previous account's sync state. Each account now keeps its own: switching accounts sets the previous account's synced memories and sync state aside (switching back restores them), and the new account starts from its own. Memory synced by an older OmO version is kept only when the signed-in account's sync service confirms it synced that memory; otherwise it is set aside rather than uploaded, and it comes back when its account signs in again. While that check cannot reach the service, nothing is uploaded or set aside. A switch interrupted by a crash is finished at the next start (#14481).
