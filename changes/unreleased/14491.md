### Fixed

- Memory sync: signing out of one OmO account and into another on the same computer no longer leaves memory sync stuck. Every push on the new account used to fail with `unverified_base`, because the repository resumed the previous account's sync state. That state now belongs to the account it synced: switching accounts sets it aside (switching back restores it), the new account starts its own, and the previous account's memories stay local instead of being uploaded to the new account. Memories you write after the switch sync to the new account as usual (#14481). ([#14491](https://github.com/code-yeongyu/oh-my-openagent/pull/14491))
