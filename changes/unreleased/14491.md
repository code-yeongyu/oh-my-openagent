### Fixed

- Memory sync: signing out of one OmO account and into another on the same computer no longer leaves memory sync stuck. Every push on the new account used to fail with `unverified_base`, because the memory repository resumed the previous account's sync state. Each account now keeps its own: switching accounts sets the previous account's synced memories and sync state aside (switching back restores them), the new account starts from its own, and nothing of one account is uploaded to the other. A switch interrupted by a crash is finished at the next start (#14481). ([#14491](https://github.com/code-yeongyu/oh-my-openagent/pull/14491))
