### Fixed

- Memory sync says why the service refused it (#12123). Settings -> Memory -> Sync across devices showed "The service refused this sync request." for every refusal. A refusal whose code is on the service contract's closed list (`not_available`, `entitlement_required`, `access_not_open`, `device_revoked`, `reauth_required`, `account_deleted`, `client_update_required` and its aliases `client_upgrade_required` and `update_required`) now carries that code on the `refused` problem with OmO's own wording, so the app can tell "not available yet" from an account or device problem. Any other code keeps the generic refusal with no code, and the service's message text never reaches the app. ([#12155](https://github.com/code-yeongyu/oh-my-openagent/pull/12155))
