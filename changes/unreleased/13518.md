### Fixed

- `bun run test:fast` releases the serial quarantine's process group as soon as that phase exits, instead of retaining its PGID for the whole parallel phase where a later signal could reach an unrelated process that reused the id. The child registry now has an explicit `release` for a group whose work is finished, and the serial spawner uses it; the retention that shutdown escalation needs is unchanged. A test also pins that no `ROOT_TEST_SERIAL_QUARANTINE` path falls inside the `opencode-memory` or `senpi` group scopes, so the split's disjointness is checked rather than assumed (#12031).
