**`omo setup` can carry a secret file into the engine config as a reference instead of a copy.** A `{file:...}` or `{env:NAME}` placeholder in an OpenCode MCP server, provider, or credential now becomes a reference object (`{$file: ...}`, `{$env: ...}`, `{$concat: [...]}`) in `mcp.json`, `models.json`, and `auth.json`, and the engine reads it at load time. The secret's bytes are no longer copied into a second plaintext file, and rotating the source file is picked up on the next engine load with no re-import. A field that takes a plain string refuses a reference instead of writing it out as literal text, and a URL field refuses every placeholder. On an engine that does not support reference objects yet, `omo setup` keeps today's behaviour and says so ([#10749](https://github.com/code-yeongyu/oh-my-openagent/pull/10749)).
