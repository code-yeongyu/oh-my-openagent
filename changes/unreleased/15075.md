### Changed

- omo now runs on senpi 2026.11.26 (from 2026.11.23); the bundled plugin and the service-auth table are regenerated for it. What changes through the engine:
  - A session whose opener says nobody answers its prompts (a `thread_create` session) now refuses a permission ask with a reason the model reads, instead of waiting forever.
  - A message another session sends while the previous message's turn is still starting joins that turn, so messages sent together arrive in one turn, in order.
  - `edit` and `write` warn when a JS, TS or JSON file no longer parses after the call, naming the first syntax error and its line.
  - Switching the model from `/model` no longer clears the scrollback and replays the whole transcript.
  - Claude: a second subscription account is no longer lost when a session on an older engine rewrites the accounts, and an account whose refresh was refused asks for a new sign-in instead of retrying every 15 minutes.
  - Sign in with ChatGPT started from a client no longer fails with "requires a device ID".
  - A timed-out (HTTP 408) or reset request retries on the same model before the fallback chain, and DeepSeek DSML leakage triggers a bounded resample.
