### Fixed

- A background child no longer stays running forever after its work is done. When a finished child refuses a follow-up (for example while it is compacting), the task keeps its finished result and the next message revives it normally; before, the record stayed running with nothing tracking it, and the row read `starting` for days. A child whose recorded owner process is gone is no longer deferred to whatever later process the system gave the same pid, and a paused child this session takes back no longer keeps showing `resuming (revival deferred: foreign_live_owner)`. ([#12078](https://github.com/code-yeongyu/oh-my-openagent/pull/12078), fixes [#12077](https://github.com/code-yeongyu/oh-my-openagent/issues/12077))
