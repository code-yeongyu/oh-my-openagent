**One computer is one OmO device: omo login binds to the machine's device service instead of registering its own.** A sign-in now advertises machine binding. When the service asks for the machine hash, omo asks this machine's device service (`device.machine_binding`) for it, and computes the same hash itself when no device service runs. The sign-in presents the device keys this machine already holds, so the service keeps the machine's existing device instead of adding a row. If the device service holds a device whose keys omo does not have (the desktop app's sign-in), omo refuses and points to the desktop app instead of minting a second device. The raw OS machine id never leaves the computer. A computer with no readable machine id signs in exactly as before. Part of sisyphuslabs/omo-service#1016.
