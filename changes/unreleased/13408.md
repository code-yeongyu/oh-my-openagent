### Fixed

- A thread `thread_create` makes on another device is named by its durable id; the relay listing key it returned before answered `not_found` in every later thread tool (#13393).
- `thread_create`'s `cwd`: a relative folder resolves against the caller's folder on this device and is refused on another device, and a folder that does not exist answers `invalid_arguments` naming it, on both devices, instead of `internal_error` or "update omo" (#13400).
- `thread_create` on another device that opened the session but could not name its relay key or apply its name answers the created thread with `thread.warnings` instead of an error, so a retry replays it and a new key cannot create a second session.
- `thread_create { fork_from }` is refused `unsupported` (`details.reason: fork_unsupported`) on both devices instead of opening a blank thread reported as a fork: the engine's `open_session` does not fork yet (#13031).

### Added

- `thread_create { worktree: { branch?, base? } }` creates a git worktree for the new thread, on this device or another one, in OmO's worktrees folder there, and starts the thread in it; every failure (not a repository, branch or folder exists, unknown base, no disk space, no permission, git missing, an older omo on the other device) is a typed code with `details.reason` and a next action (#13408).
