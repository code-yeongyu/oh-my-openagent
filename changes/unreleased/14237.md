### Fixed

- Thread tools: a command for a thread whose session parked on another device after it was listed no longer fails `unsupported` with advice to update omo on that device. The device service answers such a command `route_unlisted` (its host no longer lists that session, so nothing was sent to it). `thread_close` now answers `closed: false, reason: "not_live"`, and the other thread tools answer `not_resumable`, as for a session that ended there. A create, or a reopen's session-file lookup, refused that way is `host_unavailable`, with a retry. ([#14237](https://github.com/code-yeongyu/oh-my-openagent/pull/14237), fixes [#14233](https://github.com/code-yeongyu/oh-my-openagent/issues/14233))
