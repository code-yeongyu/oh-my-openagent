**One memory per repository is now the default, and `/memory-merge` brings scattered memories together.** `memory.auto_identity` defaults to `"git"`, so a session anywhere in a git repository, including every worktree OmO Desktop opens per thread, a subdirectory or a symlinked path, shares that repository's memory instead of starting empty. Memories already written per worktree stay where they are until you run `/memory-merge`, which lists them without changing anything; `/memory-merge --apply` merges each one as a single revertible commit, never touches the repository's `system/` and keeps differing files under `reference/merged/`. `/doctor` lists stores that are still waiting to be merged. `auto_identity: "path"` restores the previous behaviour. ([#10070](https://github.com/code-yeongyu/oh-my-openagent/issues/10070), [#12974](https://github.com/code-yeongyu/oh-my-openagent/pull/12974))
