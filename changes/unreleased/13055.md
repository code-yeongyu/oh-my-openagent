### Fixed

- Computer use reports a click or typed text that went out as window events with its real input route, and judges whether input landed only for multi-event input such as drags, so a single click whose window then closes is reported delivered.

### Fixed

- Computer use flags text typed into a secure field of a background window, and reports how much text was delivered when the user intervenes mid-send.

### Fixed

- On macOS, key priming now bounds and classifies its focus reads, so a slow or failing focus read no longer stalls background typing into a multi-window app.

### Changed

- Computer use now lets the user keep typing and clicking while it works by default (`computer.intervention: "continue"`); set it to `"pause"` to have input wait for the user and stop with `UserIntervened`.

### Fixed

- Computer use keeps holding the machine-wide interaction lock while it hands key focus back after background typing, so another session can no longer type in between.

### Added

- Computer use waits until an accessibility target is actionable before it acts, lists the sheets, windows and menus an action opened, suggests the next call when it refuses, and refuses `cmd+q`, `alt+f4` and `win+l` unless the key chord is forced.
