### Added

- `omo-agent-toolkit config edit` opens an interactive editor for a selected configuration source and shared, harness, or profile view. Edit agent and category model chains and validated settings, then save with preserved JSONC comments, a backup, and the original file permissions. This continues WietRob's [TUI configuration editor contribution (#1529)](https://github.com/code-yeongyu/oh-my-openagent/pull/1529) on the unified configuration format.
