## 2026-11-22 - TypeScript 7 projects get post-edit diagnostics from their own tsc (#14656)

`findServerForExtension` in `@oh-my-opencode/lsp-core` swaps the builtin `typescript` server for the project's `node_modules/.bin/tsc --lsp --stdio` when the `typescript` package beside it has no `lib/tsserver.js` (TypeScript 7 dropped it, so typescript-language-server cannot start there). Only a repo-local `tsc` counts (`resolveServerBinary(..., { localOnly: true })`); a user-configured `typescript` command, project overrides and disabled settings keep their precedence, and the tsserver-specific initialization is not sent to `tsc`. `lsp_status` reports `typescript` installed in such a project. `omo.js` is regenerated. Fixes #14642.
