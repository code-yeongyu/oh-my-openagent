### Fixed

- Memory sync tells the desktop why it is paused or unavailable (#11056). The `sync` field of the `omo.memory.status` snapshot now carries, for `paused`, the refused entry as `refused: { seq, code }` (the verifier's closed refusal code), and for `unavailable`, `unavailable: { code, reason, variable? }` with a closed code (`engine_unavailable` or `config_invalid`) and OmO's own wording. Both fields are optional and add no new state, so an older desktop reads the status as before; the runner's error text stays in its log. ([#13658](https://github.com/code-yeongyu/oh-my-openagent/pull/13658))
