### Added

- macOS computer use now watches the user's own key presses and clicks in each app it works in, so later steps can stop when the user steps in. Every event the engine posts carries an engine tag and is never counted as the user's; dictation and other assistive tools count as the user. `capabilities.interventionWatch` reports `not_started`, `on`, or `off` (no Accessibility trust, or the system refused the watch: nothing is watched, it never prompts, and background input is not held back). The stop-chord tap is unchanged.
