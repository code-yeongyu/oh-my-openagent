### Fixed

- When a dream or reflection run deletes, archives or moves a memory note, `[[path]]` and relative markdown links to it in other notes are now updated in the same run: a moved note's links follow it, a note archived in a run that writes `ARCHIVE.md` is linked as `[[ARCHIVE.md|<old path> (archived)]]`, and links to any other removed note become plain text. `/doctor` no longer reports `audit:link_dangling` after a dream archive. Facts extraction also no longer writes into a month ledger path that was archived or deleted: that month's new facts go to `notes/facts/<month>-2.md` (then `-3`, ...), so an old link can never start pointing at unrelated new content. ([#12642](https://github.com/code-yeongyu/oh-my-openagent/issues/12642))
