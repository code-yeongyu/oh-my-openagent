### Fixed

- When a dream or reflection run deletes, archives or moves a memory note, `[[path]]` and relative markdown links to it in other notes are now updated in the same run, after the completion check has decided which of the run's changes land. A moved note's links follow it, and the moved note's own relative links keep pointing at their targets. A note the run archived, meaning its `ARCHIVE.md` entry names the file, is linked as `[[ARCHIVE.md|<old path> (archived)]]`. Links to any other removed note, such as one the user asked to forget, become plain text. A note the completion check refuses keeps its links as they were, so `/doctor` can still report those. A targeted `/dream --to <doc>` that removes its own target is no longer refused because of these link updates. Facts extraction also no longer writes into a month ledger path that was archived or deleted: that month's new facts go to `notes/facts/<month>-2.md` (then `-3`, ...), so an old link can never start pointing at unrelated new content. ([#12642](https://github.com/code-yeongyu/oh-my-openagent/issues/12642))
