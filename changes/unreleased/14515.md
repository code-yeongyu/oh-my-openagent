### Added

- The omo SDK enrolls a machine reachable over SSH: `enrollDevice({ ssh, onUserCode })` reaches it with key or agent authentication and a strictly checked host key, installs omo when it is missing, signs it in by device code, and waits until it is online in the device list. Each step is recorded and a second call resumes; a refusal names its step and code. ([#14515](https://github.com/code-yeongyu/oh-my-openagent/pull/14515))
