## 2026-11-27 - Usage-limit turns settle in bounded time (#9711)

An announced provider retry is held for its stated delay and then settled, a terminal limit end is no longer dropped while a monitor is live, a spent provider is not called again for each child (also after a limit that ended a turn which had already run a tool), a task routed around a spent model waits for capacity on the model it actually runs, and an ambiguous limit's scope is probed once inside the turn that hit it, with that probe belonging only to its own run.
