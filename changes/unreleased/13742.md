### Added

- Scripts can drive other devices: `import { openRemote } from "omo-ai/remote"` lists devices and one merged session list, and opens, sends to, reads, watches, interrupts, closes and archives sessions on any device. Every call answers data with a typed error code and a next action instead of throwing. See docs/reference/omo-remote-sdk.md.

### Changed

- The `omo-ai` package now declares its exports: only `omo-ai/remote` and `omo-ai/package.json` resolve by package name. A deep import such as `omo-ai/bin/...` or `omo-ai/plugin/...` no longer resolves; the `omo` command itself is unaffected.
