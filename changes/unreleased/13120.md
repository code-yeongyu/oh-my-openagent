### Added
- Computer use v3: the scriptable fake backend lands in `omo-computer-backend-fake`. It provides one scenario format with typed, JSON-pointer refusals for an unknown key, a non-object root, a dangling window and an error-code pair the table does not have; a recording sink that writes every OS-level side effect as one line; a fake clock driven only by `OMO_COMPUTER_FAKE_CLOCK`; timelines for loading indicators, observer events and user input; a fault FIFO whose refusals resolve through the `COMPUTER_*` table; and `macos`, `x11`, `wayland` and `win32` personas. Every scenario field has a fixture and a null control. Nothing user-visible changes yet; the existing desktop engine is untouched. ([#13120](https://github.com/code-yeongyu/oh-my-openagent/pull/13120))
