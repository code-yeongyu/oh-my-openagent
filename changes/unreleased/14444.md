### Added

- Set `OMO_THREAD_READ_TRACE=1` in the caller to diagnose failed local read RPCs. The diagnostic reports the command, last socket phase, elapsed time and error code without printing addresses, credentials or transcript data. It is silent by default and does not change timeouts or retry behavior. Related to [#14444](https://github.com/code-yeongyu/oh-my-openagent/issues/14444).
