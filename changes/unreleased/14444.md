### Fixed

- Concurrent `thread_read` calls of local terminals no longer fail together with `thread RPC request timed out`, `EPIPE` or `ECONNRESET` when another call in the same engine blocks its event loop (a cold remote read, for example). A local socket conversation's deadline now stops while the caller itself cannot run, and a read whose connection the terminal dropped during such a stall, before any response byte arrived, is dialed once more. Other commands are never retried. ([#14444](https://github.com/code-yeongyu/oh-my-openagent/issues/14444))
