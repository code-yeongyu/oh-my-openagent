### Fixed

- A memory save is no longer blocked forever by a leftover git `index.lock` that nothing holds. The writer removes such a lock itself only when every check proves it is debris: no process has it open, no git process works in the repository, it is at least 10 minutes old, and it stayed unchanged for a minute. Anything unproven is still kept and reported. Each removal is recorded and shown by `/memfs status`. ([#13911](https://github.com/code-yeongyu/oh-my-openagent/pull/13911), fixes [#13808](https://github.com/code-yeongyu/oh-my-openagent/issues/13808))
