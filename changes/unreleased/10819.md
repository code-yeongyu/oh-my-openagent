### Changed

- Memory transcript journals that reflection has fully consumed are retired after 7 idle days: the transcript is deleted and only per-message dedupe keys stay, so a resumed session journals only new messages. Unconsumed journals are never removed. This runs in the existing 12-hour memory maintenance pass. `/doctor` adds a `storage` line with bytes per area. Design note: `docs/reference/memory-storage-budget.md` (#10819).
