## 2026-11-12 - model_profile home refusal: directory outage and relative PATH (#13292)

`runPasswdLookup` maps getent exit 2 to "no such account" only when the `passwd:` line of `/etc/nsswitch.conf` names local sources alone (`files`, `systemd`, `altfiles`; a missing file or line counts as local), and never maps macOS `id -P` "no such user" to it, because both tools give that answer when a directory service is unavailable. This account's own missing entry is handled like a failed lookup: folders at or above HOME are refused. The lookup binary comes from `/usr/bin`, `/bin` or `/usr/sbin` first, then from absolute PATH entries only (`findOnPath` option `absoluteOnly`; the claude-code callers keep their behavior). Must not break: a bind-mounted project below HOME stays allowed; another account's home is still refused when its entry is found.
