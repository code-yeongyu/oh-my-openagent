**Each memory identity's runtime directory is capped at 2 GiB, and `omo doctor` and `/doctor` show how much it holds.** After retention, the 12-hour memory maintenance pass evicts oldest-first until the identity fits `memory.runtime.max_bytes` (default 2 GiB, `0` for unbounded, per-agent overridable under `memory.agents.<id>.runtime`). It removes folded reflection runs first, then the transcripts of fully reflected sessions, idle sidecars, and finally old failed runs beyond the newest ten. Journals that were never or only partly reflected are kept by default; `memory.runtime.discard_unreflected_journals: true` lets the cap evict them too, and only while reflection is succeeding on the identity. Live sessions, in-flight runs and the run-id high water are never touched. `omo doctor` prints each identity's runtime size and the total, and warns when an identity reaches 80 % of its cap. `/doctor` adds a `runtime-size` check with the largest stores and what retention would still free.
