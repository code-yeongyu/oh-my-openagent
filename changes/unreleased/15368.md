### Fixed

- On macOS and FreeBSD without `bun:ffi`, a memory reflection launcher or memory run whose process id an unrelated program took over is now recognized as gone even when an older omo version recorded its start time. It used to count as alive until that program exited, which kept its reflection lock held.
