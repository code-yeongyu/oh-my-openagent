**A category's `max_tokens` now limits the delegated model's output.** `categories.<name>.max_tokens` is the documented key and `maxTokens` is only its deprecated alias, but the delegation path read the alias alone, so a category that set `max_tokens` had it silently ignored and the child ran with the provider's default output limit. `max_tokens` is read first, with `maxTokens` kept as the fallback. ([#10302](https://github.com/code-yeongyu/oh-my-openagent/pull/10302))
