**Slow language servers can have more time to publish fresh diagnostics.** Set `OMO_LSP_DIAGNOSTICS_FRESHNESS_TIMEOUT_MS` to a positive integer in milliseconds to override the three-second freshness wait; explicit client options still take precedence. Restart an existing LSP daemon after changing the value. Cancelled waits release their timers and document waiters immediately, and the standalone Codex LSP manifest also forwards the setting.
