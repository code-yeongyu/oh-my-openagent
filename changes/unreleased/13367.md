### Added

- Computer use v3: the session crate's side-effect funnel lands. Every mutating call runs the gate, writes a pre-input marker before the first OS call on every transport, performs the call, reads back and writes one audit event per side effect; a crashed call is never resent and reads `delivery_uncertain`. Audit, lock, permits, batches and artifact retention come with it, and a typed secret is audited by length only. Nothing user-visible changes yet; the existing desktop engine is untouched.
