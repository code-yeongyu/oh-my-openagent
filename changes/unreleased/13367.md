### Added

- Computer use v3: the session crate's side-effect funnel lands. Every mutating call runs the gate, writes a pre-input marker before the first OS call on every transport, performs the call, reads back and writes one audit event per side effect; a crashed call is never resent and reads `delivery_uncertain`. Audit, lock, permits, batches and artifact retention come with it, and a typed secret is audited by length only. Nothing user-visible changes yet; the existing desktop engine is untouched. ([#13367](https://github.com/code-yeongyu/oh-my-openagent/pull/13367))

### Changed

- Computer use v3: on Windows, one user's two logon sessions take turns at the computer instead of acting at once: the interaction lock is now the operating system's file lock on `%LOCALAPPDATA%\OmO\ComputerControl\run\interaction.lock`, in a directory only that user and SYSTEM can open, on a local NTFS or ReFS volume. A session without a runtime directory cannot act on a real machine; it can still read. ([#13367](https://github.com/code-yeongyu/oh-my-openagent/pull/13367))
