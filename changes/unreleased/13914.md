### Fixed
- A launch of the standalone `omo` binary prunes only old runtimes of its own release channel. It no longer deletes a source-built (`0.0.0-*`) runtime or another channel's runtime from `~/.omo/binary-runtime`, so the next run of that build no longer fails with `ENOENT`. A stable build no longer removes beta runtimes. ([#13914](https://github.com/code-yeongyu/oh-my-openagent/pull/13914))
