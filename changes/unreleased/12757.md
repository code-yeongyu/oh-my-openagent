**Category children run on the Claude subscription when an Anthropic API key is also connected.** The `architect`, `artistry`, `unspecified-low` and `unspecified-high` defaults name `anthropic/<model>`, and that literal used to win over the chain, which lists `anthropic-subscription` first, so the child ran on (and was billed to) the API key. The default now follows its chain rung's provider order. An empty prepaid balance ("Your credit balance is too low", "Insufficient credits") is recorded as an out-of-credit billing refusal, not a usage limit, and the task's error says to add credit or remove the key. ([#12753](https://github.com/code-yeongyu/oh-my-openagent/issues/12753))

## 2026-11-07 - Category defaults follow the chain's provider order; an empty credit balance is a billing refusal (#12753)

`resolveCategory` passes the builtin default through `chainOrderedDefaultModel` (`model-chain.ts`): when the default's own provider serves it and an earlier provider of the same chain rung also does, the earlier provider is selected. A default whose provider is absent still falls through to the chain unchanged. `credential-failure.ts` adds `isOutOfCredit`: such a message is no longer a usage limit, the runtime walk still tries other providers first with no `limit` scope, and the terminal text names the credit balance. `model_refusals[].reason` gains `billing` ("out of credit"), also used for the engine's `billing` hop reason; older builds drop the unknown reason when they parse a record.
