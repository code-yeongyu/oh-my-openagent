### Fixed

- Memory sync: creating a recovery phrase now checks the sync service's own answer on whether it accepts recovery-phrase keys, read fresh through the signed-in session for every creation. Before this the host never wired that check, so a recovery phrase could not be created even where the service accepts one. A refused, absent, unreadable or signed-out answer still refuses before any words are shown or anything is written. ([#13646](https://github.com/code-yeongyu/oh-my-openagent/pull/13646), fixes [#13631](https://github.com/code-yeongyu/oh-my-openagent/issues/13631))
