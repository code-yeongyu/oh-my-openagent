### Fixed

- A memory repository created by an older omo no longer keeps that release's git hooks: every memory write moves an omo-installed hook forward first, so a note carrying the `provenance` claim receipt is no longer refused by a stale key allowlist. A hook omo did not install is left as it is, and `/memfs repair` names it. When a commit hook does refuse a write, that write is rolled back and fails alone with a typed reason, so it no longer leaves the repository dirty and blocks every later memory write. Thanks to @CarlosCommits. ([#12226](https://github.com/code-yeongyu/oh-my-openagent/pull/12226))
