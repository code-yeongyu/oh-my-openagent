### Changed

- The omo SDK root (#15031): the thread core now ships in its own runtime file, `runtime/omo-sdk/threads.js`, which the root loads on the first thread call. A script that never makes a thread call no longer loads the thread core. If that file is missing or cannot be loaded, every thread call answers `internal_error` with details `{ reason: "runtime_file_unavailable", file: "threads" }`; account, device and configuration calls keep working; and the next thread call tries the load again. The exception itself goes only to the root's local logger port.
