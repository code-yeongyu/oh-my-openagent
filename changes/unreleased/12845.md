### Fixed

- `omo remote send --json` now prints one typed result on stdout for every exit: a `--steer` with nothing running is a typed `not_steerable` error, and a send whose turn ends before it settles prints the send's fields under `kind: "unsettled"`, with the text it streamed and how the follow ended (`ended`), so a consumer that reads only `kind` never takes it for success.
