### Fixed

- Computer use on X11 no longer reports a background click, scroll, drag, typing or key chord as delivered when the target app drops synthetic input (GTK 3/4, Qt, LibreOffice, Chromium, Electron and Firefox apps whose window class names no toolkit, or xterm without `allowSendEvents`). Background input now goes only to apps whose toolkit is known to accept it (Xt, Motif, Tk); any other app is refused before anything is sent, with the element action and foreground delivery offered as the next step. ([#13736](https://github.com/code-yeongyu/oh-my-openagent/pull/13736), addresses [#9109](https://github.com/code-yeongyu/oh-my-openagent/issues/9109))
