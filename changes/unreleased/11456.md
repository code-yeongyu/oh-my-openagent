**The opencode edition's skill tool no longer repeats skill descriptions OpenCode already lists.** A skill is left out of the skill tool's item list only when OpenCode core's own skill list has the same skill (same name, same file) with a description, so its description is sent once per request instead of twice. Skills core does not list (flat `.md` skills, skills without a name or description, skills core skips because of its disable flags or a custom Claude config dir, OMO-bundled skills) stay in the skill tool's list, and when core's list cannot be read nothing is left out. ([#11456](https://github.com/code-yeongyu/oh-my-openagent/pull/11456))
