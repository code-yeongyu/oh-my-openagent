**Models released after this build now resolve from the refreshed capability cache.** `refresh-model-capabilities` and the startup refresh wrote models.dev's catalog to `model-capabilities.json`, but nothing read it at runtime, so a new model such as `kimi-for-coding/k3.1-pro` stayed `unknown` however recently the cache was refreshed. The cache is now consulted before the bundled snapshot; a missing, malformed, or older-than-bundled cache is ignored.
