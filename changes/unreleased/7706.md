### Fixed

- OpenCode runtime fallback hops when a provider failure arrives as `UnknownError`. `retry_on_errors` used to match only numeric HTTP codes, so an expired-auth or unexpected-server-error wrapped as `UnknownError` never switched models. The scoped classifier now treats those wrapped messages as retryable, so configured `models[]` still hop. Thanks @RaviTharuma. ([#7706](https://github.com/code-yeongyu/oh-my-openagent/pull/7706), fixes [#7702](https://github.com/code-yeongyu/oh-my-openagent/issues/7702))
