### Changed

- The thread tools now check which devices are signed in and online, and which device they run on, through the one remote module, which reads them in one round where it used to take two or three. Naming a thread on another device no longer reads the device list at all. A device list that cannot be read now answers "device service unavailable" with the reason, instead of failing the tool. The remote module can also look up a session on any device by its id, its name, or `<device>/<session>`, without listing the account again for a session it has already seen.
