### Added

- The thread SDK runtime (`runtime/thread-sdk/sdk.js`) exports `attachRpcSession`. It attaches a raw single-session pi-RPC stream to one session on a running shared host: open a new session or attach by durable id; read this session's records, with the routing `sessionId` removed; send commands, or raw JSONL bytes, that are tagged for the session; then detach by releasing or closing the session. The SDK authenticates and frames the connection itself, so an integration that relays a session to another client carries no protocol code. Every failure is answered as data (#15238).
