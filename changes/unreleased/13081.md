**A monitor command runs through the shell, so loops and pipes work.** `monitor_start` split the command into argv and spawned it directly, so `for i in 1 2 3; do ...; done` failed with `Executable not found in $PATH: "for"` and `tail -f log | grep ERROR` passed `|` to `tail`. The command now runs through the same shell OpenCode's `bash` tool uses. ([#13081](https://github.com/code-yeongyu/oh-my-openagent/pull/13081))
