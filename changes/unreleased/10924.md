### Fixed

- Memory facts extraction no longer loops until its deadline when a model fills the optional `person` field on a project fact with an empty placeholder: the placeholder is dropped and the fact is recorded, while a project fact naming a real person is still refused. A model that resends a refused `record_fact` call unchanged now ends the run with the facts it already recorded, and a parked queue entry no longer holds back that conversation's later entries (#10918).
