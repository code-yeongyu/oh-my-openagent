### Fixed

- Standalone `omo update` now installs the release instead of printing a curl command (#13084). It downloads the matching platform asset from get.omo.dev with GitHub fallback, verifies published SHA256SUMS and the existing macOS signature, stages beside the installed executable, and keeps a rollback copy until the installed `--version` succeeds. Failures report a typed error; an unwritable directory is refused without partial files. Windows rollback files still held by a running process are cleaned on a later launch. `--dry-run` and `--print` remain print-only.

### Added

- Interactive standalone release launches now check and install updates asynchronously through the same verified updater. Offline mode and `OMO_SKIP_VERSION_CHECK` (including legacy Senpi/Pi equivalents) disable this startup check. Maintainer builds, headless commands and directly invoked provisioned runtime copies never auto-update.
