### Fixed

- Memory git no longer inherits `GIT_CONFIG_*`, `GIT_CONFIG_PARAMETERS` or repository redirection (`GIT_DIR`, `GIT_WORK_TREE`, ...) from the environment it was started in, so an exported git config pair can no longer silently skip the memory repository's hooks and mirror push or point memory git at another repository. ([#12360](https://github.com/code-yeongyu/oh-my-openagent/pull/12360), fixes [#12354](https://github.com/code-yeongyu/oh-my-openagent/issues/12354))
