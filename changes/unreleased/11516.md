### Fixed

- Computer use on macOS: a background input call that already sent part of its input (some keys of a typed string or chord, a click, an accessibility press or value write) and was then refused now reports `InputFailed` ("earlier input of this call may already have landed, so inspect the target before retrying") instead of `BackgroundUnavailable`, so the host never reruns it in the foreground and repeats input that landed. Key chords now check stop and cancellation before every key press and release the keys already down. ([#11516](https://github.com/code-yeongyu/oh-my-openagent/pull/11516), part of [#11461](https://github.com/code-yeongyu/oh-my-openagent/issues/11461))
