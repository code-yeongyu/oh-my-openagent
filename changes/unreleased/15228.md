### Added

- Computer use on sway/wlroots: a new backend drives the `computer` tool where no RemoteDesktop portal exists. It is selected only when `$SWAYSOCK` has a live listener and no RemoteDesktop portal is on the session bus, so GNOME, KDE and Hyprland keep the portal backend. Displays and windows come from sway IPC, capture from `grim`, keys from `wtype` and the pointer from a `zwlr_virtual_pointer_v1` client. The stop chord needs one sway line, `bindsym Ctrl+Alt+Shift+Escape exec true`. Background-window input, modifier clicks and plain Alt chords are refused. ([#15228](https://github.com/code-yeongyu/oh-my-openagent/pull/15228))
