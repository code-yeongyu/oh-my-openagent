### Changed

- `/memory-merge` no longer refuses a whole memory store because one source entry cannot be placed safely (a name that is not a plain path, a destination already on disk, or a path through a link). The rest of the store merges, that entry writes nothing and is listed in the result with its reason, and the store is not marked fully merged until it is resolved (#13203).

### Fixed

- A cleanup failure after a refused `/memory-merge` no longer hides the original refusal (#13203).
