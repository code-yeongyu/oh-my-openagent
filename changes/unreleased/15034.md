### Fixed

- The Codex installer copies the plugin tree, the root CLI runtime and the bundled MCP runtimes with a synchronous directory walk instead of node:fs `cp`, and lists the cached plugin synchronously when it materializes links, checks entry types, collects `package.json` files and scans prompt files. Under Bun the async calls stat'ed, chmod'ed and listed every file through a thread pool, so one install from a source checkout took tens of seconds on a busy machine; it now takes a few seconds, and the installed files are unchanged.
