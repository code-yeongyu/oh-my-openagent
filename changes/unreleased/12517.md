A reflection lock left behind by a run whose processes died (launcher killed before the run started, supervisor and child gone with no outcome, an unreadable run ledger, or a torn `active.lock`) is now released at session start, on the next turn, and by the new `omo doctor --fix` (`--dry-run` to preview, `/doctor --fix` in a session), instead of keeping every later reflection queued; `omo doctor --fix` also reclaims runtime locks whose owner is gone. ([#12517](https://github.com/code-yeongyu/oh-my-openagent/pull/12517))
