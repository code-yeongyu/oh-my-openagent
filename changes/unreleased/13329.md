**A signed-out desktop no longer looks like a memory-sync error to the engine.** When the desktop had no signed-in account, the engine's main thread treated the desktop's refusal as a broken channel and the sync runner reported an error; it now reads it as signed out, as session Workers already did, and picks up the account once you sign in.
