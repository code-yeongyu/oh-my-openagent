**`omo update` authenticates its GitHub release lookup.** The standalone updater uses `GH_TOKEN`, falling back to `GITHUB_TOKEN`, so a valid token avoids an exhausted anonymous API quota. Whitespace-only values count as unset. If GitHub rejects the token with HTTP 401, the updater retries once anonymously instead of blocking an update that could otherwise succeed. Failed retries identify the token variables without exposing credentials.
