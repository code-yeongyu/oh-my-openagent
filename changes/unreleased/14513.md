### Added

- The omo SDK signs a machine in by device code and renames a device: `account.signIn({ onUserCode })` shows the code once through the caller's callback, waits for approval and answers the new device, or a typed refusal such as `device_limit` (with the live devices; nothing is removed) or `machine_exists`. `devices.rename({ id, name })` renames one device. `omo account sign-in` drives the same function and prints JSON lines only, so an enroll call on a new machine can read the code before the approval it waits for. ([#14513](https://github.com/code-yeongyu/oh-my-openagent/pull/14513))
