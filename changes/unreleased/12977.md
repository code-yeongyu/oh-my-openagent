**OpenCode goal continuation no longer fires after you abort a turn.** Pressing Esc while a goal is active used to queue a `goal:idle-continuation` prompt about a second later, which could fail with `FOREIGN KEY constraint failed`. The goal hook now skips on the same signals the todo continuation already respected: an abort, an aborted last reply, an unanswered question, or a turn that is still open. It logs the reason and keeps the goal active, so your next message resumes it. `get_goal` and `update_goal` also work in a session resumed with `-s` without passing `session_id`.
