### Added

- `/memory cleanup` reports the duplicate, superseded, stale and conflicting notes in a memory repository together with the `system/` token delta, as a dry run by default; `--apply` archives the retired notes into `ARCHIVE.md` with their reason, successor and evidence, merges a duplicate's distinctive paragraphs verbatim into the kept copy, marks conflicting notes on both sides instead of picking a winner, repoints inbound links, and commits once. Nothing is deleted, `system/persona.md` and `system/human.md` stay untouched unless `--include-load-bearing`, and a second run changes nothing. The same pass is available to code as `planMemoryCleanup` / `applyMemoryCleanup` / `renderMemoryCleanupReport` in `@oh-my-opencode/memory-core` (#12931).
