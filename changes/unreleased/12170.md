### Fixed

- Background task notifications cap each embedded provider error at 2,000 characters with a `... (truncated, N chars)` marker. A provider that returned a huge error used to paste it into the parent session once per failed attempt, in the retrying, retry-ready, attempt-timeline, status and error fields, and could overflow the parent's context window. The stored task error keeps the full text. ([#12170](https://github.com/code-yeongyu/oh-my-openagent/pull/12170), fixes [#8325](https://github.com/code-yeongyu/oh-my-openagent/issues/8325))
