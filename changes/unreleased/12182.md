### Fixed

- A runtime fallback now keeps the next rung's `reasoning` level. Background-task retries and the model-fallback hook used to send only the rung's `variant`, so a chain written with per-rung `reasoning` ran its fallback model at no level; the level is now lowered for the fallback model the same way the first attempt does it. ([#12182](https://github.com/code-yeongyu/oh-my-openagent/pull/12182), fixes [#9918](https://github.com/code-yeongyu/oh-my-openagent/issues/9918))
