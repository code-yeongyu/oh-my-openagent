### Added

- `look_at` and `task` take an optional `provider` (`"openai"` or `"anthropic"`) once `provider_models` holds a pin set. The child then runs on that provider's pinned model for the agent or category, with no fallback chain, runtime fallback or ultrawork override, and the call fails with the missing `provider_models.<provider>.<agents|categories>.<name>` key instead of using another provider.
