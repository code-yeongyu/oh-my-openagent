### Removed

- Thread bindings are gone (#14312). `omo thread` keeps `list`, `send <target> <text>` and `read`; `bind`, `unbind`, `rebind`, `bindings`, `report`, `answer`, `outbox`, `ack`, `send --binding` and the `--author-*` flags are unknown now. The thread SDK (`runtime/thread-sdk/sdk.js`) loses the same methods, and `send` takes exactly `{ thread, text, mode?, expected_turn_id?, all_scope?, idempotency_key? }`. The agent tools `thread_report`, `thread_outbox`, `thread_outbox_ack` and `thread_answer` are gone, as are the store-extension helpers `bind`, `unbind`, `rebind`, `bindingsForSession`, `enqueue`, `outboxAck` and `outboxPending`. Gateway schema v16 drops the `outbox`, `outbox_cursors` and `completion_arms` tables, and `bindings` only once it holds no rows: until then an extension reads its old routes through the read-only `bindingFor`, so upgrading omo before the connector has imported them loses none. A connector keeps its own chat-thread-to-session map and sends by session id.

### Fixed

- The thread SDK refuses an argument key an operation does not read (a misspelt `allScope`, say) as `invalid_arguments` naming it, instead of ignoring it (#14316).
