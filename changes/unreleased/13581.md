### Fixed

- Listing a thread endpoint that stopped answering reads its leftover claims and the session files they name asynchronously and one at a time, so a host that died holding many sessions neither blocks the engine's event loop nor runs it out of file descriptors while `thread_list` runs. Endpoints are still listed together, so the files open at once are bounded by the number of endpoints, not by the number of stale claims. ([#13581](https://github.com/code-yeongyu/oh-my-openagent/pull/13581), fixes #13579 and #13584)
