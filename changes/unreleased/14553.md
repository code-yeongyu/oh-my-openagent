### Fixed

- The `memory` tool no longer hangs a session when a write stalls. Escape now cancels it, and every call ends within a deadline with an error that names where it stopped (waiting for the lock, editing the file, committing to git, ...). ([#14546](https://github.com/code-yeongyu/oh-my-openagent/pull/14546))
- The `omo remote attach` identity test now awaits the attach endpoint's own close before checking that its directory is gone, instead of watching the temp directory with a fixed 2 s timer, so a loaded macOS runner no longer fails it with `attach endpoint was not removed`. Test-only; no behavior change. ([#14530](https://github.com/code-yeongyu/oh-my-openagent/pull/14530), fixes [#14528](https://github.com/code-yeongyu/oh-my-openagent/issues/14528))
- The DAG e2e ordering case runs the real task manager on an in-memory task record store held to the file store's contract, and both DAG stores name the session-capacity lock through one shared path builder, so host disk latency no longer times the case out. ([#14503](https://github.com/code-yeongyu/oh-my-openagent/pull/14503))

### Added

- The `visual-qa` skill checks behaviour as well as look: state and flow captures (a held request, a failure, re-entry, a switch of target, a repeated press), checklist items H12-H19 for them, and a fourth verdict, UNVERIFIED, for anything that could not be observed. An UNVERIFIED item on a changed state or flow keeps the surface from a GOOD verdict. ([#14545](https://github.com/code-yeongyu/oh-my-openagent/pull/14545))
- The `frontend` skill asks for a state table before the code on any screen with a request, saved state or a multi-step flow, and its States rule now requires each state to be true: a failed or unfinished read is shown as unknown, never as empty. ([#14545](https://github.com/code-yeongyu/oh-my-openagent/pull/14545))

### Changed

- Listings of another device's sessions now ask its device service for listing rows 7 first and step down one version at a time to rows 2 when it refuses. A service at relayd 0.1.46 or later then sends each row's holder retry wait (`waiting`, rows 6) and engine version (`engine_version`, rows 7). An older service answers as before. ([#14511](https://github.com/code-yeongyu/oh-my-openagent/pull/14511))
