**Computer use v3 on macOS: window frames, Spaces and epochs.** Moving or resizing a macOS window writes only the axes that differ and answers the frame read back; a full-screen or unmovable window is refused with nothing written. Minimizing and resizing need no lease, while restoring does and is confirmed by reading the minimized state back. Window queries include sheets, popovers and windows on other Spaces without ever switching Spaces. A change of display layout, backing scale, active Space, session lock or display sleep is reported once per source as an epoch change. The display is kept awake with a power assertion exactly while the session holds it. Installed and running apps are listed together, de-duplicated by bundle id, and opening an app never activates it unless asked. ([#13899](https://github.com/code-yeongyu/oh-my-openagent/pull/13899))
