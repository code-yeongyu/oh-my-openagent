**Research fact locators now bind to original snapshot bytes.** Source snapshots retain the fetched bytes as `raw.bin`; a `--text` file alone becomes a converted-only source that supports warned quotations but no measured rows, and `--raw <bytes> --text <extraction>` keeps the original next to a declared extraction. Page locators read only reader-visible text nodes (never attributes, scripts, styles, or hidden elements), record byte offsets in the source's own encoding, and `fact verify` fails closed when a cited snapshot cannot be read. The new `source refresh` command repins a re-fetched source and re-anchors its rows by quote and context; a legacy row on a refreshed source is listed as not re-anchored and blocks verification instead of passing unchecked.
