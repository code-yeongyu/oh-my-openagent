### Fixed

- `config migrate` keeps the `models` chain of a category that also carries a leftover `fallback_models` key. `models: [A, B]` with `fallback_models: [C]` used to become `models: [C]`, so the old fallback became the primary model, and an empty `fallback_models` left the category with no model at all. The chain now becomes `[A, B, C]`, as it already did for agents (#8191).
