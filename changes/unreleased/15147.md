### Added

- Computer use v3 on Windows: capture, displays and OCR, and a Windows live driver for QA. A window is captured through Windows Graphics Capture with a PrintWindow fallback, and a near-black PrintWindow frame is rejected. An elevated window is captured through WGC only and otherwise refuses `CAPTURE_UNAVAILABLE` (`elevated_target`). A null or near-black frame while the session is known to be inactive or the display asleep answers `CAPTURE_FAILED` (`null_frame` or `black_frame`). Displays report their per-monitor scale, and OCR stays out of the default observation. `script/qa/computer/windows.ts` prints one `SET` line counting pass, fail and blocked, and a host the scenario cannot admit counts as blocked. Nothing user-visible changes yet; the existing desktop engine is untouched. ([#15147](https://github.com/code-yeongyu/oh-my-openagent/pull/15147), supersedes [#13348](https://github.com/code-yeongyu/oh-my-openagent/pull/13348))
