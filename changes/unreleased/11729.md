### Changed

- Computer use on macOS: `el.setValue(text)` on a native text field, text area or combo box now writes the text through the field's own editor (focused only when the app is in the background, whole value selected, text inserted, value read back exactly, focus handed back when nothing was written) instead of an `AXValue` write some apps echo without taking; every other `AXValue` write is read back exactly, web content and terminal apps are refused before any write, and a secure field's text never appears in an error. ([#11729](https://github.com/code-yeongyu/oh-my-openagent/pull/11729), part of [#11462](https://github.com/code-yeongyu/oh-my-openagent/issues/11462))
