### Fixed

- A script using the thread SDK (or `omo thread send`) can now message a session on another of your devices. Another device's engine accepts no command-line delivery from a different machine, so these sends answered `unsupported` (`sender_not_allowed`). They now go the way `omo remote send` does: the text arrives as your own input, and the result names the device that answered. Sends to sessions on the same device are unchanged. ([#14668](https://github.com/code-yeongyu/oh-my-openagent/pull/14668), fixes [#14616](https://github.com/code-yeongyu/oh-my-openagent/issues/14616))
