**Memory sync names the last unexplained "authority is unavailable" causes, and its log stays free of memory text.** When closing a sync operation, releasing its claim, or the request handler itself failed, Settings still showed the bare "Memory sync authority is unavailable." with nothing in the log. These now carry a code (`close_failed`, `release_failed`, `handler_failed`) and log a warning. Logged errors name the error type, not its message; only a sync service error keeps its service code and status, because other messages can quote memory content. A device or pending-request read whose failure returns after the service refused a request is logged again. Carried by the next train top's bundle regeneration.
