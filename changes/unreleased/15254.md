**A task child that runs outside the parent process keeps its agent's tool limits and instructions.** A child whose agent denies a tool, allows only some, or has its own instructions used to get none of them when it ran as its own process or as a session of the task daemon, so a denied tool was callable. It now gets all three, on start and when it is revived. On a task daemon that cannot hold them yet, a new child runs as its own process where they apply, and a child already recorded on that daemon waits for it to be upgraded (`host_persona_unsupported`) instead of reopening without them.
