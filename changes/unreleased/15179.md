**The `git-master` skill is now `git`, rewritten for eval cells, and `git-master` keeps working.** The skill teaches the git CLI through a small `Bun.$` helper (a failed step stops the cell, reads run together), staging only named paths, worktrees, base sync, push preconditions, and handing the pushed head SHA to the `github` skill. `load_skills=['git-master']`, `/git-master`, `/skill:git-master`, `disabled_skills: ['git-master']` and a read of an installed `.../git-master/SKILL.md` path all resolve to `git` through one alias table. The `git_master` config section and its keys keep their names. `git_env_prefix` is now stated in a form both an eval cell and a shell line can carry (`.env({ ...process.env, GIT_MASTER: "1" })` on `Bun.$`, a prefix on a `tool.bash` line) instead of a per-command text prefix `Bun.$` ignores, and the commit-attribution directive is the same short block on every harness. The PR-body evidence attachment section left this skill; it moves to the `github` skill (#15044). ([#15050](https://github.com/code-yeongyu/oh-my-openagent/pull/15050))

**Scripts can drive your devices with `omo-ai/remote`.** `import { openRemote } from "omo-ai/remote"` gives a script the same remote client `omo remote` uses: list your devices and sessions, open, send, read and close, with typed answers instead of exceptions. The omo SDK's device list now comes from that same client. (#13413, #14881) ([#14881](https://github.com/code-yeongyu/oh-my-openagent/pull/14881))
