### Added

- Hosts that omo starts in RPC mode now carry an omo presenter account authority and enforce presenter accounts: a presenter signed in to the same omo account can enroll, and a signed-out host refuses it with `presenter_account_unavailable`. Sign-out (`omo logout`) and an account switch revoke enrolled presenters. Hosts started by `omo daemon run` on the npm install are not covered yet ([#12611](https://github.com/code-yeongyu/oh-my-openagent/issues/12611)). ([#12618](https://github.com/code-yeongyu/oh-my-openagent/pull/12618), part of [#12399](https://github.com/code-yeongyu/oh-my-openagent/issues/12399))

## 2026-11-06 - Presenter account authority for omo-launched RPC hosts (#12618)

Hosts that omo starts in RPC mode register an omo presenter account authority before the engine starts and run with presenter-account enforcement on. A signed-out host refuses account presenters with `presenter_account_unavailable`; sign-out and an account switch revoke enrolled ones. Daemon-started hosts on the npm install are tracked in #12611.
