### Fixed

- A thread on another device reports its working folder as `cwd`, not just the folder's name. `thread_list` with `all_scope`, a `thread_create` reopen whose engine answers without a cwd, and a `thread_handoff` or `thread_send` by name all now read the device's listed path, and fall back to the folder name only when the device could not name the folder. Before, they printed the bare folder name, which read like a relative path. ([#14458](https://github.com/code-yeongyu/oh-my-openagent/pull/14458), fixes [#14429](https://github.com/code-yeongyu/oh-my-openagent/issues/14429))
