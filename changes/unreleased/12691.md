**`/extended-context` toggles eligible ChatGPT subscription models between their existing windows and the maximum reported by the subscription catalog.** It reads the catalog with the session's OAuth credential, maps model IDs to slugs using only the catalog's `-fast` and `-ultrafast` variants, and writes context-window overrides in `models.json`. Existing user-set windows are left alone. A second invocation removes only the unchanged values written by the command.

The prompt budget is calculated as `max_context_window - maxTokens`, following senpi's catalog calculation. Windows only increase; existing model budgets above the calculated value are retained. The catalog reports the same maximum for several models, so that reported maximum should not be treated as an independently verified per-model limit. Requests use the engine's `hostVersion` and an `omo/<hostVersion>` User-Agent. If the engine does not report its version, the command refuses rather than inventing one.

`models.json` is checked before writing, edits preserve comments where possible, and a write that would remove comments is refused. Writes are atomic and concurrent toggles are prevented. `on` and `off` are explicit; a bare invocation toggles.
