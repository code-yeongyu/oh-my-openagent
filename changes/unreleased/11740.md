### Changed

- Computer use on macOS: background keyboard input reaches a window of a multi-window app once the app proves the keys go there (the window is made key without raising it and the app's focused window confirms it within 250 ms) instead of being refused for every app with more than one window; a window behind its own sheet or panel is refused with the sheet named, keys for a system Open or Save panel go to the process that draws it, and a focus that moves mid-call stops the keys with `InputFailed`; `el.press()` on an element whose actions cannot be read is refused as such. ([#11740](https://github.com/code-yeongyu/oh-my-openagent/pull/11740), part of [#11462](https://github.com/code-yeongyu/oh-my-openagent/issues/11462))
