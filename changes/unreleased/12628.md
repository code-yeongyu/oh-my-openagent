### Changed

- The compiled engine no longer has the unused `installEngineCaTrust` startup routine. That routine set `NODE_USE_SYSTEM_CA=1` but had no caller, and engine launches set up certificate trust in the launcher trust stage. A new test checks that an engine started without `NODE_USE_SYSTEM_CA` in its environment does not get it from the launcher. Validation of `OMO_EXTRA_CA_CERTIFICATES` is unchanged. ([#12628](https://github.com/code-yeongyu/oh-my-openagent/pull/12628), part of #10762)
