## 2026-11-18 - Thread recovery hints name the eval cell (#13240)

Thread tools are eval-only since #12903, and #14070 made the thread tool descriptions name both the direct and the eval form. The recovery hints across `thread/` (`reader.ts`, `addressing.ts`, `tools.ts`, `remote/*`, `control/*`, `gateway/*`, `tools/*`, `worktree/failures.ts`) still named bare tools ("Call thread_list ..."); each now adds the eval form after the name, with arguments only where the hint gives them (`tool.thread_list({ all_scope: true })`, `tool.thread_send({ thread, message })`). `thread/eval-cell-hints.test.ts` reads the string literals of every thread source file and fails on a thread tool named without its eval form in the same sentence, on an eval form of a tool that does not exist, and on a call argument the tool's schema does not have; the parameter schemas under `contracts/` are left as they are, because the `omo thread` CLI shares them. QA scratch sandboxes chmod their agent dir to 0700 for senpi's key-dir check under umask 002; the layout lives in `scratch-layout.mjs`, so its test loads without the engine version `gateway.mjs` requires.
