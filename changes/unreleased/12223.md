### Changed

- A Linux container matrix (Debian, Fedora, Alpine, openSUSE Leap and Tumbleweed) now checks the compiled engine's CA import on each distribution: the bundle chosen from `os-release` is the one the engine reads, a root installed with `update-ca-certificates` or `update-ca-trust` is trusted, and a root placed only in openSUSE's `/var/lib/ca-certificates/openssl` is not. ([#12223](https://github.com/code-yeongyu/oh-my-openagent/pull/12223), part of [#10762](https://github.com/code-yeongyu/oh-my-openagent/issues/10762))
