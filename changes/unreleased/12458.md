## 2026-11-05 - Launcher protocol modes: --hand and --headless (#12458)

New `bin/lib/mode-flags.js`: `ENGINE_PROTOCOL_MODE_FLAGS` (`--hand`, `--headless`, senpi#5840) and `isEngineProtocolMode(args)`, which reads flags before `--` only. The launcher's interactive gate (`isInteractiveDefault`) skips the banner and the setup-suggestion read for them, and `herdr-agent-hint.js` treats them as non-interactive, so a hand or headless host started in a herdr pane is never named as an agent. Engine argv is unchanged: `--extension <plugin>` plus the user's flags.
