**omo now runs on senpi 2026.11.23.** What changes for you:

- **Images on text-only models:** when a tool returns an image and the current model cannot read images, the `look_at` vision model now describes it and the description takes the image's place, so the model still gets the content.
- **macOS paths under `/home`:** a tool call naming a path under `/home` (an automount that may never answer) no longer stalls every file operation in the session; a mount that never answers is refused instead.
- **Self-hosted Anthropic-compatible proxies:** a custom `models.json` provider using `anthropic-messages` with an `sk-ant-oat...` key works again; the key is sent as a plain API key instead of failing before the first request.
- **Reopening right after an engine handover** no longer fails with `read ECONNRESET`.
- Claude, GLM and Kimi models are told to edit files with the session's file-editing tool directly, and the bundled model catalog is refreshed. (#14822)
