### Changed

- Feature pull requests no longer commit the generated bundles that the release job regenerates: the Senpi plugin `extensions/` and runtime bundles, the Codex installer bundle, and `service-auth.generated.js`. Build them locally with `bun script/build-generated.ts`; CI builds them before the jobs that read them.
