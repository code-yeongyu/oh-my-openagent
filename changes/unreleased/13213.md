### Changed

- Feature pull requests no longer commit the generated bundles that the release job regenerates (the Senpi plugin `extensions/` and runtime bundles, the Codex installer bundle, and `service-auth.generated.js`, listed in `script/generated-bundles.json`). A pull request check refuses a branch that changes one of them and prints the command that restores it. Build them locally with `bun script/build-generated.ts`, and restore them before a merge or branch switch with `bun script/restore-generated.ts`. CI builds them before every job that reads them. ([#13213](https://github.com/code-yeongyu/oh-my-openagent/pull/13213), fixes [#9903](https://github.com/code-yeongyu/oh-my-openagent/issues/9903))
