### Fixed

- A thread message that starts a turn on an idle session now reports `effective_mode: "start"` in the tool result and `effective=start` in the delivery header the receiving session reads. It used to report `follow_up`, which looked as if the message had been queued. The lanes are now `start`, `steer` and `follow_up`, on this device and on another device alike, including a session woken to take the message. The gateway store moves to schema v15 so it can record `start`; an older omo build refuses a v15 store with the existing `gateway_schema_too_new` error. ([#14339](https://github.com/code-yeongyu/oh-my-openagent/pull/14339), part of [#14333](https://github.com/code-yeongyu/oh-my-openagent/issues/14333))
