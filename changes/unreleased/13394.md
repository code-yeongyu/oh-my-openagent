### Fixed

- `thread_list` and `omo thread list` now list threads on all of the account's devices in every call, not only with `all_scope`. An ended thread on another device shows as resumable instead of live. The result includes the account's devices: name, platform, kind, online state, last seen, thread count, and whether this listing reached them, so a device that did not answer is named instead of silently missing. `omo thread list --json` now prints that whole result as one object (`threads`, `devices`, `remote_unavailable`) instead of a bare array of threads, and the plain listing names each other device's thread's device and prints one line per device. ([#13394](https://github.com/code-yeongyu/oh-my-openagent/pull/13394), fixes [#13392](https://github.com/code-yeongyu/oh-my-openagent/issues/13392))
