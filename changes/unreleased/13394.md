### Fixed

- `thread_list` and `omo thread list` now list threads on all of the account's devices in every call, not only with `all_scope`. An ended thread on another device shows as resumable instead of live. The result includes the account's devices: name, platform, kind, online state, last seen, thread count, and whether this listing reached them, so a device that did not answer is named instead of silently missing.
