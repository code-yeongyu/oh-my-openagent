The session identifier is also hashed with the salt of the agent directory the caller was given, instead of the process default. ## 2026-10-28 - Feedback identifiers follow consent at send time (#11658)

Submit re-runs the feedback identity-hash gate (fresh env and omo config for the draft's cwd) and drops the install and session hashes, and their identity lines, when consent is gone; the report itself is still sent. `hashSessionId` takes the caller's env (default `process.env`) and creates the salt next to its own path, so an injected env no longer reads or writes the process default's salt.
