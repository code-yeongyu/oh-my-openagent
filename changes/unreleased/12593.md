### Fixed

- `~/.omo/agent` is now created owner-only (`0700`) regardless of the umask. On a host with umask 0002 it used to come out group-writable, and the RPC socket host then refused to start with `key_publication_failed: unsafe_key_record`. ([#12593](https://github.com/code-yeongyu/oh-my-openagent/pull/12593), fixes [#12546](https://github.com/code-yeongyu/oh-my-openagent/issues/12546))
