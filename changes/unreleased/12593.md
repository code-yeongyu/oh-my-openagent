### Fixed

- `omo` now gets `~/.omo/agent` ready before the engine starts, so a host with umask 0002 no longer stops at `key_publication_failed: unsafe_key_record`. A missing directory is created owner-only (`0700`) instead of being left for the engine to create with the umask. An existing directory that is group- or world-writable has those write bits removed when it is a real directory you own. A symlink or a directory owned by another user is left as it is, and `omo` prints the `chmod go-w` command that fixes it. ([#12593](https://github.com/code-yeongyu/oh-my-openagent/pull/12593), fixes [#12546](https://github.com/code-yeongyu/oh-my-openagent/issues/12546))
