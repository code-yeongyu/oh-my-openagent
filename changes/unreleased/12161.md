### Fixed

- Memory git on Windows now starts only from a fully qualified PATH directory or the Git for Windows install location, never from the memory folder or the project you are working in. A `git.exe`, `git.com`, `git.cmd` or `git.bat` sitting in either directory is no longer run by an auto-commit, a sync or a reflection merge: every executable the memory engine launches on Windows - git, `reg`, `powershell` and `taskkill` - is resolved to an absolute path first, a `.cmd`/`.bat` git is started through the System32 `cmd.exe` that runs it, and a PATH entry that is relative, drive-relative or rooted without a drive is skipped and reported once, since each of those is a lookup relative to the working directory. macOS and Linux are unchanged. ([#12146](https://github.com/code-yeongyu/oh-my-openagent/issues/12146))
