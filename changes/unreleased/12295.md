### Fixed

- Memory sync no longer loses an edit when two devices change the same line of a memory file at the same time, once every device on the account runs this version. Both edits are then kept as two whole lines, and both devices converge. Before, the edits were merged character by character into text that matched neither. Each device advertises the new merge in the batches it syncs, and a device switches to it only after hearing that advertisement from every other member of the account. While any member still runs an older version, or has not synced since updating, every device keeps the old character merge, so a mixed account behaves exactly as before and an unedited line is never touched (#12279).
