### Fixed

- Memory sync no longer loses an edit when two devices change the same line of a memory file at the same time. Devices on this version keep both edits as whole lines, and every device converges. Before, the edits were merged character by character into text that matched neither. An edit never disturbs a line that nobody edited, even when one device still runs an older version. Against an older device, this version's edit stays whole, and the older device's change stays within the line it edited, except in one case: the older device edits a line that this version deletes. The older device's leftover text then joins the next line, exactly as it does today between two older devices. Two older devices keep their old character merge until they update (#12279).
