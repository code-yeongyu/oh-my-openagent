**A crash no longer locks the CLI sign-in for good.** When omo was killed between taking its credential lock and writing the lock record (an unclean reboot leaves the file empty), that empty record was never reclaimed: every later sign-in read waited 15 seconds and failed, and each `thread_send` addressed by name paid that wait on its alias lookup. Such a record is now reclaimed after a minute; a running owner still keeps its lock however long it holds it. (#12989)
