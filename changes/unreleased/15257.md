### Fixed

- The memory filesystem policy (the hard guard against reading another memory identity) now reaches senpi's file tools. It was registered when a session bound, after senpi had composed the policies its tools enforce, so it was never consulted. It is now registered when the extension loads and reads the session's bound identity on every call (#15251). With no bound identity (before the session binds, after it shuts down, or a resume-conflict session) the policy now denies the memory areas instead of allowing everything; files outside memory stay readable.
