### Fixed

- `thread_send` works in a run started by input sent over the session's RPC socket (`prompt`, `steer` or `follow_up`), the same as in a run started by typed input. Every such send was refused with `invalid_arguments` (`guard: "unknown_cause"`). That input now starts a new causal chain. A session still continues a chain only for messages its own gateway drain delivered, so the causal guard still refuses a cause the sender did not receive (#12317).
