### Fixed

- A session parked by a host restart, swap or reopen now wakes for a message from another device as soon as the host's delivery consumer is serving. Each woken session's admission check used to wait for the consumer's whole startup, which itself waited on that wake, so every parked session stalled for the 30-second wake timeout, one after another, and cross-device deliveries on that host waited behind them. ([#14621](https://github.com/code-yeongyu/oh-my-openagent/pull/14621), fixes [#14335](https://github.com/code-yeongyu/oh-my-openagent/issues/14335))
