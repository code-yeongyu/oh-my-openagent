### Added
- Desktop engine: several clients run by the same user can attach to one shared `--serve` daemon session (SDK `attach` over the Unix socket), each with its own replies; the daemon checks every client's peer credentials and closes a connection from another user before any byte.

### Fixed
- Desktop engine: the client retries a connection reset before the first reply byte only on Unix sockets, never on a Windows named pipe, where the daemon may already have run the request.
