### Fixed

- Reopening a closed thread with `thread_create({ thread })`, on this device or another, now names the folder the session file records (`cwd`) beside its file. The engine therefore resumes it without probing the file's path on its loop. On a loaded host that probe missed its 500 ms step deadline and refused the reopen with `open_failed: ... a filesystem step did not answer in time`. ([#14393](https://github.com/code-yeongyu/oh-my-openagent/pull/14393), fixes [#14296](https://github.com/code-yeongyu/oh-my-openagent/issues/14296))
- A `task` call or workflow node that names a builtin agent (`explore`, `librarian`, `plan-consultant`, `plan-reviewer` or a reviewer agent) together with `model` is now refused with `agent_with_model` instead of silently replacing that agent's designated model chain. Change a builtin agent's model with `agents.<name>.model` or `agents.<name>.models` in omo.json; custom agents still accept a call-site model. ([#14378](https://github.com/code-yeongyu/oh-my-openagent/pull/14378))

### Added

- OmO Native ships an `omo-relay` skill for working on the account's other devices from a js eval cell: running commands and jobs, moving and searching files, and running one operation on every machine, on chosen machines or on several threads at once, with one outcome per target and the error codes each one can return. ([#14381](https://github.com/code-yeongyu/oh-my-openagent/pull/14381))
