### Fixed

- A computer signed in before OmO accounts knew machine identity now binds its device to that machine. After a token refresh in `omo account token` (the desktop app's token path) or `omo login|logout|whoami`, omo signs this machine's hardware digest with the device's own key and sends it to `PUT /v1/devices/current/machine`, if the service advertises `hardware-digest-v1`. A later sign-in on the same computer is then refused as a second device instead of being added beside it. The service's answer (bound, or another device already holds this computer) is kept in `~/.omo/account-state/<credential>.machine-binding.json` and not asked again. When another device holds the computer, omo names it and changes nothing. ([#13643](https://github.com/code-yeongyu/oh-my-openagent/pull/13643))
