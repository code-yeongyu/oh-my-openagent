**A question or approval a remote session asks now reaches every `omo remote attach` on it, not only the one that sent the prompt.** The terminal UI shows the request and sends your answer back by its request id, as it already did for prompts you sent yourself, and dismisses it when another device answers it first. A secret input or a grant approval is still shown only on the terminal whose prompt raised it. A request already waiting when you attach, or raised while the relay link was down, is shown too, and one that was settled during a relay gap is dismissed after the reconnect (#13474).
