**A question or approval a remote session asks now reaches every `omo remote attach` on it, not only the one that sent the prompt.** The terminal UI shows the request and sends your answer back by its request id, as it already did for prompts you sent yourself, and dismisses it when another device answers it first. A secret input or a grant approval is still shown only on the device whose prompt raised it. ([#12750](https://github.com/code-yeongyu/oh-my-openagent/pull/12750))
