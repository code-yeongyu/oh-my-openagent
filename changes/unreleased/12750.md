**A question or approval a remote session asks now reaches every device watching it, not only the one that sent the prompt.** `omo remote attach` shows the request in the terminal UI and sends your answer back, as it already did for prompts you sent yourself. `omo remote watch` prints each request the session waits on, with its choices and the command that answers it. The new `omo remote answer <device>/<session> <request> <answer>` (or `--cancel`) answers it from any terminal. A secret input or a grant approval is still shown only on the device whose prompt raised it. ([#12750](https://github.com/code-yeongyu/oh-my-openagent/pull/12750))
