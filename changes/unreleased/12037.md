### Fixed

- Memory git hooks no longer initialize unrelated supervisor modules before checking staged notes, preserving validation. The startup cut applies to the source runtime (tests and dev), where one pre-commit hook took about 3.7 s; the packaged plugin bundle already deferred module initialisation, and its hook-mode time was measured unchanged (about 133-151 ms before and after). ([#11957](https://github.com/code-yeongyu/oh-my-openagent/pull/11957))
- Completed-turn memory journal counters are delivered before `agent_settled` and `agent_idle`, even when the bounded maintenance observer expires. Journal delivery does not wait for full snapshots, git reads, journal writes or reflection recovery. Late full snapshots preserve newer journal accounting, and unreadable transcripts fall back to durable counters. ([#11935](https://github.com/code-yeongyu/oh-my-openagent/pull/11935))
- A foreground `task` spawn's running progress updates wait for launch settlement and carry the model the child actually started on (and a start-time fallback's route), instead of publishing incomplete model facts when the launch exceeds 250 ms. Foreground batch rows wait the same way and carry the launched run epoch and route (batch rows do not report `effective_model`). A launch that fails releases the held updates instead of freezing them; pending slot reports remain immediate ([#11693](https://github.com/code-yeongyu/oh-my-openagent/pull/11693), fixes [#11691](https://github.com/code-yeongyu/oh-my-openagent/issues/11691), [#11827](https://github.com/code-yeongyu/oh-my-openagent/issues/11827)).

### Changed

- Memory command tests avoid redundant hook checks while seeding trusted fixtures, while retaining real hooks for later writes. ([#11954](https://github.com/code-yeongyu/oh-my-openagent/pull/11954))

## 2026-10-31 - Isolate memory-hook startup from supervisor imports (#11957)

Load supervisor-only dependencies after selecting supervisor mode, and load child bootstrap code only for its mode. Keep the existing checker, entry point, process ownership and deadlines. An import-boundary regression and real Senpi hook proof cover valid writes, duplicate-key rejection and provenance rejection.

## 2026-10-31 - Reduce trusted command-fixture setup cost (#11954)

Install the real memory hooks after the fixture's initial seed commit rather than before it. Keep normal hook installation and validation for commands under test, with a real-git regression proving later invalid writes remain rejected. This is only the fixture part of #10696; actual hook-startup latency is tracked separately in #11953.

## 2026-10-30 - Ordered post-turn memory journal delivery (#11935)

Separate required read-only journal delivery from the two-second maintenance observer. Combine live and durable answer IDs, and run full snapshot builds outside the journal publication queue. Publish journal updates immediately, rebase late full results on newer journal accounting, and use an explicitly unknown non-journal state before the first full snapshot. Transcript read failures retain durable counters.
