**`session_list` with a date filter no longer reads every session.** The `from_date`/`to_date` filter now runs on session metadata (`time.updated`) instead of loading each session's full message history, so a date-filtered list returns promptly even on projects with thousands of sessions, and `limit` is still applied after the filter.
