### Fixed

- Runtime fallback keeps compaction retries separate from the primary model chain and preserves substantive retry prompts. Compaction watchdogs defer within a bounded budget, exhausted native retry signals do not trigger an abort, and stuck-session watchdogs still return control when no replacement can be dispatched. Thanks @mradwankhalil. ([#11907](https://github.com/code-yeongyu/oh-my-openagent/pull/11907), fixes [#9786](https://github.com/code-yeongyu/oh-my-openagent/issues/9786))
- Background tasks let runtime fallback decide who recovers a session error before starting a replacement or finalizing the task. Exhausted and refused retries release recovery ownership, model-less retry errors can finish the task, and a slow decision never starts a competing replacement. ([#9683](https://github.com/code-yeongyu/oh-my-openagent/pull/9683), [#11907](https://github.com/code-yeongyu/oh-my-openagent/pull/11907))
