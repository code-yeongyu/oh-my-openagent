### Added

- Computer use on macOS: `el.press("cmd+a")` (or `el.press(["cmd", "a"])`) presses a key chord in one accessibility element without taking your focus: the keys go out only once the element holds its app's keyboard focus, and nothing is sent to an element that never takes it; `el.press()` without a chord is still the element's native press action, and `el.doubleClick()` double-clicks an element. ([#11724](https://github.com/code-yeongyu/oh-my-openagent/pull/11724), part of [#11462](https://github.com/code-yeongyu/oh-my-openagent/issues/11462))
