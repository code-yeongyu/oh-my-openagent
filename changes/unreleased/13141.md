**A fuzzy handoff no longer fails on an account with many ended sessions, and never goes to a different session than an exact name would.** A fuzzy handoff first tries the thread's exact id, alias or name across every session, ended ones on other devices included, so a name that exactly matches one session always reaches that session. Otherwise local, live and ended sessions are compared together and the clearly best match wins wherever it lives; two equally good matches ask you to pick. Ended sessions that cannot match no longer count against the 500-candidate fuzzy cap, so a large history no longer blocks a unique match.
