## 2026-11-12 - Ended remote sessions rank below local and live candidates in a fuzzy handoff (#13141, follows #13066)

`tools/internals.ts` `resolveAcross`: for `match: "fuzzy"` the first comparison is local entries plus the account book's live rows; the book's ended (resumable) rows join a second comparison only when the first answers `not_found`, and the 500-candidate cap then applies to that full set. Exact name and id resolution is unchanged and still reaches an ended remote row. Tests (`remote/route-parity.test.ts`): "600 ended remote rows + unique local" (RED before: `ambiguous_target` from the cap), "live remote exact title beats a local near-match" (the combined comparison stays), "only an ended remote row matches" (fuzzy and exact reach the same ended row through the same relay calls; RED on the live-only filter: `not_found`), "a live and an ended remote row match equally" (the live row wins; RED on the old combined set: `ambiguous_target`).
