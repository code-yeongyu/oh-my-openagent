### Fixed

- The cold-wake session host unit (and every other unit or plist the cold-wake install writes) is now written 0644 under any umask. Under umask 077 it was written 0600, because a file's creation mode is masked by the umask; the mode is now set explicitly before the file is moved into place. ([#14249](https://github.com/code-yeongyu/oh-my-openagent/pull/14249), fixes [#14247](https://github.com/code-yeongyu/oh-my-openagent/issues/14247))
