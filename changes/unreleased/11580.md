### Changed

- Release builds now produce the signed macOS keychain helper, `omo-keychain`, as one universal build signed as `com.mengmota.omo-keychain-helper` and notarized. They ship it in omo-ai (`bin/darwin/omo-keychain`), the compiled darwin binaries and the darwin platform packages, and attach it to the GitHub release as `omo-keychain-darwin-universal`. Its signature is checked before every upload. Nothing uses it yet. ([#11580](https://github.com/code-yeongyu/oh-my-openagent/pull/11580), part of [#11262](https://github.com/code-yeongyu/oh-my-openagent/issues/11262))
