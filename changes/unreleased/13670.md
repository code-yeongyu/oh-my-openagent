### Changed

- Computer use no longer has a code cell of its own: the `computer` tool's `run` action and the eval global's `computer.run()` are removed, and a multi-step desktop task is an eval cell that awaits one `computer` helper per step. Call chains and `computer_actions` batches now run as data inside the desktop service, which executes no model-written code. Input helpers return `{ value, report, reports, auditIds, toolCallId }`, so a cell can check whether resending is safe; audit records carry the tool call id; arguments over 1 MiB and helper values over 8 MiB are refused, and a session is capped at 20,000 desktop requests (#13634). ([#13670](https://github.com/code-yeongyu/oh-my-openagent/pull/13670))
