### Added

- Computer use v3: pointer verbs and held keys. Click, scroll, drag and key or button holds go through one ledger that releases every held input on each way out of a call (success, error, cancel, the 100 s bound, stop, connection close), and a stopped drag releases its button where it started. The protected-targets table now follows the operating system the session's backend acts on, chosen once when the session opens. Nothing user-visible changes yet; the existing desktop engine is untouched. ([#13360](https://github.com/code-yeongyu/oh-my-openagent/pull/13360))
