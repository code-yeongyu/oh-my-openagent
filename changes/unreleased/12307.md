### Added

- Team-mode and subagent panes can render through [Herdr](https://herdr.dev) instead of tmux: set `"multiplexer": "herdr"` under `tmux` (or `OMO_TMUX_MULTIPLEXER=herdr`). A team becomes one herdr workspace (`omo-team-<teamRunId>`) with one tab per member; background subagents get one workspace per omo process (`omo-agents-<pid>`) with one tab each — the same `opencode attach` line, no tmux session required, the headless herdr server started on demand. Password-protected opencode servers authenticate panes through a single-use 0600 file, the same private channel tmux panes use. ([#12307](https://github.com/code-yeongyu/oh-my-openagent/pull/12307))
