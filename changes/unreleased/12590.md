### Changed

- On a split session (the agent loop on one machine, the tools on your device) the memory tool's `apply_patch` now works: patches are applied and committed through the device's files, with the same path checks as the other memory commands, so memory stays on the device. Sessions that are not split behave exactly as before. ([#12590](https://github.com/code-yeongyu/oh-my-openagent/pull/12590), part of [#12407](https://github.com/code-yeongyu/oh-my-openagent/issues/12407))
