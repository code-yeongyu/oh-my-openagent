### Added

- Computer use v3: secure fields, private mode and the send-on-Enter guard. A password or one-time-code field's value never reaches a reply, an observation of a focused secure field withholds the tree and asks for the user, and secrets are typed as keystrokes, never through the clipboard. A bare Return into the message box of an app listed in `computer.send_on_enter` is refused unless the call says `force`, while Shift+Return still inserts a line break. Text a remote-screen window's keyboard layout cannot type is refused before any key. Nothing user-visible changes yet; the existing desktop engine is untouched. ([#13371](https://github.com/code-yeongyu/oh-my-openagent/pull/13371))
