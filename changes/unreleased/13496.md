**`omo remote` accepts `--` to end its options.** `omo remote send <device>/<session> -- --text that starts with dashes` now sends that text, and the same works for a model id given to `omo remote model`; before, any argument starting with `--` was refused as an unknown option. Options before `--` still apply. ([#13496](https://github.com/code-yeongyu/oh-my-openagent/pull/13496), fixes #13431)
