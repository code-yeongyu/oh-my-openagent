### Fixed

- Memory reflection children started inside the Linux bubblewrap sandbox no longer exit at startup with `unsafe trust ancestor`. Inside the sandbox's user namespace, root-owned directories show the overflow uid. The engine trust stage now accepts one only when the launcher verified, from outside the sandbox, that this exact inode is root-owned. A directory owned by another user is still refused. The sandbox child also gets its own private `TMPDIR`, and a read-only trust directory falls back to a private temporary one. A hand-made user namespace that omo cannot verify now gets the named refusal `trust-userns-unattested` with a next step, instead of a stack trace. ([#12079](https://github.com/code-yeongyu/oh-my-openagent/pull/12079), code-yeongyu/senpi#5334)
