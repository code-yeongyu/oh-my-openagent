**plan-reviewer reviews the plan you name, even if this session never opened it.** Before, a plan path in the prompt counted only when the plan had been touched with the read, write, edit or apply_patch tools. A plan written from an eval cell or a shell was silently swapped for the session's most-edited plan, so an unrelated plan could come back `[OKAY]`. Now an existing plan in the project's `.omo/plans` is reviewed as given. A path that does not exist, sits outside `.omo/plans`, or comes with a second path is refused with a message naming it. The most-edited plan is used only when the prompt names no plan.
