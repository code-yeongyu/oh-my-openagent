**`omo remote attach` now ends when the remote session ends.** If another device closes the session you are attached to, the terminal UI leaves, prints `The remote session <device>/<session> ended (<reason>).` and the command exits 0, instead of sitting on `Disconnected` until you quit it yourself. An attach that ends for another reason, such as revoked access, exits 1 with the same line. ([#12767](https://github.com/code-yeongyu/oh-my-openagent/pull/12767))
