### Added
- Thread gateway: the store keeps a record of each session a wake asked for or opened (#13037): one row with its state, a lease and a generation that fences every write, at most 4 such sessions past `requested` per agent directory, and a transient open failure that returns the row to `requested` with its attempts and the time of the next one (the third deletes it). A wake primitive resolves a durable id to its one session file, refuses child and worker sessions, ensures the host and sends one plain `open_session` frame (no `attended`, no permission preset). The gateway store's schema moves to version 13 (one new table); a process still on the previous build reports the store's "schema too new" error until it restarts. Nothing calls the wake yet, so no behavior changes. ([#13212](https://github.com/code-yeongyu/oh-my-openagent/pull/13212))
