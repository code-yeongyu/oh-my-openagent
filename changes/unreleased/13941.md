### Fixed

- An agent whose omo build is older than the one that last upgraded this machine's gateway store no longer gets an opaque `internal_error` from `thread_send` and the other thread tools (or `omo thread send`). The store is still refused, so nothing is read or written at a schema the build does not know, and the failure is now `gateway_schema_too_new`: it names the store's schema and the build's schema, and tells you to update omo with the exact command (`omo update`), then restart the session. ([#13941](https://github.com/code-yeongyu/oh-my-openagent/pull/13941), fixes [#13927](https://github.com/code-yeongyu/oh-my-openagent/issues/13927))
