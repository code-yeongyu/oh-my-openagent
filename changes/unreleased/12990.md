**The beta channel no longer falls behind the stable release.** Every stable release now also moves `omo-ai@beta` on npm and the `beta` installer channel on get.omo.dev to that release, unless beta already holds a newer prerelease, so `bun add -g omo-ai@beta` and `install.sh beta` never install something older than `latest`.
