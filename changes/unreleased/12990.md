**The beta channel no longer falls behind the stable release.** Every stable release now also moves `omo-ai@beta` on npm and the `beta` installer channel on get.omo.dev to that release, unless beta already holds a newer prerelease, so `bun add -g omo-ai@beta` and `install.sh beta` never install something older than `latest`. The beta move and its beta >= latest guard now also run when a release is re-run after it was already published, and after the move beta is re-read: a beta someone moved further forward is left alone, while a beta still older than latest or the newest prerelease fails the run with the exact `npm dist-tag add omo-ai@<version> beta` repair command.
