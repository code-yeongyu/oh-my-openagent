**Memory no longer grows without bound on disk.** The background memory maintenance pass now removes finished reflection runs, fully reflected transcripts, recall sidecars and legacy stores past configurable windows (`memory.runtime.retention_days` 7, `completions_days` 30), in time-boxed slices that resume where they stopped. Transcript input reflection never folded into memory is kept unless you turn on `discard_unreflected_journals` (then removed after `abandoned_journal_days`, 14, only while reflection works for that agent). Nothing a live session owns, no locked or unfinished work and no run id reflection still needs is touched. ([#12532](https://github.com/code-yeongyu/oh-my-openagent/pull/12532))
