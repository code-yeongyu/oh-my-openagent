### Fixed

- `thread_send` no longer reports a message as `queued` when nothing will ever pick it up. When the target thread's session has no running drain, the send now answers `queued_offline`: the message is kept and the session takes it the next time it runs, so a caller knows no turn started and can act instead of waiting. The drain also reports a message it is holding behind the user's unsent draft, so a live drain is never mistaken for a missing one. ([#12488](https://github.com/code-yeongyu/oh-my-openagent/pull/12488), fixes [#12486](https://github.com/code-yeongyu/oh-my-openagent/issues/12486))
