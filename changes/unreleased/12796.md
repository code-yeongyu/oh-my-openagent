### Added

- Plan review ledger: when the plan file carries a `## Review ledger` markdown section, the plan-reviewer spawn prompt now says so and instructs the reviewer to re-verify only the rows the ledger marks as changed, plus the plan parts those rows touch, instead of re-reviewing the whole plan. The same clause states that the ledger is evidence and not a verdict, so a fabricated or incomplete ledger fails the review rather than becoming a prompt-stuffing pass; the reviewer agent gained the matching ledger pass and a REJECT criterion. A plan without the section keeps the previous spawn sentence byte-identical, and a plan that cannot be read fails open to it. ([#12796](https://github.com/code-yeongyu/oh-my-openagent/pull/12796), fixes [#11329](https://github.com/code-yeongyu/oh-my-openagent/issues/11329))
