### Fixed

- Memory sync replicates between devices again. The client refused every batch row from `GET /v1/sync/entries` that carried the `batch_id` the service contract declares, so two devices paired but no edit reached the other. Account recovery, and pairing a device after the first batch, failed the same way. A well-formed `batch_id` on a batch row is now accepted. A null or malformed one, one on a keyring row, and any other extra field are still refused (#12277).
