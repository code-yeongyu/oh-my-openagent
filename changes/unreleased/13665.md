### Fixed

- A memory sync failure of the same kind but with a different action, such as a stranded git lock that moved to another path, now starts a new failure with its own start time and an attempt count of 1, instead of inheriting the previous one's. The sync status also hands each caller its own copy of the failure, so a caller that changes it no longer changes what the engine reports next (#11759). ([#13665](https://github.com/code-yeongyu/oh-my-openagent/pull/13665))
