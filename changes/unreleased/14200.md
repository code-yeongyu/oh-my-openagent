### Fixed

- `thread_create` on another device now opens the thread on that device's own engine (the primary engine endpoint its device service names), never on the first endpoint listed. Before this, a thread could land on an owner shard or on another registered agent dir's older engine, which then refused every cross-device `thread_send` as unsupported (`method_unclassified`). A device that lists several engine endpoints but names none of them as its own is now refused `host_not_answering` before anything opens; a device with a single engine endpoint works as before. ([#14200](https://github.com/code-yeongyu/oh-my-openagent/pull/14200), fixes [#14195](https://github.com/code-yeongyu/oh-my-openagent/issues/14195))
