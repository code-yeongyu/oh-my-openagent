**`omo remote` takes a device by the name its table prints.** The session verbs (`open`, `send`, `model`, `interrupt`, `close`) accept a device's id, its name (compared as thread names are) or a unique id prefix, through the same resolver `thread_create` uses, and their output names the device by its id. A name two online devices share is refused with `ambiguous_target`, listing each candidate; a name only an offline device has is `device_offline`; a device nothing matches is `not_found`.
