### Changed

- The `browser` skill (#15047) now shows the owned-browser loop beside the attached one and adds three rules: wait for a page state instead of a fixed delay, keep one connection per task and hand a wait that can outlast an eval cell to `tool.monitor`, and read pages within a token budget. The desktop built-in browser step and the doctor state table moved to `references/desktop.md` and `references/install.md`. `references/commands.md` now lists `tabCreate` / `tabSelect` as not gated and states which calls reject an unknown option (#12540, #12905). Examples in `visual-qa`, `debugging` and `ultimate-browsing` take the browser path from `detectBrowsers()` instead of an undefined variable.

- The browser skill's bundled runtime is omowright 0.3.3 (was 0.3.2): scroll collection ends each round on the next response instead of a fixed 800 ms delay, an `emulate()` device survives `goto()`, a failed `fill()` no longer echoes the entered value, and `cooperate("sync")` resolves without a context on a BrowserSkill extension that has no shared control.

### Fixed

- The attached-engine loop example sends its first `navigate` without a sync context, which the untouched Agent Window tab refuses (first reported and fixed in #14385 by @kristianvast).
