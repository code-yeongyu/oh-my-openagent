### Fixed

- The Prometheus planning-file guard resolves Windows paths the way the executor opens them: both `/` and `\` split the physical walk, so a `link/..` spelling is followed through the link instead of being collapsed lexically (a symlink escape was allowed), a symlinked or junctioned planning directory such as `.omo -> docs\plans` is recognised again, and 8.3 short names, drive-letter case and directory case all resolve to one canonical path. Inside-planning checks compare the canonical paths exactly, which keeps case-variant entries on case-sensitive directories distinct ([#11548](https://github.com/code-yeongyu/oh-my-openagent/pull/11548))
