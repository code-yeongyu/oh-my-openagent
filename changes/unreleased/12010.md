### Fixed

- A delegated category whose model chain names one vendor only (`deep-high` and `deep-low`, all OpenAI) no longer finishes on the parent session's model from another vendor once every rung is usage-limited or signed out. It now fails with `failure_kind: "provider_lock_exhausted"` and an error naming the category and the reset time the provider reported. The new `categories.<name>.provider_lock` key applies the same lock to a mixed chain (`true`) or restores the parent-model fallback (`false`). ([#12006](https://github.com/code-yeongyu/oh-my-openagent/issues/12006))
