### Added

- Ship the engine trust helper in the compiled payload on macOS (arm64, x64) and Windows (x64, arm64), with its sha256 and file mode in the runtime manifest. The macOS build is signed and smoke-tested against the runner's own trust store before upload; the Windows build is unsigned for now. omo-native can locate the extracted helper, but nothing runs it yet.
