**Computer use v3 on macOS: window capture and displays.** The macOS backend lists windows from its own window-server enumerator, keyed by window number, process id and process start time, so a reused process id never inherits an old window. Stills come from a persistent ScreenCaptureKit helper, so a window on another Space or behind other windows is captured without switching Spaces. A minimized window is reported as unavailable instead of captured. A display still excludes the engine's own windows, and a frame that cannot prove that exclusion is refused. Displays report their bounds in points and their backing scale. A low-rate preview stream runs only while a window is leased and someone is watching, and it never feeds the model.
