### Added

- Thread SDK: `backlog({ thread, caller, action, destination?, idempotency_key })` cancels or moves the pending deliveries of a session on this device without loading it, for a seat taken over while its old session is parked. `move` queues each line on the destination in order, with its sender, and the sender's idempotency key follows the line; `cancel` drops them. The answer names the cancelled ids, or each moved id with its new id. Only the session that holds the target's registered name, or the one that created it, may ask (anyone else is refused `scope_denied`); a target that is loaded and mid-turn is refused `turn_active` with nothing changed; a repeat under the same key answers the same result and changes nothing. ([#15189](https://github.com/code-yeongyu/oh-my-openagent/pull/15189), fixes [#15187](https://github.com/code-yeongyu/oh-my-openagent/issues/15187))
