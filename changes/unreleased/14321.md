### Fixed

- A compiled omo binary now advertises the embedded senpi engine's CalVer as its host's `engineVersion` and `engineOrdinal` (the omo version stays in `serverVersion`). Through 5.1.78 it advertised the omo version (`[5,1,78,0,0]`), so an engine that orders hosts by CalVer read a newer compiled host as older and handed it down to an older engine (code-yeongyu/senpi#7040, #14321).
