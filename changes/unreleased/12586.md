### Changed

- On a split session (the agent loop on one machine, the tools on your device) the memory tool runs where the session's memory is bound and writes, commits and locks its store through the device's files, so memory stays on the device; `apply_patch` and a first write to a device with no memory repository yet are refused with an explanation for now. Sessions that are not split behave exactly as before. ([#12586](https://github.com/code-yeongyu/oh-my-openagent/pull/12586), part of [#12407](https://github.com/code-yeongyu/oh-my-openagent/issues/12407))
