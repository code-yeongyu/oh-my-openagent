**The credential lock home ignores drive-relative Windows paths, and its Windows lookup is covered by CI.** The test-only lock-home override no longer accepts a rooted path without a drive (`\\tmp\\x`) or a UNC path: it now reuses the drive-absolute check that guards SystemRoot. Changes to the lock-home module also force the full OS matrix on pull requests, and a Windows-only test runs the real registry lookup on the Windows runner.
