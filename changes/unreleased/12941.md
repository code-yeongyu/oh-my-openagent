**An isolated clone is deleted when its work is already on a remote.** A child whose patch could not land used to leave its clone on disk forever, even after every commit was pushed and no edit remained. That clone is removed. One that still has an unpushed commit, an edit, an untracked file, a nested repository, or no remote-tracking ref is kept, and the patch stays with the task.
