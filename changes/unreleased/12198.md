## 2026-11-03 - Mid-turn compaction keeps the pinned memory block (#12198)

When auto-compaction ran in the middle of a turn, the session-pinned memory block moved to the newest memory on the next turn, which changed the system prompt again and rewrote the whole prompt cache a second time. A compaction the turn already sent requests past now keeps the pinned block, and the next memory notice lists every memory change since the pin, including the ones the compaction summarized away. A compaction at a turn boundary, `/recompile`, and a missing pinned commit still move the pin as before.
