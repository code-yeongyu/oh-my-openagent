**A memory reflection merge that fails no longer leaves the shared memory repo dirty.** When a reflection merge stopped after staging (a refused commit hook, or `index.lock` held by another writer), the run's files stayed staged and every later reflection and memory write refused with `parent_dirty`. The merge now restores the repo, waits out a briefly held lock, and if the lock never clears the next reflection finishes the stranded merge.
