### Fixed

- `omo session-of-pid <pid> --json` reaches the engine and answers its one JSON line, on the compiled binary and on npm and bun installs. Before, omo put its plugin option in front of the command, so the engine never saw it and answered `Unknown option: --json`. A test now checks that every command the engine's entry dispatches reaches it unchanged. ([#14255](https://github.com/code-yeongyu/oh-my-openagent/pull/14255), fixes [#14253](https://github.com/code-yeongyu/oh-my-openagent/issues/14253))
