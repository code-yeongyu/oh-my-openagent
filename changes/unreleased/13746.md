### Changed

- `omo remote status`, `devices`, `sessions`, `disable`, `control` and `wake` now run on the one remote client (part 4c-1 of the one remote module design): each makes one call, and `--json` prints that call's value. `devices --json` lists this device first (marked `self`) with `id`/`name`/`caps`, `sessions --json` returns `{revision, rows, unanswered}` with each row's `thread` and full device, and `status --json` adds `service_version`. The human output is unchanged apart from this device's row in `devices`.
