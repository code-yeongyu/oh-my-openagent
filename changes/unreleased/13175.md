### Fixed
- Computer use: an accessibility snapshot no longer returns the whole window as success when it was asked for an option it cannot honour. `since`, which no read implements, now fails with a clear error in every session, including older clients that never chose a reporting mode; `root`, `drill` and `skeleton` fail with one in a session that chose a reporting mode other than object. Older clients that never chose a mode otherwise keep their exact replies. An `observe` call that asks for such an option fails as a whole, screenshot included, instead of returning the full tree.
