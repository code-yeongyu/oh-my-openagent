**Native skills no longer point Senpi sessions at OpenCode-only agents, tools and commands.** A community audit of the installed skills found 16 more references that exist only in OpenCode or nowhere: `refactor` consulted an `oracle` agent and called `team_list` and `team_status`, `debugging` ended a team with `team_shutdown_request` and `team_approve_shutdown`, `frontend` loaded skills through a `skill` tool and addressed a `Prometheus` planner, `ulw-loop` named an `explorer` agent, a `plan` agent and a `/cancel` command, `ulw-plan` offered a `git` category, and `ultimate-browsing` named a `web-search` tool and Playwright MCP calls. Senpi now gets the `deep-high` lane in place of `oracle`, the `task_send` shutdown handshake and `task_output` in place of the missing team tools, and `explore`, the `ulw-plan` workflow and `/goal pause` or `/goal clear` in the Native skills. The shared skills read the same in OpenCode and Codex. ([#12523](https://github.com/code-yeongyu/oh-my-openagent/pull/12523))
