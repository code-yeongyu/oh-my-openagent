### Changed

- Eleven memory slash commands (`/memory`, `/remember`, `/init`, `/recompile`, `/memory-repository`, `/sleeptime`, `/reflect`, `/dream`, `/search`, `/facts`, `/agreements`) still appear at startup with the same names, descriptions and hints, but their handlers now load on first use from a separate `extensions/omo-memory-commands.js`, so every session start reads about 33 KB less of the `omo.js` entry bundle (#10860).
- Memory sync's signed-in device account (the service-auth credential store, token refresh and account read) now loads from `extensions/omo-device-account.js` the first time a session resolves its sync, instead of riding in `omo.js` (#10860).
- If `extensions/omo-device-account.js` cannot load, memory sync now reports `sync-unavailable` with the reason, the same as a missing sync engine, instead of logging a generic start failure and looking signed out (#10860).
