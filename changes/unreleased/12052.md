### Added

- The device service SDK (`@oh-my-opencode/device-service-core`) can download, verify and install the OmO device service and run its start-up bootstrap: the release signature is checked with the repository's strict Ed25519 helper against a compiled-in release key, every file against the signed checksums, and the release lands in the service's state dir only after every check passed. Nothing calls it yet, and the release key is a placeholder until it is published.
