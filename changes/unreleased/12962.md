**Memory settings now come from the session's own folder.** `memory.agent` and `memory.auto_identity` are read from the config layers of the directory a session runs in, not from wherever the shared engine process started, and every bind records how the session reached its memory store in `identity.json`, the evidence the upcoming `/memory-merge` uses to bring per-worktree stores together.
