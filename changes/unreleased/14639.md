### Fixed

- A session no longer sticks at "Starting session..." when the OS refuses to start `ps` (EPERM from `posix_spawn`, a process limit or a sandbox refusal on macOS). The thread gateway now treats that as an unreadable process start time, which it already counts as a live claimant, instead of failing every gateway read, including the pending completion arms the session waits on at start. ([#14639](https://github.com/code-yeongyu/oh-my-openagent/pull/14639), fixes [#12314](https://github.com/code-yeongyu/oh-my-openagent/issues/12314))
