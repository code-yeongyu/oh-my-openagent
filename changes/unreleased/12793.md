### Fixed

- Memory git now pins `core.hooksPath` to the memory hooks directory on every git call, so a global `core.hooksPath` (for example pointing at `/dev/null`) can no longer silently skip the installed pre-commit, commit-msg and post-commit hooks. ([#12793](https://github.com/code-yeongyu/oh-my-openagent/pull/12793), fixes [#12367](https://github.com/code-yeongyu/oh-my-openagent/issues/12367))
