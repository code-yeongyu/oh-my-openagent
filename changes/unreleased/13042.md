**An agent that answered a message from another agent can keep answering it in the turns the engine starts on its own, with no prompt.** The reply allowance a consumed delivery grants (a reply to that sender by id or stated name, approved from the delivery alone) now lasts for the work the delivery started: the consuming turn and every later turn the engine starts by itself - an open-todo reminder, a goal continuation, a monitor wake. A settle alone no longer ends it; it ends when a new message starts work after that answer: a person's message, or any delivery, whose own sender the new group then holds (a delivery that joins running work adds its sender). A reply in a covered turn continues the delivery's chain at the next hop, so the chain limit still closes it. ([#13042](https://github.com/code-yeongyu/oh-my-openagent/issues/13042), part of #12996)
