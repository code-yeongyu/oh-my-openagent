**The model_profile verbs remove only their own backup and refuse the folder owner's home.** A write's pre-write copy now goes to a name only that write uses, so a backup another writer makes at the same moment is never removed. The home-folder refusal covers this account's homes and the home of the account that owns the folder - looked up once per call through the system user database (`getent passwd` on Linux, `id -P` on macOS), so it also covers network (NSS/LDAP) accounts and never stats every account's home; a folder that merely sits beside an account's home is no longer refused. ([#13209](https://github.com/code-yeongyu/oh-my-openagent/pull/13209), follow-up to #13207)
