### Fixed

- A memory reflection or dream launcher now hears its supervisor's exit even when the supervisor dies while the "launched" receipt is still being written. The launcher used to subscribe to the exit only after that write, so an early supervisor death was never reported and the launcher waited for an outcome that could not arrive: until the run deadline (15 minutes by default), or without a deadline while the run was still queued. The run now fails at once with the supervisor's exit status.
