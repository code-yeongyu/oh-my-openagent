## 2026-11-12 - One shared endpoint enumeration per agent dir (#13236)

`live-surface.ts`: enumerations live in a process-wide map keyed by the resolved agent dir, the legacy socket and the engine launch, and are no longer kept in each surface. The 5 s window is unchanged; the #13231 deadline is now timed on a monotonic clock (`monotonic`, default `performance.now`), so a wall-clock jump never abandons an enumeration that is about to answer. A caller still waiting on an abandoned enumeration gets its list, but its late answer never replaces a kind the newer enumeration recorded. The key is read from `env` on every call. A surface given its own `statusAll` or `registry` keeps a private map; `enumerations` lets a test share one explicitly. A unit test pins the enumerations one send starts: 1 inside a window and 2 when every step outlives it, for a first send and for a reply.
