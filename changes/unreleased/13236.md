## 2026-11-12 - One shared endpoint enumeration per agent dir (#13236)

`live-surface.ts`: enumerations live in a process-wide map keyed by the resolved agent dir, the legacy socket and the engine launch, and are no longer kept in each surface. The #13231 deadline and the 5 s window are unchanged. A surface given its own `statusAll` or `registry` keeps a private map; `enumerations` lets a test share one explicitly. A unit test pins the enumerations one send starts: 1 inside a window and 2 when every step outlives it, for a first send and for a reply.
