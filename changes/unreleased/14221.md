### Fixed

- A newer gateway store schema of an extension is no longer reported as the gateway's own schema with that extension's migration counts.
- When a thread created on another device cannot be named because this device is signed out, the warning now names this device's sign-in instead of telling you to update omo on that device.
- `thread_create` with an alias held by a thread on another device no longer opens a copy of that thread's session file on a third device as if it were the holder.
- The remote wake's engine minimum now also holds back a compiled omo or dev build when a caller sets a stricter minimum, and an omo prerelease no longer counts as its release.
- A reply's route and the listing it takes are decided from one read of this device's id, and a late endpoint listing no longer replaces a terminal's kind that another session's newer listing recorded.
