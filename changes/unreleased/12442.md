## 2026-11-05 - Comment-checker state is per session (#12442)

`createCommentCheckerComponent` kept its per-turn record of reported files and its failed-start flag on the component object, which omo builds once per process and every session registers. Both now live in a per-session map (`comment-checker/scope.ts`) keyed by the event's session id and dropped on `session_shutdown`; `turn_start` clears only its own session's record. The resolved binary and the missing-binary notice stay process-wide.
