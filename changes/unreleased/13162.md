### Fixed

- Release notes no longer publish references to private repositories. Two layers apply to commit subjects, contributor titles and fragment text in the published release body: an allowlist keeps references and GitHub URLs to allowlisted public repositories and replaces every other repository reference or GitHub URL (including unknown third-party repositories, by design) with "tracked internally"; then a name-based deny pass, fed by the RELEASE_NOTES_PRIVATE_NAMES secret, replaces any link, URL or reference that names a listed repository however it is encoded (percent-encoding, HTML entities, markdown or backslash escapes, repeated slashes, trailing-dot hosts). Bare names only match in reference contexts, so ordinary words stay. The release job now refuses to publish when that secret is missing or empty.
