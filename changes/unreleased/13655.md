### Fixed

- A memory sync cycle that fails on anything other than a stranded lock, an expired sign-in or the network now says what failed instead of one "unexpected error". A full disk, a refused or read-only write and a service refusal each get their own reason and action. Every such failure carries a safe cause (error class, errno or service code, HTTP status, git exit code and the cycle stage, never message text or paths) in the TUI notice and as an optional `cause` on the `omo.memory.status` sync failure. With OMO_DEBUG=1 the memory log holds the whole error with its stack and cause chain (#13635). ([#13655](https://github.com/code-yeongyu/oh-my-openagent/pull/13655))
