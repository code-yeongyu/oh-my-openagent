### Added

- The engine can recover memory on a fresh device for the desktop app: `omo.memory.sync.recover` runs the recovery through the desktop's protected window and turns memory sync on, `features` lists `recover`, and `status.recovery` names the enrolled recovery method and whether this device already syncs. ([#14464](https://github.com/code-yeongyu/oh-my-openagent/pull/14464))

### Fixed

- Recovery refuses on a device that is already part of the account's memory sync, so it can no longer rotate the account's other devices out. `omo sync recover` says so and points at `omo sync enable`. ([#14464](https://github.com/code-yeongyu/oh-my-openagent/pull/14464))

## 2026-11-20 - Recover refuses on a device that already syncs (#14464)

`omo sync recover` answers that the device is already part of memory sync instead of recovering it again, and it turns sync on through the same path the desktop uses.

## 2026-11-20 - Desktop recover verb (#14464)

`omo.memory.sync.recover` recovers memory on a fresh device through the desktop's protected window; the engine never sees the recovery phrase. `status.recovery` reports the recovery method, whether this device is a member, or a pin that needs repair.
