### Changed

- thread: a host that does not authenticate (an engine older than 2026.10.24-3, which publishes no key record; code-yeongyu/senpi#3795) is still served in this release, except where it is already refused: when a key record names its endpoint (`host_identity_unproven`), or when a record under the key root cannot be used (`unsafe_key_record`). From the next release every such host is refused with `host_unauthenticated`. To prepare: `omo update`, then `omo daemon stop`, then any thread call. Windows named pipes do not yet prove the host's identity (code-yeongyu/senpi#7571). See "Hosts that do not authenticate" in the `omo thread` reference ([#15222](https://github.com/code-yeongyu/oh-my-openagent/issues/15222)).
