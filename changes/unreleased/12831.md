### Added
- Wayland (Hyprland): window-targeted pointer input through libei behind a `windowInput` capability probe (`no_eis`, `hyprland_ipc_missing` reasons).
- Wayland (KWin): window-targeted pointer input through the same libei path, and window captures placed on the KWin frame rectangle so coordinates round-trip between capture and click.
- `senpi-desktop-sdk`: the typed facade package for computer-use v2 consumers (connect, Computer / Window / Element / Frame, reports and verification, typed errors), with a pinned facade manifest and a package-boundaries test.
- Desktop engine: `skeleton` observation (logical depth 3), the web-wrapper rule, and `root: <ref>` drill with sub-generations (object mode only).
- `senpi-desktop-sdk`: the spawn transport with the in-session refusal (`spawn_inside_session`); the service run facade routes windows, displays and capabilities through the SDK.
- Desktop engine host: features-gated session.open options (intervention, macosKeyPriming, trace, reportMode) sent only when the engine advertises them; `ActionReport` typed exec results with the 7 valid disposition pairs; reserved settings `computer.run_sandbox`, `intervention`, `macos_key_priming`, `trace` (defaults unchanged); error codes `COMPUTER_AMBIGUOUS_TARGET`, `COMPUTER_CAPTURE_CONSENT_REQUIRED`, `COMPUTER_PROTECTED_PROCESS` with `data.reason` hints.
- Desktop engine: late replies after a stop are quarantined (`Suspended`, disposition `unknown / unknown`, audited on stderr); macOS helpers (overlay, keymap, canary) gain parent-death containment.
- Desktop service: a fresh-process permission re-probe before every session open, so a capture/accessibility grant made after a denial is seen without restarting the service.
- `computer.run`: a QuickJS cell with wall-clock, call and payload limits and an escape battery (no host bridge yet).
- macOS capture: SkyLight-first window capture with SCK/legacy fallback, capture of windows on another Space, and a measured replayd consent probe (opt-in, never gating).
- Desktop engine: epoch sources (display change, lock, sleep, Space switch, engine restart) announced as `epoch.changed`; stale frames after an epoch move answer `InvalidCoordinateFrame superseded`.
- Desktop engine: the ref-generation store keeps 8 live generations per target and up to 65,536 retained objects; refs past their generation answer `StaleRef`.
- Desktop engine: object-mode `ax.snapshot` returns a partial observation (`complete`, `nodesObserved`, `cuts`) at a 3000 ms default deadline and a node budget; null mode is byte-equal to v1.
- Desktop engine: per-stage timings on action reports and a redacted trace JSONL sink, both behind the `trace` session option (default off).
- Wayland (KWin): window-targeted pointer input through libei behind the `windowInput` capability probe, plus the KDE QA driver.
- Kernel `computer` globals (JS and Python preludes) are generated from the SDK facade manifest; `verify` lives on the desktop root, `drill` on window handles.
- Wayland (GNOME): window-targeted pointer input through a small Shell extension that publishes the window list over the session bus.

### Changed
- Desktop engine: the stop-marker policy is pinned to the XPC-only path and reported by `omo doctor`.
