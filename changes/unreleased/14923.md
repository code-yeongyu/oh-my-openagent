### Changed

- Telemetry destinations are disclosed everywhere they must be, and every opt-out now stops every sender: the first-run notice, the installer text, the privacy policy and the telemetry reference name both destinations (the PostHog project at `https://us.i.posthog.com` and OmO's own OTLP collector at `https://t.omo.dev`); `OTEL_SDK_DISABLED=true` now disables the PostHog senders as well, not only the collector; `*_SEND_ANONYMOUS_TELEMETRY=yes` no longer opts out (`0`, `false` and `no` still do — migration note in the telemetry reference); and the Codex adapter's daily ping (CLI, installer, and plugin session start) now honors `telemetry.enabled: false` in `omo.json` like every other sender. ([#14920](https://github.com/code-yeongyu/oh-my-openagent/issues/14920))
