**A send to an agent on another device now reports the same facts as one on this device.** `thread_send` and `thread_handoff` answer `delivery_id` and `effective_mode` for a target on another device too, so a caller reads the delivery's id and the lane it took the same way whichever device holds the thread; `message_seq` and `endpoint` stay the facts of a gateway row on this device, and `device` names another one. The reply allowance (a run answering the agent whose delivery it took in, by that agent's id or stated name, with no prompt) is proved identical for a same-device and a cross-device delivery, and one parity table now runs every send assertion against both legs, so a rule that reads the transport fails the build instead of reaching a user. ([#13006](https://github.com/code-yeongyu/oh-my-openagent/issues/13006), on top of [#13000](https://github.com/code-yeongyu/oh-my-openagent/pull/13000))
