**Computer use gets a declared-outcome conformance catalog for its QA.** `script/qa/computer/conformance/` adds a typed catalog in which every action, toolkit and mode cell on each OS declares that it delivers or refuses with an exact engine code, a report that fails a missing, duplicate, skipped or mis-coded cell or one that disturbed the person's session, an environment preflight that ends a broken host's run as `ENVIRONMENT_ERROR`, and twelve model-free reference tasks. QA tooling only; no runtime behaviour changes. ([#13241](https://github.com/code-yeongyu/oh-my-openagent/pull/13241), part of #13221)
