**A monitor no longer loses a batch that arrives while the previous one is being sent.** `flushMonitor` deleted the monitor's pending entry after awaiting a dispatch, so a batch queued during that await vanished without counting as dropped. The flush now deletes the entry only when it is still the one it drained. ([#13089](https://github.com/code-yeongyu/oh-my-openagent/pull/13089))
