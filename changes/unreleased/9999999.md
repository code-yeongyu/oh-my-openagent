### Added
- Desktop engine host: features-gated session.open options (intervention, macosKeyPriming, trace, reportMode) sent only when the engine advertises them; `ActionReport` typed exec results with the 7 valid disposition pairs; reserved settings `computer.run_sandbox`, `intervention`, `macos_key_priming`, `trace` (defaults unchanged); error codes `COMPUTER_AMBIGUOUS_TARGET`, `COMPUTER_CAPTURE_CONSENT_REQUIRED`, `COMPUTER_PROTECTED_PROCESS` with `data.reason` hints.
### Added
- Desktop engine: late replies after a stop are quarantined (`Suspended`, disposition `unknown / unknown`, audited on stderr); macOS helpers (overlay, keymap, canary) gain parent-death containment.
### Added
- Desktop service: a fresh-process permission re-probe before every session open, so a capture/accessibility grant made after a denial is seen without restarting the service.
### Added
- `computer.run`: a QuickJS cell with wall-clock, call and payload limits and an escape battery (no host bridge yet).
### Added
- macOS capture: SkyLight-first window capture with SCK/legacy fallback, capture of windows on another Space, and a measured replayd consent probe (opt-in, never gating).
### Added
- Desktop engine: epoch sources (display change, lock, sleep, Space switch, engine restart) announced as `epoch.changed`; stale frames after an epoch move answer `InvalidCoordinateFrame superseded`.
### Added
- Desktop engine: the ref-generation store keeps 8 live generations per target and up to 65,536 retained objects; refs past their generation answer `StaleRef`.
