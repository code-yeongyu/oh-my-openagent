### Added
- Desktop engine: object-mode `ax.snapshot` returns a partial observation (`complete`, `nodesObserved`, `cuts`) at a 3000 ms default deadline and a node budget; null mode is byte-equal to v1.
### Added
- Desktop engine: per-stage timings on action reports and a redacted trace JSONL sink, both behind the `trace` session option (default off).
### Added
- Wayland (KWin): window-targeted pointer input through libei behind the `windowInput` capability probe, plus the KDE QA driver.
### Added
- Kernel `computer` globals (JS and Python preludes) are generated from the SDK facade manifest; `verify` lives on the desktop root, `drill` on window handles.
### Added
- Wayland (GNOME): window-targeted pointer input through a small Shell extension that publishes the window list over the session bus.
### Changed
- Desktop engine: the stop-marker policy is pinned to the XPC-only path and reported by `omo doctor`.
