### Changed

- OmO now runs on senpi 2026.11.10-3 (from 2026.11.10-2). A session follows the permission setting of the machine it runs on: work sent from another device of the same account, which the relay states as such, no longer asks for approval, and one remote command no longer makes every later automatic turn on that session ask. Devices of another account still ask.

### Added

- The senpi `contextFiles.globalPath` setting loads the global context file from an explicit file or directory (for example `~/.agents/AGENTS.md`). It is read from global settings only, and an unset value keeps the current behavior.

### Fixed

- From senpi 2026.11.10-3: the footer names the account actually serving the session when the pinned account is blocked, pinned Ultrafast variants no longer warn that Ultrafast is undocumented, provider error text and fallback-log fields are value-redacted everywhere, and after a mid-session model switch the context usage no longer shows the previous model's token count against the new model's window.
