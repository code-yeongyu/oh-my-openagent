# Keywords

A few words in your message switch OmO into a special way of working. You don't need a command or a menu: type the word anywhere in the message and send it.

## The keywords

| Type | What OmO does |
| --- | --- |
| `ulw` or `ultrawork` | Plans the job, does the work, checks the result on the real thing, and keeps going until the task is done. |
| `ulw loop` | Sets a goal with checks that prove it is done, then works step by step until every check passes. |
| `ulw plan` | Explores the code first and writes one complete plan before changing anything. |
| `ulw research` | Sends a team of agents across many sources and hands back one report with its sources. |
| `mass ulw` | Splits a large job into tasks and runs them side by side as a [workflow](workflows.md). |

`mass ulw` also answers to `mulw`, `ulw mass` and `meth`. Keywords combine: `mass ulw research` runs a research job as a workflow.

## How OmO spots them

- Case doesn't matter, and a space, a hyphen or no gap all count: `ulw loop`, `ulw-loop` and `ulwloop` are the same.
- Only whole words count. `ulw` inside a longer word, such as `ulwx`, does nothing.
- Words inside `inline code` or a code block are ignored, so you can write about a keyword without starting it.
- Mentioning a keyword only asks OmO to check whether you want that mode. If you are just talking about it, OmO carries on as normal.
