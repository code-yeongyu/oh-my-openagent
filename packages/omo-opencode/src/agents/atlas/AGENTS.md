# Atlas

`agent.ts` creates the primary orchestration agent with its existing settings.
Its model core is generated by the public Senpi builders through
`../native-model-prompt.ts`. `../opencode-role-append.ts` appends the role,
available agents, categories and skills. No Atlas model markdown variants
or per-model routing table remain in prompts-core.

`prompt-section-builder.ts` supplies shared category descriptions.
The runtime-injection test protects live context data; the parent catalog
matrix proves rendered Native content parity. Per-request frame replacement
handles runtime model switches while preserving the role and user appends.
