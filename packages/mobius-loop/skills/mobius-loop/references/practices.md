# Choose a practice for the current need

These practices are optional aids, not required stages or ceremonies.

| Need | Practice | Useful result |
| --- | --- | --- |
| Clarify intended impact | [Target Outcomes](https://openpracticelibrary.com/practice/target-outcomes/) | A result and a way to recognize it |
| Connect impact to possible work | [Outcome Mapping](https://openpracticelibrary.com/practice/outcome-mapping/) | Obstacles and candidate actions |
| Identify affected people and feedback sources | [Stakeholder Mapping](https://openpracticelibrary.com/practice/stakeholder-mapping/) | Named perspectives to investigate |
| Test a risky assumption | [Design of Experiments](https://openpracticelibrary.com/practice/design-of-experiments/) | A hypothesis, measurement, and interpretable result |
| Bound an experiment | [Experiment Canvas](https://openpracticelibrary.com/practice/experiment-canvas/) | Scope, participants, expectations, and follow-through |
| Improve ways of working | [Retrospectives](https://openpracticelibrary.com/practice/retrospectives/) | An owned improvement to Foundation |

Use original project records rather than copying a workshop template. Explain
why the selected practice helps answer the present question. Keep cultural and
collaboration needs visible alongside technical work.

These brief descriptions are original navigation aids. For model attribution,
see [the model reference](model.md).
